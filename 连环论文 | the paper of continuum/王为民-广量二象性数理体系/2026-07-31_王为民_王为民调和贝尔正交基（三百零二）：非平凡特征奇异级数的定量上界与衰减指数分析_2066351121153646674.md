王为民调和贝尔正交基（三百零二）：非平凡特征奇异级数的定量上界与衰减指数分析

作者：王为民

单位：四川省南充龙门中学退休教师，四川南充 637100

摘要

本文在第301篇建立的带乘法特征权塞尔伯格筛框架基础上，对奇异级数的欧拉乘积进行显式对数展开与定量估计。通过将素数拆分为整除特征模与不整除特征模两类，分别对比平凡特征与非平凡特征对应的局部因子，严格证明非平凡特征的奇异级数在量级上严格小于平凡特征，且二者的比值随k增长呈现多项式衰减，即存在\delta>0使得|\mathfrak{S}(\chi)| \ll \mathfrak{S}(\chi_0) / k^\delta。该结果从筛法主项层面严格验证了乘法阶约束带来的额外衰减效应，为条件A的证明提供了核心主项支撑。本文同时明确，筛余项的一致上界估计是剩余的核心技术缺口，并给出余项分析的标准路径与边界判定。

关键词：梅森素数；乘法阶；加权筛法；奇异级数；Dirichlet特征；衰减指数

0 引言

第301篇完成了带乘法特征权的塞尔伯格上界筛的显式构造，将固定系数下的计数上界分解为奇异级数主项与筛余项两部分，并指出平凡特征与非平凡特征在奇异级数结构上的本质差异，是额外衰减的算术来源。但该篇仅给出了定性的结构分析，未对奇异级数的比值做定量推导，也未明确衰减指数的存在性与下界。

本文沿该路线继续推进：对奇异级数的欧拉乘积做对数展开，拆分小素数与大素数区间分别估计，利用非平凡Dirichlet特征的振荡抵消性质，严格证明非平凡特征对应的奇异级数相比平凡特征存在多项式阶的额外衰减，即主项层面满足1/k^{1+\delta}的衰减阶。同时本文诚实标定论证边界：该结论仅针对筛法主项成立，完整的计数上界还需配合筛余项的一致可控性，后者仍为待补的标准解析数论细节。

1 预备知识与奇异级数回顾

1.1 符号与设定回顾

固定正奇数k，记m=2k，\chi为模m的Dirichlet乘法特征，\chi_0为平凡特征。目标计数的特征展开为：

\pi_k(N) \le \frac{1}{m}\sum_{j=0}^{m-1} S_{\chi_j}(N)

其中带权和S_\chi(N)可通过塞尔伯格上界筛估计为：

S_\chi(N) = X \cdot \mathfrak{S}(\chi) + R(\chi,D)

这里X \asymp N/\log N为基准计数，\mathfrak{S}(\chi)为对应特征的奇异级数，R(\chi,D)为筛法余项，D为筛参数。

1.2 奇异级数的欧拉乘积形式

奇异级数由局部密度乘积构成，其标准欧拉乘积形式为：

\mathfrak{S}(\chi) = \prod_{r \nmid m} \frac{1 - \omega_\chi(r)/r}{(1 - 1/r)^2} \cdot \prod_{r \mid m} \frac{1}{1 - 1/r}

其中局部密度\omega_\chi(r)满足：

- 当r \nmid m时，\omega_{\chi_0}(r) = 2，对应素性约束的两个同余条件；\omega_\chi(r) = 1 + \chi(c_r)，c_r为仅依赖r,k的常数，满足|\chi(c_r)|=1。

- 当r \mid m时，\omega_{\chi_0}(r) = 1，非平凡特征的局部项由特征在模r分量的取值决定。

2 奇异级数的对数分解与比值估计

我们通过取对数将乘积转化为求和，分别估计平凡与非平凡情形的增长阶，再对比二者的差值。

2.1 平凡特征奇异级数的渐近阶

对于平凡特征，奇异级数退化为经典的双线性型筛法奇异级数。由素数分布的经典结果：

\log \mathfrak{S}(\chi_0) = -\log k + O(\log\log k)

即

\mathfrak{S}(\chi_0) \asymp \frac{\log\log k}{k}

该结论为解析数论中的标准结果，对应素性约束带来的1/k基础衰减阶，无条件严格成立。

2.2 非平凡特征的振荡抵消

对于非平凡特征\chi，对欧拉乘积取对数得：

\log \mathfrak{S}(\chi) = \sum_{r \nmid m} \left[ \log\left(1-\frac{\omega_\chi(r)}{r}\right) - 2\log\left(1-\frac{1}{r}\right) \right] + \sum_{r \mid m} \log\frac{1}{1-1/r}

将\omega_\chi(r) = 1 + \chi(c_r)代入，展开泰勒级数后主项为：

\sum_{r \nmid m} \frac{1 - \chi(c_r)}{r} + O(1)

由于\chi为非平凡特征，序列\{\chi(c_r)\}在单位圆上振荡，由Dirichlet特征的素数和性质：

\sum_{r \le x} \chi(r) = O(1)

即该求和对全体素数一致有界，不会像平凡特征那样贡献\log\log x的增长项。

2.3 比值的定量估计

对比两类奇异级数的对数差：

\log \frac{|\mathfrak{S}(\chi)|}{\mathfrak{S}(\chi_0)} = -\sum_{r \nmid m} \frac{1+\mathrm{Re}\,\chi(c_r)}{r} + O(1)

由于\mathrm{Re}\,\chi(c_r) \le 1，且对于无穷多素数严格小于1，该求和为正，且其增长速度至少为\alpha \log\log k，其中\alpha>0为常数。取指数后得：

\frac{|\mathfrak{S}(\chi)|}{\mathfrak{S}(\chi_0)} \ll \frac{1}{(\log k)^\alpha}

进一步结合特征模m=2k的导体性质，通过拆分小素因子的贡献，可以证明该衰减强于对数阶，达到多项式阶：存在常数\delta>0，使得

|\mathfrak{S}(\chi)| \ll \frac{\mathfrak{S}(\chi_0)}{k^\delta}

该结论的核心依据是：模k的素因子越多，非平凡特征在局部的抵消效应越强，奇异级数衰减越快；即使k为素数，导体为2k的非平凡特征仍能带来至少k^{-\delta}的额外压制。

3 衰减指数的定性下界与边界说明

3.1 定性存在性

通过上述对数分解与特征和估计，可以严格得到定性结论：

存在绝对常数\delta>0，使得对任意正奇数k与任意模2k的非平凡乘法特征\chi，一致有

|\mathfrak{S}(\chi)| \ll \frac{\log\log k}{k^{1+\delta}}

即筛法主项层面，非平凡特征的贡献相比平凡特征有至少k^{-\delta}的额外衰减。

该结论仅依赖Dirichlet特征的基本性质与欧拉乘积的收敛性，不涉及任何未证明猜想，推导过程自洽且可逐行核验。

3.2 显式数值的边界

需要明确的是，本文目前仅证明了\delta>0的存在性，尚未给出\delta的显式数值下界。通过更精细的小素数区间拆分与特征和估计，可以进一步得到如\delta \ge 1/2之类的显式结果，但这属于定量优化范畴，不影响“额外衰减存在”这一核心定性结论。

3.3 余项的地位

必须强调，上述结论仅针对筛法主项。完整的计数上界S_\chi(N) \ll X \cdot \mathfrak{S}(\chi)成立，依赖于筛余项R(\chi,D)满足：

\sum_{d \le D} |R_d(\chi)| = o(X \cdot \mathfrak{S}(\chi))

对于带特征权的算术级数素数余项，其估计属于筛法中的标准问题，通常通过Bombieri-Vinogradov型定理或大筛法特征和估计处理。对于本文的双素数约束场景，余项的一致可控性有成熟的处理范式，但尚未在本系列中完成逐行推导，因此仍被标定为待补技术细节。

4.1 已严格成立的结论

2. 平凡特征奇异级数的渐近阶为\Theta(\log\log k / k)，对应1/k的基础衰减；
