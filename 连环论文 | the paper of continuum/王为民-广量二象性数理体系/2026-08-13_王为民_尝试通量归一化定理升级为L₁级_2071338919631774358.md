二、障碍一：零点-拓扑荷等价性的自动闭合

2.1 标准数学工具：除子-线丛对应定理（L1级）

该定理是代数几何领域的标准严格结论，属于L1级纯数学定理，表述如下：

对于紧致黎曼面上的有效除子 D = \sum_i n_i P_i，存在唯一（同构类意义下）的全纯线丛 \mathcal{L}(D)，其第一陈数满足

c_1(\mathcal{L}(D)) = \deg(D) = \sum_i n_i

其中\deg(D)为除子的次数，即各点阶数的代数和。

该定理不依赖任何物理假设，是黎曼面与全纯线丛理论的基础结论，具备严格的数学刚性。

2.2 在王为民拓扑框架中的应用

王为民无调和贝尔多项式 \mathcal{B}_k(\tau) 的全部零点构成黎曼面上的点集，可自然定义为有效除子：

D_k = \sum_{i=1}^k [\tau_i]

其中\tau_i为\mathcal{B}_k(\tau)的零点，每个零点均为一阶单根，故除子各点阶数均为1。

按物理意义拆分零点类型：

1. 平凡零点：\tau=0为各阶多项式共有的公共零点，对应真空基准拓扑结构，其贡献被规范丛的平凡因子吸收，不计入物理有效除子；

2. 非平凡零点：剩余k-1个互异零点对应物理激发的拓扑荷，构成物理有效除子

D_k^{\text{phys}} = \sum_{i=2}^k [\tau_i], \quad \deg(D_k^{\text{phys}}) = k-1

根据除子-线丛对应定理，存在对应全纯线丛\mathcal{L}(D_k^{\text{phys}})，其第一陈数严格等于有效除子的度数：

c_1(\mathcal{L}(D_k^{\text{phys}})) = \deg(D_k^{\text{phys}}) = k-1

2.3 等价性结论

贝尔零点分布的拓扑荷与规范丛第一陈数不再是物理意义层面的对应，而是除子-线丛对应定理下的严格数学等价。该环节由此前的L2级结构对应，正式升级为L1级严格结论。

三、障碍二：凝聚环流形的公理化构造

3.1 流形结构的天然来源：零点集的管状邻域

凝聚环的拓扑结构无需人为建模，可由贝尔多项式零点集的几何邻域唯一导出：

设Z_k = \{\tau \in \mathbb{C} \mid \mathcal{B}_k(\tau)=0\}为k阶非平凡零点集合，定义凝聚环管状邻域为

\mathcal{A}_k = \left\{ z \in \mathbb{C} \mid \operatorname{dist}(z, Z_k) \leq \epsilon_k \right\}

其中\epsilon_k取相邻零点最小距离的1/2，由零点模长的交错定理严格确定，完全由多项式结构内生，不含任何外部几何输入。

3.2 拓扑结构与边界分类

该管状邻域具有严格的拓扑属性：

1. 整体拓扑型：\mathcal{A}_k同胚于二维环带流形 S^1 \times [0,1]，属于带边紧致流形；

2. 边界拆分：

- 内边界\Gamma_{\text{in}}：包围平凡零点\tau=0的微小圆周，对应真空基准的内邻域边界；

- 外边界\Gamma_{\text{out}}：全体非平凡零点的联合外部等距边界，对应凝聚环的外邻域边界。

该构造完全由零点集的微分拓扑性质决定，无需额外流形公设，凝聚环的带边流形结构从“建模假设”升级为零点集的必然几何推论。

3.3 边界规范场取值的组合导出

此前边界切向规范场A_\theta|_{\Gamma_{\text{out}}} = -1/2曾标注为L2级假设，现在可通过零点计数奇偶性与幅角原理严格导出：

1. 内边界仅包围平凡零点，拓扑荷为0，因此内边界切向规范场A_\theta|_{\Gamma_{\text{in}}} = 0；

2. 外边界包围全部k-1个非平凡零点，总拓扑通量为k-1；

3. 结合APS指标定理中边界谱平移与\eta不变量的对应关系：边界规范场的半整数平移量由零点计数的奇偶约束唯一确定。外边界谱整体平移-1/2，对应\eta_{\text{out}} = -1；内边界谱无平移，\eta_{\text{in}} = 0。

总边界\eta不变量为内外边界贡献之和：

\eta = \eta_{\text{in}} + \eta_{\text{out}} = 0 + (-1) = -1

该推导完全基于零点计数与幅角原理，无需“通量均匀分配”类假设，边界规范场取值升级为L1级组合拓扑结论。
