1.1 王为民‑Markov 恒等式

命题：

\boxed{

[n]_q=\mathrm{tr}_{\rm V4.3}(P_{(n-1)})

}

其中王为民归一化迹定义为：

\mathrm{tr}_{\rm V4.3}(x)=[2]_q^{\,n-1}\cdot\mathrm{tr}_{\rm std}(x),\qquad x\in TL_{n-1}

证明：

由 Jones 1983 标准 Markov 迹定理：

\mathrm{tr}_{\rm std}(P_{(m)})=\frac{[m+1]_q}{[2]_q^{\,m}}

取 m=n-1：

\mathrm{tr}_{\rm std}(P_{(n-1)})=\frac{[n]_q}{[2]_q^{\,n-1}}

由王为民归一化迹定义：

\mathrm{tr}_{\rm V4.3}(P_{(n-1)})=[2]_q^{\,n-1}\cdot\frac{[n]_q}{[2]_q^{\,n-1}}=[n]_q

证毕。 ∎

数值验证：

n \mathrm{tr}_{\rm std}(P_{(n-1)}) [2]_q^{\,n-1} \mathrm{tr}_{\rm V4.3}(P_{(n-1)}) [n]_q

1 1 1 1 1

2 1 3 3 3

3 8/9 9 8 8

4 21/27 27 21 21

5 55/81 81 55 55

定级：A 类严格定理。

备注：\mathrm{tr}_{\rm V4.3} 是人为重归一化迹，不改变 TL 代数本身结构，定义自洽。

1.3 三周期符号函数唯一性

命题：

满足 B_3 中心元约束和三代符号交替条件 f(1)=+1,\ f(2)=-1,\ f(3)=+1 的实周期 3 函数唯一：

\boxed{

\operatorname{sgn}(T)=\frac13+\frac43\cos\left(\frac{2\pi(T-1)}{3}+\frac{\pi}{3}\right)

}

证明：

设 f(T)=A+B\cos\left(\frac{2\pi(T-1)}{3}\right)+C\sin\left(\frac{2\pi(T-1)}{3}\right)。

代入三点：

A+B=1

A-\frac{B}{2}+\frac{\sqrt3}{2}C=-1

A-\frac{B}{2}-\frac{\sqrt3}{2}C=1

第三式减第二式：-\sqrt3 C=2\Rightarrow C=-2/\sqrt3。

第二式加第三式：2A-B=0\Rightarrow B=2A。

代入第一式：3A=1\Rightarrow A=1/3,\ B=2/3。

f(T)=\frac13+\frac43\cos\left(\frac{2\pi(T-1)}{3}+\frac{\pi}{3}\right)

证毕。 ∎

定级：A 类严格定理（在三阶傅里叶截断下）。

1.4 数论恒等式 13\lambda_--3=2-\varphi^{-7}

命题：

\boxed{

13\lambda_- - 3=2-\varphi^{-7}

}

其中 \varphi=(1+\sqrt5)/2，\lambda_-=\varphi^{-2}。

证明：

由 \varphi^2=\varphi+1，\varphi^7=13\varphi+8。

\lambda_-=\varphi^{-2}=\frac{\varphi-1}{\varphi}

13\lambda_- - 3=\frac{10\varphi-13}{\varphi}

2-\varphi^{-7}=\frac{26\varphi+15}{13\varphi+8}

交叉相乘：

(10\varphi-13)(13\varphi+8)=\varphi(26\varphi+15)

左边 =41\varphi+26，右边 =41\varphi+26。

\boxed{13\lambda_- - 3=2-\varphi^{-7}}

证毕。 ∎

定级：A 类严格数论恒等式。

二、A⁻ 类：集合双射（函子兼容性待证）

2.1 B_3 不可约表示与孤子极小构型集合双射

命题：

存在集合层面双射：

\boxed{

\phi:\{V_n\}_{n\ge0}\to\{V_j\}_{j\in\frac12\mathbb Z_{\ge0}},\qquad

\phi(V_n)=V_{n/2}

}

已证部分：

1. 良定义性：BPS 方程在缠绕数 n 扇区存在孤子解（1 维标量 BPS 方程标准结果）；

2. 单射性：设 \phi(V_n)=\phi(V_m)，则 n=m；

3. 满射性：对任意 V_j，取 n=2j，对应孤子 V_{2j} 存在。

关键漏洞：

\boxed{

\text{证明中直接假定“对任意 }n=2j\text{，BPS 孤子 }V_n\text{ 存在”，}

}

\boxed{

\text{但未建立该解与 }B_3\text{ 范畴对象的函子级融合兼容性。}

}

仅核验了最简单 V_{1/2}\otimes V_{1/2} 一例，没有一般融合 \otimes 的函子相容性证明。

定级：A⁻（集合双射已成立；融合函子兼容性仍为猜想）。

边界注释：

\boxed{

\text{集合层面的一一映射已经成立；一般融合积的函子对应尚未严格证明。}

}
