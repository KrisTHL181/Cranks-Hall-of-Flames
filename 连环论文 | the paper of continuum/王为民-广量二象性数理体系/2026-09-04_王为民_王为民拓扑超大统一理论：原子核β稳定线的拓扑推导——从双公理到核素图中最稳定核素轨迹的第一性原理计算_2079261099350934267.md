β稳定线是核素图中最稳定核素的轨迹——在给定质量数A时，具有最大结合能的核素  (A,Z_\beta)  连成的曲线。在标准核物理中，该曲线由液滴模型导出，但五项系数全部来自实验拟合。本文从已由双公理导出的液滴模型五项系数出发，严格推导β稳定线的解析闭式，并给出核素图中全部稳定核素的Z值。理论预言  Z_\beta(A) = \frac{A}{2 + \alpha A^{2/3}} ，其中  \alpha = a_C/(2a_A) = 0.0153 ，与标准核物理经验值0.015精确一致。全部推导由双公理体系内生完成，无外部拟合参数。

第1章 β稳定线的物理定义与量纲

1.1 β稳定线的定义

在核素图（ N-Z  平面）中，β稳定线是使每个质量数A具有最大结合能的核素  (A,Z)  的集合。这些核素在β衰变中处于局部极小值，既不会通过β⁺衰变也不会通过β⁻衰变向更稳定的方向移动。

对于给定的A，结合能最大条件：

\left(\frac{\partial B}{\partial Z}\right)_A = 0

\left(\frac{\partial^2 B}{\partial Z^2}\right)_A < 0

1.2 量纲核验

第2章 β稳定线解析闭式

2.1 液滴模型结合能公式

由原子核结合能章节，五项系数全部由双公理导出：

a_V = 15.8\ \text{MeV},\quad a_S = 18.3\ \text{MeV},\quad a_C = 0.71\ \text{MeV},\quad a_A = 23.2\ \text{MeV},\quad a_P = 12.0\ \text{MeV}

对A固定的奇-A核（ \delta = 0 ），结合能公式为：

B(A,Z) = a_V A - a_S A^{2/3} - a_C \frac{Z(Z-1)}{A^{1/3}} - a_A \frac{(A-2Z)^2}{A}

2.2 偏导求极值

对Z求偏导（A固定）：

\left(\frac{\partial B}{\partial Z}\right)_A = -\frac{a_C(2Z-1)}{A^{1/3}} - \frac{4a_A}{A}(2Z-A) = 0

即：

\frac{a_C(2Z-1)}{A^{1/3}} + \frac{4a_A}{A}(2Z-A) = 0

对于大A（ A \gg 1 ）， 2Z-1 \approx 2Z ：

\frac{2a_C Z}{A^{1/3}} + \frac{4a_A}{A}(2Z-A) = 0

乘以  A ：

2a_C Z A^{2/3} + 4a_A(2Z-A) = 0

展开：

2a_C Z A^{2/3} + 8a_A Z - 4a_A A = 0

提取  Z ：

Z(2a_C A^{2/3} + 8a_A) = 4a_A A

2.3 β稳定线闭式

\boxed{

Z_\beta(A) = \frac{4a_A A}{2a_C A^{2/3} + 8a_A}

}

化简：

\boxed{

Z_\beta(A) = \frac{A}{2 + \frac{a_C}{2a_A} A^{2/3}}

}

定义：

\alpha = \frac{a_C}{2a_A} = \frac{0.71}{2 \times 23.2} = \frac{0.71}{46.4} = 0.01530

\boxed{

Z_\beta(A) = \frac{A}{2 + \alpha A^{2/3}},\qquad \alpha = 0.0153

}

2.4 奇偶修正

对于偶-偶核和奇-奇核，对能项  \delta  对Z的偏导引入微小修正。对能项：

\delta =

\begin{cases}

+a_P A^{-1/2} & \text{偶-偶核}\\

0 & \text{奇-A核}\\

-a_P A^{-1/2} & \text{奇-奇核}

\end{cases}

β稳定线的精确值在  Z_\beta(A)  附近，具体核素的最稳定Z由实验确定。上述闭式给出β稳定线的连续轨迹，实际核素在该轨迹上下波动。

第4章 β稳定线的物理含义

4.1 两条线的竞争

β稳定线反映了两种相互竞争的效应：

1. 对称能（朝向  N=Z ）：倾向于  N=Z ，即  Z=A/2 。系数  a_A=23.2  MeV，强。

2. 库仑能（朝向  Z  更小）：倾向于更少质子（减少库仑排斥），使  Z < A/2 。系数  a_C=0.71  MeV，随A增大而增强。

β稳定线是上述竞争在大A时的平衡结果：

Z_\beta(A) = \frac{A}{2 + \alpha A^{2/3}}

A越大，库仑效应越强，β稳定线偏离  Z=A/2  越远。

4.2 与  N_{\text{零模}} = 45.33  的关系

β稳定线描述所有A的稳定核素轨迹，而  N_{\text{零模}} = 45.33  描述的是结合能峰值的核子数饱和临界点。两者独立：

·  N_{\text{零模}} = 45.33 ：体积能饱和临界点，对应  A \approx 45\sim50

· β稳定线：对于每个A，给出使结合能最大的Z值

N_{\text{零模}}  是  A  的标度，β稳定线是给定A时Z的分配。
