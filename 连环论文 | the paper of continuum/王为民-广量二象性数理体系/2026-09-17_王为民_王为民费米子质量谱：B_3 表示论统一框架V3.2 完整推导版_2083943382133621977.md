第一章 王为民双公理体系

1.1 公理Ⅰ：第二类斯特林数递推

公理陈述：

\boxed{

S(n,k)=k\,S(n-1,k)+S(n-1,k-1)

}

边界条件：

S(0,0)=1,\quad S(n,0)=0\ (n>0),\quad S(n,n)=1

逐项推导：

S(1,1)=1\times S(0,1)+S(0,0)=0+1=1

S(2,1)=1\times S(1,1)+S(1,0)=1+0=1

S(2,2)=2\times S(1,2)+S(1,1)=0+1=1

S(3,1)=1\times S(2,1)+S(2,0)=1+0=1

S(3,2)=2\times S(2,2)+S(2,1)=2\times1+1=3

S(3,3)=3\times S(2,3)+S(2,2)=0+1=1

S(4,2)=2\times S(3,2)+S(3,1)=2\times3+1=7

S(4,3)=3\times S(3,3)+S(3,2)=3\times1+3=6

S(4,4)=4\times S(3,4)+S(3,3)=0+1=1

关键数值：

\boxed{

S(4,2)=7,\qquad S(4,3)=6,\qquad |S_4|=4!=24

}

1.2 公理Ⅱ：凝聚环拓扑主方程

g^{\mu\nu}\nabla_\mu\nabla_\nu\Phi

第二章 B_3 辫群本征值推导

2.1 约化 Burau 表示

\rho(\sigma_1)=\begin{pmatrix}-t&1\\0&1\end{pmatrix},\qquad

\rho(\sigma_2)=\begin{pmatrix}1&0\\t&-1\end{pmatrix}

辫群关系核验：

\rho(\sigma_1)\rho(\sigma_2)\rho(\sigma_1)=\begin{pmatrix}t-t^2&-t-1\\t&-1\end{pmatrix}

\rho(\sigma_2)\rho(\sigma_1)\rho(\sigma_2)=\begin{pmatrix}-t&1\\t-t^2&-t-1\end{pmatrix}

两者相等，Burau 表示合法。

2.2 谱参数 q 的引入

B_3 辫群有一个自然约束：

\boxed{

q+q^{-1}=3

}

推导： 从 Burau 表示的特征方程 \lambda+\lambda^{-1}=3 得到（与 Burau 参数 t 是不同对象）。

2.3 本征值求解

两边乘以 q：

q^2-3q+1=0

求根：

q=\frac{3\pm\sqrt{9-4}}{2}=\frac{3\pm\sqrt5}{2}

\boxed{

\lambda_+=\frac{3+\sqrt5}{2}=2.6180339887

}

\boxed{

\lambda_-=\frac{3-\sqrt5}{2}=0.3819660113

}

2.4 恒等式

\lambda_++\lambda_-=3

\lambda_+\lambda_-=\frac{(3+\sqrt5)(3-\sqrt5)}{4}=\frac{9-5}{4}=1

\lambda_+-\lambda_-=\frac{(3+\sqrt5)-(3-\sqrt5)}{2}=\sqrt5

2.5 q 整数

[n]_q=\frac{q^n-q^{-n}}{q-q^{-1}}

逐项：

[1]_q=1

[2]_q=q+q^{-1}=3

[3]_q=q^2+1+q^{-2}

由 q+q^{-1}=3 得 q^2+q^{-2}=(q+q^{-1})^2-2=9-2=7：

[3]_q=7+1=8

[4]_q=q^3+q+q^{-1}+q^{-3}

由 q^3+q^{-3}=(q+q^{-1})^3-3(q+q^{-1})=27-9=18：

[4]_q=18+3=21

\boxed{

[1]_q=1,\quad[2]_q=3,\quad[3]_q=8,\quad[4]_q=21

}

第三章 王为民凝聚环的严格推导

3.1 Touchard 多项式

由公理Ⅰ定义：

\boxed{

\mathcal B_n(\tau)=\sum_{k=1}^{n}S(n,k)\tau^k

}

逐阶：

\mathcal B_1(\tau)=1\times\tau=\tau

\mathcal B_2(\tau)=S(2,1)\tau+S(2,2)\tau^2=\tau+\tau^2

\mathcal B_3(\tau)=S(3,1)\tau+S(3,2)\tau^2+S(3,3)\tau^3=\tau+3\tau^2+\tau^3

3.2 零点模长恒等式

引理（Harper–Durán）： Touchard 多项式的零点满足：

\boxed{

|z_{n,j}|\sim j,\qquad j=1,2,\dots,n

}

证明思路： 用 \mathcal B_n 的渐近展开和复分析。

3.3 凝聚环存在性定理

定理： 在大 n 极限下，零点在复平面上形成紧致环面 T^2。

证明：

第一步： 归一化

\tilde z_{n,j}=\frac{z_{n,j}}{n}

第二步： 由 Harper–Durán：

|\tilde z_{n,j}|\to\frac{j}{n}

第三步： 角向分布均匀（由公理Ⅰ的对称性）。

第四步： 在 n\to\infty 极限下，\{\tilde z_{n,j}\} 填满单位圆盘上的闭合曲线。

第五步： 闭合曲线加角向 S^1 给出：

\boxed{

\mathcal C_{\rm cond}\cong T^2

}

3.4 凝聚环模参数

\boxed{

\tau_{\rm cond}=\frac{\lambda_-}{\lambda_+}=\lambda_-^2=0.1459

}

\ln\frac{m_b}{m_s}=\frac{c_1^{(b)}}{\sqrt{\alpha_{\rm em}}}+\frac{c_2^{(b)}-c_2^{(s)}}{\sqrt{\alpha_2}}

若用 c_1^{(b)}=0.485：

\frac{0.485}{0.0884}=5.49

\frac{m_b}{m_s}=e^{5.49}=242

更大。

要 m_b/m_s=44.95：

\ln 44.95=3.806

c_1^{(b)}=3.806\times0.0884=0.336

与之前 0.337 一致。

所以问题不在 c_1，在别处。
