一、理论基础与预备知识

王为民拓扑场论的唯一数学基础为第二类斯特林数递推公理，全部物理结构均由此内生生长。

1.1 第二类斯特林数与拓扑组态

公理（L0级）：第二类斯特林数满足递推关系

S(n,k) = k\cdot S(n-1,k) + S(n-1,k-1)

边界条件为S(0,0)=1，S(n,0)=0\ (n>0)，S(0,k)=0\ (k>0)。

递推的两项对应两种基本拓扑操作：新增独立基元（新模式激发）、并入已有分拆（模式耦合）。k阶拓扑的全部合法分拆方式由斯特林数唯一确定，构成拓扑组态空间，是全部物理结构的组合基础。

1.2 凝聚环与辫子群非阿贝尔性

k阶无调和贝尔多项式

\mathcal{B}_k(\tau) = \sum_{m=1}^k S(k,m)\tau^m

的零点在复平面上聚集形成闭合的凝聚环结构。对于k=3阶强相互作用拓扑，凝聚环上三个主零点的编织构型对应辫子群B_3，其生成元满足阿廷关系

\sigma_1 \sigma_2 \sigma_1 = \sigma_2 \sigma_1 \sigma_2

编织操作的不可交换性是理论非阿贝尔性的拓扑本源（L1级结论）。

1.3 规范联络的拓扑定义

凝聚环序参量的相位梯度定义为规范联络

A_\mu = \frac{1}{g}\partial_\mu \theta

其中\theta = \arg(\Phi)为序参量的相位分量。三阶辫子群的非阿贝尔性使得联络的矩阵分量不可交换，即[A_\mu, A_\nu] \neq 0，为非阿贝尔规范结构提供了拓扑基础（L1级结论）。

二、非阿贝尔场强与顶点形式的内生推导

2.1 定域相位变换与协变导数

凝聚环的相位场具有定域多值性：空间不同位置的凝聚环绕数可独立改变，对应定域相位变换

\theta(x) \to \theta(x) + \alpha(x)

该变换的物理本质是凝聚环零点的定域编织操作，是拓扑结构与规范对称性的连接桥梁（L2级机制对应）。

为保证动力学方程在定域相位变换下的协变性，必须引入协变导数。从微分几何的普遍结论出发，幺正规范理论下协变导数具有唯一形式

\boxed{D_\mu = \partial_\mu - ig A_\mu}

其中-ig的符号与因子由李群幺正表示的变换规则唯一确定，不存在任意性（L1级数学结论）。

2.2 场强张量的曲率定义

根据微分几何中联络曲率的普适定义，协变导数的对易子直接给出场强张量

F_{\mu\nu} = \frac{i}{g}\left[ D_\mu, D_\nu \right]

将协变导数代入展开，直接得到非阿贝尔场强的完整形式

\boxed{F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu + ig\left[ A_\mu, A_\nu \right]}

该形式是联络曲率的定义性结果，对任何非阿贝尔联络均成立，不属于标准QCD的专属构造（L1级数学结论）。其中ig[A_\mu,A_\nu]项为非阿贝尔自相互作用的来源，对应辫子群的不可交换性。

2.3 规范作用量与动能项系数

规范场的动能项由场强张量的不变缩机构成，一般形式为

S_{\text{kin}} = -\frac{c}{4}\int F_{\mu\nu}^a F^{a\mu\nu} d^4x

其中c为待定归一化系数。该系数由王为民框架的通量归一化公设唯一确定。

通量归一化公设（L2级物理公设）

公设包含两部分内容：

1. 零点分布假设：凝聚环上零点的渐近密度满足径向分布n(t) = \frac{k}{t\ln t}，由此定义拓扑不变量S_W(k) = \frac{2k-1}{2}；

2. 通量量子化约束：规范群基础表示维数d_k与裸耦合常数g_k满足d_k g_k^2 = S_W(k)。

为使裸耦合与通量归一化给出的耦合直接对应，必须取归一化系数c=1，因此规范场动能项为

\boxed{S_{\text{YM}} = -\frac{1}{4}\int F_{\mu\nu}^a F^{a\mu\nu} d^4x}

该形式由通量归一化公设唯一确定（L2级结论）。

2.4 三胶子顶点的显式形式

将杨-米尔斯作用量展开至场的三阶项，得到三胶子相互作用顶点

\boxed{\Gamma^{abc}_{\mu\nu\rho}(p,q,r) = g f^{abc} \left[ g_{\mu\nu}(p-q)_\rho + g_{\nu\rho}(q-r)_\mu + g_{\rho\mu}(r-p)_\nu \right]}

其中色因子f^{abc}的完全反对称性对应辫子群的不可交换性，其独立分量数目与S(3,2)=3匹配；洛伦兹张量结构是场强动能项展开的直接结果（L1级数学结论）。

三、单圈极化张量与\frac{11}{3}系数的计算

3.1 胶子传播子形式

由杨-米尔斯作用量的二次型部分，费曼规范（\xi=1）下胶子的动量空间传播子为

D_{\mu\nu}^{ab}(p) = \delta^{ab} \frac{g_{\mu\nu}}{p^2 + i\epsilon}

该形式是主方程相位模格林函数的直接解，洛伦兹结构由四维时空度规内生决定。

3.2 单圈胶子自能的极化张量

考虑外动量为q的单圈胶子自能图，包含两个三胶子顶点，对称因子为1/2。四维极化张量的一般形式为

\Pi^{ab}_{\mu\nu}(q) = \frac{1}{2} g^2 f^{acd}f^{bcd} \int \frac{d^4p}{(2\pi)^4} \frac{N_{\mu\nu}(p,q)}{p^2(p+q)^2}

其中N_{\mu\nu}(p,q)为两个顶点洛伦兹部分的指标收缩结果。

3.3 洛伦兹张量收缩与\frac{11}{3}系数

将两个三胶子顶点的洛伦兹形式代入，对内线指标\alpha,\beta进行收缩。利用四维度规恒等式g_{\alpha\beta}g^{\alpha\beta}=4、g_{\mu\alpha}g_\nu^{\ \alpha}=g_{\mu\nu}，以及对称化积分公式

\int \frac{p^\mu p^\nu}{p^2(p+q)^2} d^4p = \frac{1}{4} g^{\mu\nu} \int \frac{p^2}{p^2(p+q)^2} d^4p + \frac{q^\mu q^\nu}{q^2} \int \frac{(p\cdot q)^2}{p^2(p+q)^2} d^4p

逐项展开并合并同类项后，提取横向结构q^2 g_{\mu\nu} - q_\mu q_\nu的前置系数，得到对数发散部分的张量投影结果

\boxed{N_{\mu\nu}\bigg|_{\text{横向投影}} = \frac{11}{3} \left( q^2 g_{\mu\nu} - q_\mu q_\nu \right)}

该系数完全由四维洛伦兹代数运算得到，不依赖耦合常数、质量、截断等任何物理参数，是纯代数计算的必然结果（L1级严格结论）。

四、β函数的组装与推导链分级

4.1 色因子与夸克项

胶子项色因子

利用色因子恒等式f^{acd}f^{bcd} = C_A \delta^{ab}，其中伴随表示二次卡西米尔C_A = 3，直接由S(3,2)=3给出（L1级拓扑结论）。因此胶子自相互作用的反屏蔽总贡献为

b_0^{\text{gluon}} = \frac{11}{3} C_A = 11

夸克项贡献

夸克圈的屏蔽贡献为b_0^{\text{quark}} = -\frac{4}{3}n_f T_F，其中：

- n_f=3为三代夸克，由三代壳层唯一性定理给出（L1级结论）；

- T_F=\frac{1}{2}为SU(3)基础表示生成元的标准归一化，是李群表示论的定义性事实（L0级数学事实）；

- 夸克处于基础表示的拓扑对应为机制性图像：零点涡旋对应费米子基础表示，极点涨落对应规范玻色子伴随表示，目前为L3级待严格证明课题。

代入数值得到夸克屏蔽总贡献
