第二部分 两种效应的显式形式

2.1 组合熵：S_{\rm comb}(k)

\boxed{

S_{\rm comb}(k)=\ln p_k

}

对于整数分拆数（Hardy–Ramanujan）：

\boxed{

p_k\sim\frac{1}{4k\sqrt3}\exp\left(\pi\sqrt{\frac{2k}{3}}\right)

}

S_{\rm comb}(k)\sim\pi\sqrt{\frac{2k}{3}}\approx2.565\sqrt{k}

对于量子维度（候选 B）：

\boxed{

p_k=[k+1]_q\sim\lambda_+^k

}

S_{\rm comb}(k)\sim k\ln\lambda_+\approx0.9624k

2.2 几何压制：S_{\rm geom}(k)

\boxed{

S_{\rm geom}(k)=-2k\ln\frac{1}{\lambda_-}=-2k\times0.9624=-1.9248k

}

物理来源： 每个模态的几何衰减因子 \lambda_-^2。

2.3 净有效熵

\boxed{

S_{\rm eff}(k)=S_{\rm comb}(k)+S_{\rm geom}(k)

}

具体：

候选 S_{\rm comb}(k) S_{\rm geom}(k) S_{\rm eff}(k)

A（整数分拆） 2.565\sqrt{k} -1.9248k 2.565\sqrt{k}-1.9248k

B（量子维度） 0.9624k -1.9248k -0.9624k

C（B_3 迹） 0.9624k -1.9248k -0.9624k

D（卢卡斯） 0.9624k -1.9248k -0.9624k

第三部分 竞争平衡点

3.1 候选 A 的平衡分析

\boxed{

\frac{dS_{\rm eff}}{dk}=\frac{1.2825}{\sqrt{k}}-1.9248=0

}

\sqrt{k}=\frac{1.2825}{1.9248}=0.6663

\boxed{

k_{\rm balance}\approx0.444

}

结论： 候选 A 的竞争平衡点几乎在 k=0 附近，没有显著平衡点。

3.2 候选 B、C、D 的平衡分析

\boxed{

S_{\rm eff}(k)=-0.9624k

}

单调递减，没有平衡点。

3.3 问题的关键

\boxed{

\text{以上分析表明：}\\

\text{根本不存在}67\text{ 阶平衡点！}

所以"竞争平衡截断"不是谱内部的平衡。
