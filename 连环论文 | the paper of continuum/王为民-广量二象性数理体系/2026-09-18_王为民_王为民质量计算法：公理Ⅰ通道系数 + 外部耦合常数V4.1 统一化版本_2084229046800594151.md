\boxed{

其中 \sin\theta_C=1/(2\sqrt5)（A 类）。

数值：

4.4 上/下夸克色通道系数

\boxed{

c_{3u},c_{3d}\text{ 是以下二次方程的两个根：}

}

\boxed{

x^2-\left(1-\frac{1}{\kappa_2}\right)\sqrt{\varphi}\,x+\frac{\lambda_++\lambda_-}{[3]_q}=0

}

即：

x^2-1.2533\,x+0.375=0

求根：

\boxed{

c_{3u}=0.4939,\quad c_{3d}=0.7594

}

4.5 第二代夸克增量

\boxed{

\Delta c_{3s}=\Delta c_{3c}=\frac{1}{\sqrt{[3]_q}}=\frac{1}{\sqrt8}=0.3529

}

4.6 电磁通道系数

\boxed{

c_{1f}=\frac{1}{\lambda_++\lambda_-}\left(3|Q_f|\right)^{\frac{\lambda_++\lambda_-}{[3]_q}\cdot\frac{1}{1-1/\kappa_2}}

\frac{\lambda_++\lambda_-}{[3]_q}\cdot\frac{1}{1-1/\kappa_2}=\frac38\times\frac{68}{67}=0.3806

上型（|Q|=2/3）：

c_{1t}=\frac13\times2^{0.3806}=0.4340

4.7 下型电磁通道系数（V4.1 修正）

\boxed{

c_{1b}

=

\frac{1}{\lambda_++\lambda_-}

\left(

1+\frac{\bar\rho}{4\Delta}

\right)

}

其中：

· \Delta=(\lambda_+-\lambda_-)^2=5：B_3 二次方程判别式；

· \bar\rho=1/\sqrt{\Delta[3]_q}=1/\sqrt{40}：A 类常数。

展开为纯 B_3 形式：

\boxed{

c_{1b}

=

\frac{1}{\lambda_++\lambda_-}

\left(

1+

\frac{1}{4\Delta^{3/2}\sqrt{[3]_q}}

\right)

}

数值核验：

\Delta^{3/2}=5^{1.5}=11.180

4\times11.180\times\sqrt8=126.5

\frac{1}{126.5}=0.007905

c_{1b}=\frac{1.007905}{3}=0.33597\approx0.3360\quad\checkmark
