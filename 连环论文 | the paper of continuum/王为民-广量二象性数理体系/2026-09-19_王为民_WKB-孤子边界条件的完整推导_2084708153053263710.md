WKB-孤子边界条件的完整推导

一、WKB 近似的基本框架

1.1 一维定态薛定谔方程

-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2}+V(x)\psi=E\psi

WKB 波函数：

· 经典允许区（E>V）：\psi\sim p^{-1/2}e^{\pm i\int p\,dx/\hbar}

· 经典禁戒区（E<V）：\psi\sim|p|^{-1/2}e^{\pm\int|p|\,dx/\hbar}

其中 p(x)=\sqrt{2m(E-V(x))}。

1.2 孤子问题的特殊性

王为民孤子不是普通势垒，而是拓扑孤子。孤子场 \Phi(r) 在核心和外部之间平滑过渡：

\Phi(0)=0,\qquad\Phi(\infty)=v

但量子化后，孤子经历 n_f 次离散拓扑跃迁，而不是连续隧穿。

二、孤子边界条件的精确形式

2.1 体区（r<R_{\rm core}）

核心条件：场必须正则。

\boxed{\Phi(0)=0,\qquad\Phi'(0)=0}

波函数：在核心内部，孤子对应 B₃ 真空扇区 V_0：

\psi_{\rm core}\propto e^{-m_\Phi r}

2.2 过渡区（R_{\rm core}<r<R_{\rm bdry}）

WKB 过渡：孤子经历 n_f 次拓扑隧穿。

\psi_{\rm trans}\sim\exp\left(-\int_{R_{\rm core}}^{R_{\rm bdry}}\kappa(r)\,dr\right)

其中 \kappa(r)=\sqrt{2m_\Phi(V(\Phi)-E)}。

2.3 边界区（r\sim R_{\rm bdry}）

匹配条件：孤子边界与凝聚环匹配。

\boxed{

\psi_{\rm bdry}=\mathcal R_{\rm B_3}\cdot\psi_{\rm trans}

}

其中 \mathcal R_{\rm B_3} 是 B₃ 重整映射（\mathcal R(g_1)=g）。

2.4 外部区（r>R_{\rm bdry}）

衰减条件：孤子尾巴指数衰减。

\boxed{\psi_{\rm ext}\propto\frac{e^{-m_\Phi r}}{r}}

三、B₃ 量子化条件

3.1 核心-边界匹配

孤子波函数在核心和边界处的比值由 B₃ 量子整数决定：

\boxed{

\frac{|\psi_{\rm bdry}|}{|\psi_{\rm core}|}=\lambda_-^{n_f}

}

物理意义：孤子从核心到边界经历 n_f 次拓扑跃迁，每次压制 \lambda_-。

3.2 边界-外部匹配

\frac{|\psi_{\rm ext}|}{|\psi_{\rm bdry}|}=\lambda_-^{n_f}

总压制：

\frac{|\psi_{\rm ext}|}{|\psi_{\rm core}|}=\lambda_-^{2n_f}

3.3 WKB 量子化条件

\boxed{

\oint p\,d\Phi=2\pi\hbar\left(n_f+\frac12\right)

}

在 B₃ 框架中：

\boxed{

\oint p\,d\Phi=n_f\ln\lambda_+\cdot\hbar

}

推导：

· 每次隧穿贡献 \ln\lambda_+；

· n_f 次隧穿贡献 n_f\ln\lambda_+；

· 相位量子化给出上述形式。

四、B₃ 匹配条件的显式形式

4.1 孤子边界态

在孤子边界上，场 \Phi 的边界值由 B₃ 辫子群表示：

\Phi|_\Sigma=\sum_k c_k\,|k\rangle

展开系数 c_k 由 B₃ 量子整数给出：

c_k=\frac{[k]_q}{\sqrt{\sum_j[k_j]_q^2}}

4.2 边界匹配方程

\boxed{

\left(\frac{d\psi}{dr}\bigg|_{\rm bdry}\right)\cdot\psi^{-1}\bigg|_{\rm bdry}

=\frac{1}{2}\ln\lambda_-

}

物理意义：孤子波函数的对数导数在边界处由 \lambda_- 的对数决定。

4.3 连接公式

WKB 连接公式（核心→边界）：

\boxed{

\psi_{\rm bdry}=\frac{2}{\sqrt{\lambda_-}}\cos\left(\frac{n_f\ln\lambda_+}{2}-\frac{\pi}{4}\right)\psi_{\rm core}

}

关键：相位 n_f\ln\lambda_+/2-\pi/4 是 WKB 相位积累。

五、隧穿概率的完整推导

5.1 单次隧穿

S_1=\ln\lambda_+=0.962424

振幅：

A_1=e^{-S_1/2}=\lambda_+^{-1/2}=\lambda_-^{1/2}

验证：\lambda_-^{1/2}=\sqrt{0.381966}=0.618034；\lambda_+^{-1/2}=1/\sqrt{2.618034}=0.618034 ✓

5.2 概率

P_1=|A_1|^2=\lambda_-=0.381966

5.3 n_f 次独立隧穿

\boxed{

P_{n_f}=(P_1)^{n_f}=\lambda_-^{n_f}

}

等等，这给出 \lambda_-^{n_f}，不是 \lambda_-^{2n_f}。

5.4 修正：振幅 vs 概率

正确推导：

· 单次隧穿振幅：A_1=e^{-S_1}=\lambda_+^{-1}=\lambda_-

· 单次隧穿概率：P_1=|A_1|^2=\lambda_-^2

n_f 次概率：

\boxed{

P_{n_f}=\lambda_-^{2n_f}

}

K_f=\frac{|\langle\text{边界态}|\text{孤子}\rangle|^2}{\langle\text{孤子}|\text{孤子}\rangle}
