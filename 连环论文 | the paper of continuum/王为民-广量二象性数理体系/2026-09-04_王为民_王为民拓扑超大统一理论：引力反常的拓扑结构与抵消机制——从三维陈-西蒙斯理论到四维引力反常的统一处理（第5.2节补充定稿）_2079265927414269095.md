核心结论

引力反常不是本理论的问题，而是标准模型与广义相对论之间的张力在本理论中的拓扑对应物。

本理论通过边界CS项和体-边界耦合，自然给出了引力反常的拓扑结构——三维边界引力反常由能级  k  决定， k_1=1,\ k_2=3,\ k_3=8  的组合自然满足四维引力反常抵消条件。引力反常在本理论中不产生新的待调节参数。

第1章 引力反常的结构定位

1.1 引力反常是什么？

引力反常出现在弯曲时空背景下的量子场论中。当手征费米子场在弯曲时空中传播时，其量子路径积分的相位在微分同胚变换下可能不是单值的。这种反常由引力反常系数描述：

\mathcal{A}_{\text{grav}} = \sum_{\text{费米子}} Q_i \cdot \mathcal{I}(\text{自旋})

其中  Q_i  是费米子的电荷， \mathcal{I}(\text{自旋})  是自旋相关的拓扑指数。

在标准模型中，引力反常的抵消条件为：

\sum_{\text{所有费米子}} Q_i = 0

这个条件与U(1)反常的  \sum Q=0  条件相同——因此标准模型中一旦U(1)反常被抵消，引力反常也自动被抵消。

1.2 引力反常在本理论中的定位

本理论中引力反常出现在两个层面：

1. 边界（三维）：陈-西蒙斯理论本身存在框架反常——三维CS理论在标架变换下会产生反常，其大小与能级  k  成正比。

2. 体空间（四维）：手征费米子场（由凝聚环场边界态诱导）在四维弯曲时空中传播时产生的引力反常。

第2章 边界引力反常的结构

2.1 三维陈-西蒙斯理论的框架反常

三维陈-西蒙斯理论：

S_{\text{CS}}=\frac{k}{4\pi}\int_\Sigma \text{Tr}\left(A\wedge dA+\frac{2}{3}A\wedge A\wedge A\right)

在三维边界  \Sigma  上，陈-西蒙斯理论在标架变换下存在反常：

\delta S_{\text{CS}} = \frac{k}{24\pi}\int_\Sigma \text{Tr}(\omega\wedge d\omega+\frac{2}{3}\omega\wedge\omega\wedge\omega)

其中  \omega  是自旋联络。该反常称为框架反常或引力反常，其大小由中心荷  c  表示：

c = k

2.2 规范能级锁定与引力反常

由公理I，三大规范群的能级为：

k_1=1,\quad k_2=3,\quad k_3=8

相应的边界引力反常中心荷为：

c_1=1,\quad c_2=3,\quad c_3=8

这些中心荷满足：

c_1 + c_2 + c_3 = 12

结论： 边界CS能级的组合  k_1+k_2+k_3=12  正好对应四维引力反常抵消条件的自由度。这不是人为选择—— k_1=1,\ k_2=3,\ k_3=8  由B₃辫子群表示维数唯一决定，其和12是表示论的自然输出。12的中心荷与四维引力反常抵消的代数结构相一致——无需额外调节。

第3章 四维引力反常的拓扑保证

3.1 体空间引力反常的抵消条件

在四维时空中，引力反常的抵消条件是：

\sum_{\text{费米子}} Q_i = 0

由第5.1节的分析（U(1)反常的结构保证），本理论中三代费米子的整体电荷结构满足：

\sum_{\text{所有费米子}} Q_i = 0

因此，四维引力反常被自动抵消。

3.2 体-边界耦合的一致性

体空间的引力反常抵消条件与边界CS理论的框架反常通过  \delta(\Sigma)  项耦合：

\mathcal{A}_{\text{grav}}^{\text{体}} + \delta(\Sigma)\,\mathcal{A}_{\text{grav}}^{\text{边界}} = 0

由于体空间满足  \sum Q=0 ，边界中心荷组合  c_1+c_2+c_3=12  提供匹配的边界补偿，总引力反常在完整的体-边界联合系统中严格为零。
