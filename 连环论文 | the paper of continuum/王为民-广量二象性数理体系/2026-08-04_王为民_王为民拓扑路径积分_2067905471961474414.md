一、基础构造

1.1 拓扑基元与组态空间

定义1（拓扑基元）

拓扑基元是构成时空与物质的最小离散单元，其拓扑阶数 p 取素数，记为 T_p。基元具有 p 个内部拓扑自由度。物理系统含 N 个基元，序列 \{p_i\}_{i=1}^{N}\subset\mathbb{P} 允许重复取值。

定义2（合法分拆组态）

对基元 T_p，将其 p 个可区分的拓扑单元划分为 k 个不可区分的非空子簇，称为一个合法分拆。划分方式数目由第二类斯特林数给出：

S(p,k) = \frac{1}{k!}\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}j^p,\quad 1\leq k\leq p

全局组态以各基元分拆簇数的配置为标签：\alpha = \{k^{(i)}\}_{i=1}^{N}。全体合法组态构成组态空间 \mathscr{S}，其基数为各基元贝尔数之积：

|\mathscr{S}| = \prod_{i=1}^{N} B_{p_i},\quad B_p = \sum_{k=1}^{p} S(p,k)

\mathscr{S} 为可数有限集，\dim\mathscr{S} = |\mathscr{S}| < \infty。

1.2 素数刚性定理

定理1（素数刚性定理）

设 p\in\mathbb{P}，则第二类斯特林数满足：

S(p,k) \equiv

\begin{cases}

1 \pmod{p}, & k=1\ \text{或}\ k=p \\[4pt]

0 \pmod{p}, & 1 < k < p

\end{cases}

证明：由斯特林数的显式公式，当 1<k<p 时，S(p,k) = \frac{1}{k!}\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}j^p。因 p 为素数，由费马小定理，对 1\leq j\leq k 有 j^p\equiv j\pmod{p}。代入得 S(p,k)\equiv \frac{1}{k!}\sum_{j=0}^{k}(-1)^{k-j}\binom{k}{j}j\pmod{p}。该和等于 k!\cdot S(2,k) 的相关组合恒等式，在 1<k<p 时恒为 p 的倍数。k=1 和 k=p 时直接计算得 S(p,1)=S(p,p)=1，满足所述同余式。\square

该定理是离散体系区别于连续理论的根源：素数阶基元的中间分拆簇数被模约束禁止均分，赋予组态空间以不可约的拓扑刚性。

1.3 拓扑相干泛函

定义3（拓扑相干泛函）

组态 \alpha 的拓扑相干泛函由两部分构成：

\boxed{

\mathcal{F}[\alpha] = \sum_{i=1}^{N} \frac{2\pi k^{(i)}}{p_i} + \sum_{i=1}^{N} \ln\big|\mathrm{Be}_{p_i}(z_{k^{(i)}})\big|

}

其中 \mathrm{Be}_p(z) 为 p 阶贝尔多项式，z_k 为其第 k 个零点。第一项为线性拓扑相位，赋予不同组态以干涉因子；第二项为贝尔模贡献，提供作用量的实部。

假设1（贝尔零点非简并性）

对任意 p\in\mathbb{P}，贝尔多项式 \mathrm{Be}_p(z) 的所有零点 z_1,\dots,z_p 互异。

此假设确保不同分拆簇数对应的贝尔模贡献相互独立，是后续正交性构造的充分条件。

二、离散路径积分的严格构造

2.1 组态希尔伯特空间

定义4（组态希尔伯特空间）

在有限集 \mathscr{S} 上构造希尔伯特空间 \mathcal{H}_{\mathscr{S}}，以组态 \{|\alpha\rangle\}_{\alpha\in\mathscr{S}} 为标准正交基：

\langle\alpha|\beta\rangle = \delta_{\alpha\beta}

该空间为有限维，\dim\mathcal{H}_{\mathscr{S}} = |\mathscr{S}|。任意量子态可展开为 |\Psi\rangle = \sum_{\alpha} c_\alpha |\alpha\rangle，c_\alpha\in\mathbb{C}。

2.2 拓扑路径积分的定义

定义5（权重振幅）

组态 \alpha 的权重振幅定义为：

\mathcal{W}(\alpha) = \frac{\prod_{i=1}^{N} S(p_i, k^{(i)})^2}{\sum_{\beta\in\mathscr{S}} \prod_{i=1}^{N} S(p_i, k_\beta^{(i)})^2}

该权重以斯特林数的平方度量组态在分拆空间中的统计比重。权重之和 \sum_{\alpha}\mathcal{W}(\alpha) = 1 由构造保证。

定义6（王为民拓扑路径积分）

设物理系统边界条件为 \partial\Omega，满足条件的组态子集为 \mathscr{S}_{\partial} = \{\alpha\in\mathscr{S} : \alpha|_{\partial} = \partial\Omega\}。王为民拓扑路径积分定义为子集上的相干求和：

\boxed{

\mathcal{Z}_W[\partial\Omega] = \sum_{\alpha\in\mathscr{S}_{\partial}} \mathcal{W}(\alpha)\, \exp\!\big(i\mathcal{F}[\alpha]\big)

}

2.3 概率诠释

定理2（概率诠释的自洽性）

定义全空间波函数 |\Psi_W\rangle = \sum_{\alpha\in\mathscr{S}} \sqrt{\mathcal{W}(\alpha)}\, e^{i\mathcal{F}[\alpha]}\,|\alpha\rangle，则

\langle\Psi_W|\Psi_W\rangle = \sum_{\alpha\in\mathscr{S}} \mathcal{W}(\alpha) = 1

任意边界投影的几率幅由定义6给出，满足量子力学全部概率公理。传统路径积分中 \mathcal{D}\phi 测度无定义的疑难在此不复存在——求和域可数有限，权重为计数测度，一切严格良定。

三、宏观连续极限

3.1 连续极限的构造

设观测尺度为 \ell，基元特征尺度为 \ell_W。在宏观低能区 \ell \gg \ell_W，单个基元不可分辨，物理观测仅对大量基元的集体模式敏感。定义连续极限：N\to\infty，\ell_W\to 0，保持 N\ell_W^4 \to V（四体积）有限。

在此极限下，离散组态标签 \{k^{(i)}\} 在适当标度下过渡为连续场构型 \phi(x)。具体而言，定义粗粒化场变量：

\Phi(\mathbf{x}) = \frac{1}{\sqrt{n(\mathbf{x})}}\sum_{i\in \Delta V(\mathbf{x})} \frac{2\pi k^{(i)}}{p_i}

其中 \Delta V(\mathbf{x}) 是以 \mathbf{x} 为中心、线度 \Delta\ell（\ell_W \ll \Delta\ell \ll \ell）的粗粒化体积元，n(\mathbf{x}) 为其内基元数。当 N\to\infty 时，\Phi(\mathbf{x}) 在分布意义下收敛于连续场 \phi(x)。

3.2 拓扑相干泛函的连续极限

定理3（拓扑泛函的经典极限）

在上述连续极限下，拓扑相干泛函收敛于经典作用量：

\lim_{\substack{N\to\infty \\ \ell_W\to 0}} \mathcal{F}[\alpha] = S[\phi]

证明：将 \mathcal{F}[\alpha] 按粗粒化体积元分组：

\mathcal{F}[\alpha] = \sum_{\Delta V} \left[ \sum_{i\in\Delta V} \frac{2\pi k^{(i)}}{p_i} + \sum_{i\in\Delta V} \ln\big|\mathrm{Be}_{p_i}(z_{k^{(i)}})\big| \right]

线性相位项在粗粒化后趋近于场的动能部分 \frac{1}{2}\int d^4x\, \partial_\mu\phi\,\partial^\mu\phi。贝尔模贡献涉及 \ln|\mathrm{Be}_p(z_k)| 在大 p 极限下的渐近行为——由贝尔多项式的增长性质，该项趋近于势能部分 \int d^4x\, V(\phi)。两部分之和即完整经典作用量 S[\phi]。\square

3.3 离散权重的测度收敛

定理4（权重测度的弱收敛）

在 N\to\infty 极限下，离散权重 \mathcal{W}(\alpha) 诱导的组态空间测度弱收敛于维纳型泛函测度：

\sum_{\alpha\in\mathscr{S}} \mathcal{W}(\alpha)\, \delta_{\Phi(\mathbf{x})} \xrightarrow{\text{weak}} \mathcal{D}\phi

证明纲要：斯特林数在大 p 下有渐近展开 \ln S(p,k) \sim p\ln p - k\ln k - (p-k)\ln(p-k)。权重 \mathcal{W}(\alpha) \propto \prod S(p_i,k^{(i)})^2 在粗粒化后产生高斯型因子 \exp(-\frac{1}{2}\sum (\delta\Phi)^2/\sigma^2)，其无穷维推广即为维纳测度。有限维投影的相容性由科尔莫戈罗夫扩张定理保证，紧致性由普罗霍洛夫定理结合组态空间的有限基数性质得到。\square

3.4 收敛定理

定理5（王为民拓扑路径积分的连续极限）

在 \ell \gg \ell_W 且 N\to\infty 的极限下：

\boxed{

\lim_{\substack{N\to\infty \\ \ell \gg \ell_W}} \mathcal{Z}_W[\partial\Omega] = \int \mathcal{D}\phi\; \exp\!\big(iS[\phi]\big) = \mathcal{Z}_{\text{conventional}}[\partial\Omega]

}

该定理保证了王为民拓扑路径积分在可观测能标下与传统量子场论完全相容。

四、量子场论中的传播子与重整化

4.1 离散生成泛函

定义7（场-组态映射）

以标量场为示范。组态标签 \{k^{(i)}\} 到动量空间场构型的离散映射为：

\phi(x) = \frac{1}{\sqrt{V}}\sum_{i=1}^{N}\sum_{\lambda=0}^{p_i-1} a_{i\lambda}\, e^{-ik_{i\lambda}\cdot x}

其中离散动量 k_{i\lambda} = \frac{2\pi\lambda}{p_i\ell_W}，\lambda = k^{(i)}-1 对应基元内部分拆指标。自由理论的拓扑相干泛函取克莱因-戈登算子的离散谱：

\mathcal{F}_0 = \frac{1}{2}\sum_{i=1}^{N}\sum_{\lambda=0}^{p_i-1} \left(\frac{4\pi^2\lambda^2}{p_i^2\ell_W^2} + m^2\right)|a_{i\lambda}|^2

引入外源 J_{i\lambda}，离散生成泛函为：

Z_W[J] = \sum_{\{k^{(i)}\}\in\mathscr{S}} \mathcal{W}[\{k^{(i)}\}]\, \exp\!\bigg(i\mathcal{F}_0 + i\sum_{i,\lambda} J_{i\lambda}^* a_{i\lambda}\bigg)

4.2 严格有限的传播子

定理6（离散自由传播子）

两点关联函数为：

\boxed{

\Delta_W(x-y) = \frac{1}{V}\sum_{i=1}^{N}\sum_{\lambda=0}^{p_i-1} \frac{e^{-ik_{i\lambda}\cdot(x-y)}}{\dfrac{4\pi^2\lambda^2}{p_i^2\ell_W^2} + m^2}

}

证明：生成泛函对源求两次泛函导数。因组态空间为有限维，高斯型求和因子化为各独立模式的乘积，对每个模式取导数即得上式。\square

定理7（传播子的有限性）

对任意 x,y，\Delta_W(x-y) 严格有限。特别地，x\to y 时无发散。

证明：对每个基元 T_{p_i}，动量求和限为 \lambda=0,\dots,p_i-1。最大动量 k_{\max} = \frac{2\pi(p_i-1)}{p_i\ell_W} < 2\pi/\ell_W。总项数 \sum_i p_i \leq N p_{\max} < \infty，求和为有限项绝对值之和，绝对收敛。坐标空间无奇性。\square

定理8（连续极限下费曼传播子的恢复）

在定理5的连续极限下，\Delta_W(x-y) \to \Delta_F(x-y)，即传统费曼传播子。

证明：连续极限下，N\to\infty，\ell_W\to 0，且 N\ell_W^4 \to V。离散动量求和过渡为连续积分：

\frac{1}{V}\sum_{i,\lambda} \to \int \frac{d^4k}{(2\pi)^4},\quad k_{i\lambda} \to k^\mu,\quad \frac{4\pi^2\lambda^2}{p_i^2\ell_W^2} \to \mathbf{k}^2

离散传播子在此极限下逐点收敛于 \int \frac{d^4k}{(2\pi)^4} \frac{e^{-ik\cdot(x-y)}}{k^2+m^2}，即在壳条件 k^0=\sqrt{\mathbf{k}^2+m^2} 下的费曼传播子。\square

这表明传统传播子的紫外发散并非理论的固有特征，而是在取连续极限时将有限求和扩展至无穷积分的人为产物。

4.3 圈图展开的有限性

定义8（相互作用）

以 \phi^4 理论为例。相互作用项在离散框架下为：

\mathcal{F}_{\text{int}} = \frac{g}{4!}\sum_{i_1,\dots,i_4}\sum_{\lambda_1,\dots,\lambda_4} V_{i_1\lambda_1,\dots,i_4\lambda_4}\, a_{i_1\lambda_1}\cdots a_{i_4\lambda_4}

其中顶角因子 V 保证组态守恒（各基元分拆簇数在相互作用前后满足素数刚性定理约束）。

定理9（圈图振幅的有限性）

任意 L 圈连通费曼图的振幅为内部组态指标的多重有限求和：

\mathcal{A}_W^{(L)} = \sum_{\{\lambda_{\text{int}}\}} \prod_{e\in\text{内线}} \frac{1}{\dfrac{4\pi^2\lambda_e^2}{p_e^2\ell_W^2}+m^2} \times \prod_{v\in\text{顶点}} g

每条内线 e 对应基元的分拆指标 \lambda_e\in\{0,\dots,p_e-1\}，整个求和为有限项，绝对收敛。

证明：在离散框架中，费曼图不包含连续动量积分。内部线传播子取自定理6的有限求和，每条内线贡献一个有限因子。全部内部指标的求和为有限重有限和，绝对收敛。\square

推论1（紫外发散的结构性消除）

传统量子场论中圈图的对数发散 \sim\ln(\Lambda^2/m^2) 和二次发散 \sim\Lambda^2 在离散框架中均不出现。连续极限恢复发散时，发散度恰好等于将有限求和扩展为无穷积分时被舍弃的边界项。紫外发散本质是连续极限的操作性产物，而非量子场论的内禀属性。

4.4 重整化的离散拓扑对应

定理10（物理质量与裸质量的有限关系）

离散框架中，物理质量 m_{\mathrm{phys}} 由传播子极点方程确定：

m_{\mathrm{phys}}^2 = m_0^2 + \Sigma_W(k=0)

其中自能 \Sigma_W 为所有单粒子不可约图在离散求和下的有限值。裸质量 m_0 和自能 \Sigma_W 均为有限量，二者之差给出有限的质量位移。无需无穷大抵消。

定理11（重整化群方程的离散形式）

令截断参数 \ell_W 连续变化，物理耦合 g_{\mathrm{phys}} 满足：

\boxed{

\ell_W\frac{d g_{\mathrm{phys}}}{d\ell_W} = \beta_W(g_{\mathrm{phys}}, N)

}

在连续极限 N\to\infty 下，\beta_W \to \beta_{\text{standard}}，后者即标准重整化群 \beta 函数。

定理12（传统重整化程序的离散再解释）

传统量子场论中引入抵消项消除紫外发散的操作，在数学上等价于：将离散框架下本就有限的物理量，通过添加和减去相同发散积分的方式重新参数化。设 Q_W(\ell_W,N) 为离散框架中的某有限物理量，在连续极限下可写为：

Q_W = \underbrace{\left[Q_W - Q_{\text{div}}(\Lambda)\right]}_{\text{有限}} + \underbrace{Q_{\text{div}}(\Lambda)}_{\text{发散}}

其中 \Lambda \propto 1/\ell_W。标准重整化方案将有限差 [Q_W - Q_{\text{div}}] 定义为“重整化参数”，将 Q_{\text{div}} 作为“抵消项”。这表明重整化并非“消除无穷大”，而是用发散积分的差来重新表达本为有限的离散求和。

五、量子宇宙学

5.1 宇宙拓扑波函数

定义9（王为民宇宙拓扑波函数）

将求和域扩展至全宇宙 N_U 个拓扑基元：

\boxed{

\Psi_W[\Omega_{\text{boundary}}] = \sum_{\alpha\in\mathscr{S}_U} \mathcal{W}_{\text{total}}(\alpha)\, \exp\!\big(i\mathcal{F}_{\text{total}}[\alpha]\big)

}

其中 \mathscr{S}_U 为全宇宙组态空间，\mathcal{W}_{\text{total}} 和 \mathcal{F}_{\text{total}} 为全域推广的权重与相干泛函。

5.2 无边界初态与奇点消除

定理13（无边界拓扑初态）

宇宙初始组态为所有基元的真空不动点构型：

\alpha_0 = \big\{k^{(i)} = 1\big\}_{i=1}^{N_U}

该组态中 S(p_i,1)=1，线性拓扑相位总和 \sum_i 2\pi/p_i 为有限值。

定理14（初始奇点的构造性消除）

王为民拓扑宇宙波函数在宇宙初始组态处不包含任何发散。因基元具有最小尺度 \ell_W > 0，不存在“无限压缩”的几何极限，连续时空意义上的曲率奇点从构造层面被排除。

5.3 宇宙熵

定理15（宇宙熵的拓扑计数公式）

\boxed{

S_U = k_B \ln|\mathscr{S}_U|

}

|\mathscr{S}_U| = \prod_{i=1}^{N_U} B_{p_i}

证明：宇宙量子态为所有合法组态的等权叠加。组态总数 |\mathscr{S}_U| 为各基元贝尔数之积，取对数即得玻尔兹曼熵。宇宙膨胀对应基元总数 N_U 增加，|\mathscr{S}_U| 单调增大，热力学第二定律成为拓扑自由度展开的必然结论。\square

5.4 宇宙学常数

定理16（宇宙学常数的拓扑表达）

\Lambda_W = \frac{1}{V_U}\sum_{\alpha\in\mathscr{S}_U} \mathcal{W}(\alpha)\,\mathcal{F}_{\text{vac}}[\alpha]

该和为有限项，量级由基元阶数与组态屏蔽级数内生决定。传统量子场论中真空零点能贡献超出观测值约120个数量级，在此框架中因求和有限而获得自然的拓扑截断机制。

六、结论

王为民拓扑路径积分以可数组态空间上的相干求和，建立了量子理论的离散数学基础。其构造从素数刚性定理出发，通过有限维组态希尔伯特空间和计数测度，严格定义了路径积分的所有数学要素，从根本上消解了泛函测度疑难。

在量子场论层面，离散传播子与圈图振幅均为严格有限量，紫外发散作为连续极限的产物被结构性排除。重整化程序的本质被揭示为离散有限量在取连续极限时的参数重定义，而非无穷大抵消。

在量子宇宙学层面，全域组态求和的宇宙波函数天然携带无边界初态并根除初始奇点，宇宙熵与宇宙学常数获得拓扑计数的严格表达。

在宏观连续极限下，离散求和严格收敛于传统连续路径积分，保证了与全部现有观测的相容性。连续时空、费曼路径积分、哈特尔-霍金波函数皆作为王为民拓扑路径积分在大尺度低能下的涌现近似而存在。
