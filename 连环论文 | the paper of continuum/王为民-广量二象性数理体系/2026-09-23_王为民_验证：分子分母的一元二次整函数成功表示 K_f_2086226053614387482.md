一、验证目标

\boxed{

\text{验证：}K_f=\frac{N_f(T)}{D_f(T)}\text{ 可用一元二次整函数表示。}

}

---

二、三类粒子的二次整函数

2.1 上型夸克

\boxed{

N^{\rm up}(T)=-26T^2+121T-89

}

\boxed{

D^{\rm up}(T)=11T^2-41T+53

}

系数均为整数。

2.2 下型夸克

\boxed{

N^{\rm down}(T)=12T^2-30T+40

}

\boxed{

D^{\rm down}(T)=21T^2-85T+103

}

系数均为整数。

2.3 轻子

\boxed{

N^{\rm lep}(T)=\frac{-13T^2+25T+46}{2}

}

\boxed{

D^{\rm lep}(T)=\frac{-149T^2+589T-420}{2}

}

分子分母分别乘以 2，得到整函数比值：

\boxed{

K^{\rm lep}(T)=\frac{-13T^2+25T+46}{-149T^2+589T-420}

}

分子分母均为整系数二次多项式。

四、验证结论

\boxed{

\begin{array}{l}

\textbf{验证成功：}\\

\quad\bullet\ K_f\text{ 可用一元二次整函数之比表示；}\\

\quad\bullet\ \text{上型、下型的分子分母均为整系数二次多项式；}\\

\quad\bullet\ \text{轻子可化为整系数二次多项式之比；}\\

\quad\bullet\ \text{在定义域 }T\in\{1,2,3\}\text{ 上全部精确成立。}

\end{array}}

---

五、验证的意义与局限

5.1 正面意义

\boxed{

\begin{array}{l}

\bullet\ \text{函数形式简洁：有理二次函数；}\\

\bullet\ \text{系数为整数，无自由参数；}\\

\bullet\ \text{定义域内精确匹配全部数据。}

\end{array}}

5.2 局限

\boxed{

\begin{array}{l}

\textbf{局限一：这是插值，不是推导。}\\

\quad \text{3 个数据点唯一确定一个二次多项式；}\\

\quad \text{系数不由公理导出，由数据拟合确定。}\\[4pt]

\textbf{局限二：外推失效。}\\

\quad T=4\text{ 时上型给出 }N=-21\text{，负质量，无意义。}\\[4pt]

\textbf{局限三：无法区分中微子与带电轻子。}\\

\quad \text{两者同属 lep 类，函数给出相同 }K_f。

\end{array}}

---

六、方法论定位

\boxed{

\begin{array}{l}

\textbf{结论：}\\

\quad\bullet\ \text{数学上，一元二次整函数成功表示了 }K_f；\\

\quad\bullet\ \text{这是精确的插值表示；}\\

\quad\bullet\ \text{但插值不等于理论推导。}\\[4pt]

\textbf{理论定位：}\\

\quad \text{这验证了“存在简单函数表示”这一事实；}\\

\quad \text{但没有回答“为什么是这个函数”。}

\end{array}}
