摘要

BPS 孤子是 1975–1976 年由 Bogomolny、Prasad 与 Sommerfield 发现的特殊孤子解。其核心特征是：势能可写成超势的平方，二阶孤子方程约化为一阶，能量等于中心荷绝对值 E=|Z|，自动稳定且保持部分超对称。本文系统阐明 BPS 孤子的定义、能量下界、稳定性与物理意义，并给出王为民拓扑超大统一理论中的具体形式：BPS 孤子对应缠绕格点势 V_n，其能量决定粒子质量的层级结构。

关键词： BPS 孤子；超势；中心荷；缠绕格点势；王为民质量谱

一、引言

孤子是场论中一类拓扑非平凡的稳定解。一般孤子方程是二阶的，求解困难，稳定性需要额外论证。

1975 年，Prasad 与 Sommerfield 发现了一类特殊孤子解；1976 年，Bogomolny 给出了一般性论证。此类孤子后来被称为 BPS 孤子。

BPS 孤子的核心特征是：

\boxed{

\text{满足一阶方程，能量等于中心荷绝对值，自动稳定。}

}

在王为民拓扑超大统一理论中，BPS 孤子是连接公理Ⅰ（B_3 拓扑代数）与公理Ⅱ（体场孤子动力学）的关键对象：其能量即缠绕格点势 V_n，决定粒子质量的层级。

二、从二阶到一阶：BPS 条件的提出

2.1 一般孤子方程

静态孤子满足：

\frac{d^2\Phi}{dx^2}=V'_{\rm bulk}(\Phi)

边界条件：

\Phi(-\infty)=-v,\qquad \Phi(+\infty)=+v

这是二阶非线性方程，一般无解析解。

2.2 超势分解

若体场势可写成超势 W(\Phi) 的平方：

\boxed{

V_{\rm bulk}(\Phi)=\frac12\left(W'(\Phi)\right)^2

}

则二阶方程可约化为一阶 BPS 方程：

\boxed{

\frac{d\Phi}{dx}=W'(\Phi)

}

2.3 验证

对 BPS 方程求导：

\frac{d^2\Phi}{dx^2}=W''W'=\frac{d}{d\Phi}\left(\frac12 W'^2\right)=V'_{\rm bulk}

自动满足原二阶方程。

\boxed{

\text{BPS 方程} \Longrightarrow \text{二阶孤子方程}

}

---

三、BPS 界：能量下界

3.1 能量积分

孤子能量：

E=\int_{-\infty}^{+\infty}\left[\frac12\left(\frac{d\Phi}{dx}\right)^2+V_{\rm bulk}(\Phi)\right]dx

3.2 BPS 重构

由 V=\frac12 W'^2：

E=\int_{-\infty}^{+\infty}\left[\frac12\left(\frac{d\Phi}{dx}\right)^2+\frac12 W'^2\right]dx

配方：

E=\int_{-\infty}^{+\infty}\frac12\left(\frac{d\Phi}{dx}-W'\right)^2dx+\int_{-\infty}^{+\infty}W'\frac{d\Phi}{dx}dx

3.3 拓扑项

第二项是拓扑项：

\int_{-\infty}^{+\infty}W'\frac{d\Phi}{dx}dx=\int_{-v}^{+v}W'd\Phi=W(+v)-W(-v)=|Z|

其中 Z 是中心荷。

3.4 BPS 界

第一项非负，因此：

\boxed{

E\ge|Z|

}

当且仅当 d\Phi/dx=W' 时等号成立。

\boxed{

E_{\rm BPS}=|Z|

}

BPS 孤子就是达到能量下界的孤子。

四、BPS 孤子的性质

\boxed{

\begin{array}{l}

\bullet\ \text{满足一阶方程，而非二阶；}\\

\bullet\ \text{能量等于中心荷绝对值：}E=|Z|；\\

\bullet\ \text{自动稳定，无需额外论证；}\\

\bullet\ \text{保持部分超对称；}\\

\bullet\ \text{能量只依赖拓扑荷，不依赖解的具体形状。}

\end{array}}

4.1 稳定性

一般孤子的稳定性需要证明无非负模。BPS 孤子自动稳定，因为：

E=|Z|

是能量下界，无法再降低。

4.2 超对称

BPS 态保持部分超对称：

Q|\text{BPS}\rangle=0\quad\text{（部分超荷）}

4.3 形状无关性

E_{\rm BPS}=|Z|

只依赖 \Phi(\pm\infty) 的值，不依赖中间剖面的具体形状。

五、中心荷的定义

5.1 中心荷

\boxed{

Z=W(\Phi(+\infty))-W(\Phi(-\infty))

}

对 kink 孤子 \Phi(\pm\infty)=\pm v：

Z=W(+v)-W(-v)

5.2 与拓扑荷的关系

拓扑荷：

n=\frac{\Phi(+\infty)-\Phi(-\infty)}{2v}

BPS 孤子的中心荷正比于拓扑荷。

\boxed{

Z\propto n

}

5.3 超对称代数中的中心荷

在扩展超对称代数中，中心荷 Z^{ij} 满足：

\{Q^i_\alpha,\bar Q^j_{\dot\beta}\}=2\sigma^\mu_{\alpha\dot\beta}P_\mu\delta^{ij}+2i\epsilon_{\alpha\beta}Z^{ij}

Z^{ij} 与所有超荷对易，属于超对称代数的中心。

六、王为民理论中的 BPS 孤子

6.1 公理Ⅱ的 BPS 超势

\boxed{

W'(\Phi)=\frac{m_H}{\sqrt2}(\Phi^2-v^2)\lambda_-^{\binom{T}{2}}

}

其中：

· T 为代数；

· \lambda_-=\frac{3-\sqrt5}{2} 为王为民特征方程 IR 分支；

· \binom{T}{2} 为融合树内部节点数。

6.2 BPS 方程

\frac{d\Phi_T}{dx}=\frac{m_H}{\sqrt2}(\Phi_T^2-v^2)\lambda_-^{\binom{T}{2}}

6.3 解析解

分离变量：

\int\frac{d\Phi_T}{\Phi_T^2-v^2}=\frac{m_H}{\sqrt2}\lambda_-^{\binom{T}{2}}\int dx

积分：

\frac{1}{2v}\ln\frac{v-\Phi_T}{v+\Phi_T}=\frac{m_H}{\sqrt2}\lambda_-^{\binom{T}{2}}(x-x_0)

反解：

\boxed{

\Phi_T(x)=v\tanh\left(\frac{m_H v}{\sqrt2}\lambda_-^{\binom{T}{2}}(x-x_0)\right)

}

这是标准的 kink 解。

6.4 边界条件

\Phi_T(-\infty)=-v,\qquad \Phi_T(+\infty)=+v

拓扑荷：

n=\frac{\Phi(+\infty)-\Phi(-\infty)}{2v}=1

6.5 中心荷

Z_T=W(+v)-W(-v)=-\frac{4m_H}{3\sqrt2}v^3\lambda_-^{\binom{T}{2}}

取绝对值：

\boxed{

|Z_T|=\frac{2\sqrt2}{3}m_H v^3\lambda_-^{\binom{T}{2}}

}

6.6 BPS 能量

E_T=|Z_T|=\frac{2\sqrt2}{3}m_H v^3\lambda_-^{\binom{T}{2}}

即缠绕格点势：

\boxed{

V_n=\frac{2\sqrt2}{3}m_H v^3\lambda_-^{\binom{n}{2}}

}
