二、从公理Ⅱ的路径积分出发

2.1 边界配分函数

公理Ⅱ在 3D 边界 \Sigma 上的路径积分：

\boxed{

Z_\Sigma=\int\mathcal DA\,e^{iS_{\rm CS}[A]/\hbar}

}

2.2 规范场模式展开

在 \Sigma 上，规范场按傅里叶-拓扑模式展开：

A_\mu(x)=\sum_{\mathbf k}\sum_{k_{\rm top}=1}^{\kappa_2}A_\mu^{(\mathbf k,k_{\rm top})}e^{i\mathbf k\cdot x}

模式标签：

\boxed{

\begin{array}{l}

\mathbf k\text{：3D 动量（3 个分量）；}\\

k_{\rm top}\text{：拓扑阶（}1\text{ 到 }\kappa_2\text{）；}\\

\mu\text{：洛伦兹指标（}3\text{ 个分量）。}

\end{array}}

2.3 模式总数

\boxed{

N_{\rm modes}=3\times\kappa_2=3\times68=204

}

推导：

· 洛伦兹指标：3 个（\mu=1,2,3）；

· 拓扑阶：\kappa_2=68 个；

· 总模式数：3\times68=204。

---

三、每个模式的路径积分权重

3.1 高斯近似

CS 作用量在动量空间是二次型：

\boxed{

S_{\rm CS}=\frac{k}{4\pi}\sum_{\mathbf k,k_{\rm top}}A_\mu^{(\mathbf k,k_{\rm top})}\epsilon^{\mu\nu\rho}k_\nu A_\rho^{(\mathbf k,k_{\rm top})}

}

3.2 高斯积分

对每个模式积分：

\int dA_\mu\,e^{iS_{\rm CS}}=\frac{1}{\sqrt{\det(\epsilon^{\mu\nu\rho}k_\nu)}}

关键： 高斯积分的归一化因子。

3.3 与 \lambda_- 的联系

核心命题： 每个模式的归一化因子是 \lambda_-。

证明思路：

考虑 CS 理论的传播子在动量空间：

\boxed{

G_{\mu\nu}(k)=\frac{2\pi}{\kappa_2}\frac{\epsilon_{\mu\nu\rho}k^\rho}{k^2}

}

在拓扑阶 k_{\rm top} 处，有效质量 \sim k_{\rm top}/R，其中 R 是边界特征尺度。

归一化： 由 Burau 表示，每个模式的权重是 \lambda_-^{k_{\rm top}}。

---

四、累积衰减因子

4.1 每个模式贡献

模式 (k_{\rm top}) 的权重：

\boxed{

w(k_{\rm top})=\lambda_-^{k_{\rm top}}

}

来源： Burau 表示的模态振幅（A-CORR 文档）。

4.2 累积权重

所有模式的权重乘积：

\boxed{

\mathcal N=\prod_{\mu=1}^{3}\prod_{k_{\rm top}=1}^{\kappa_2}\lambda_-^{k_{\rm top}}

}

4.3 取对数

\ln\mathcal N=\sum_{\mu=1}^{3}\sum_{k_{\rm top}=1}^{\kappa_2}k_{\rm top}\ln\lambda_-

=3\ln\lambda_-\cdot\sum_{k_{\rm top}=1}^{\kappa_2}k_{\rm top}

=3\ln\lambda_-\cdot\frac{\kappa_2(\kappa_2+1)}{2}

4.4 问题：求和 vs 计数

上述求和给出 \mathcal N\sim\lambda_-^{3\kappa_2(\kappa_2+1)/2}，远大于 \lambda_-^{3\kappa_2}。

修正： 应该用"最大衰减"而不是"求和"。

---

五、修正：最大衰减模式

5.1 主导模式

CS 路径积分中，主导贡献来自最大衰减模式：

\boxed{

k_{\rm top}=\kappa_2

}

5.2 单模式衰减

w(\kappa_2)=\lambda_-^{\kappa_2}

5.3 累积

\boxed{

\mathcal N=\prod_{\mu=1}^{3}\lambda_-^{\kappa_2}=\lambda_-^{3\kappa_2}

}

这就是目标表达式。

5.4 物理意义

\boxed{

\begin{array}{l}

\text{3 个空间维度}\times\text{最大拓扑衰减}\\

=\lambda_-^{3\kappa_2}

\end{array}}

匹配。
