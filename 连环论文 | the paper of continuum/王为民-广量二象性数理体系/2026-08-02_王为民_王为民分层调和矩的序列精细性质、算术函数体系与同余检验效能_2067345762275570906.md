摘要

本文在王为民分层调和矩基础理论与通用同余定理的框架下，从三个方向完成系统性深化研究。其一，针对梅森数、费马数、分圆多项式三类经典特殊序列，推导分层强同余结论，给出素性与半素性的强化必要判据，明确平方自由前提的边界与Wieferich型素数的内在关联；其二，将分层构造推广至一般算术函数，建立分层常函数、分层调和矩、分层莫比乌斯函数、分层欧拉函数的生成函数体系，证明其正交关系、变换恒等式与二项式反演公式，形成自洽的分层算术函数代数；其三，定量分析分层同余检验算法的校验效能，通过典型数值算例验证其在整数分解后结构一致性校验中的实用价值。本文所有定理均给出严格证明，明确标注适用前提与边界。

关键词：王为民分层调和矩；特殊整数序列；分层算术函数；同余检验；Wieferich素数

一、引言

按素因子个数对整数约数集进行分层刻画的思想，催生了王为民分层调和矩的概念。前期工作已建立其初等代数恒等式、通用递推方程与通用同余定理，并初步应用于梅森数、费马数等经典序列，形成了基础理论框架[1-2]。但现有研究仍存在三方面可深化空间：一是特殊序列的分层性质尚未充分挖掘，强同余约束与素性判据的关联有待明确；二是分层构造未推广至一般算术函数，缺乏完整的函数恒等式体系；三是分层同余检验的实际效能缺乏定量分析，适用场景的边界不够清晰。

针对上述问题，本文完成三项核心工作：

1. 序列性质深化：结合乘法阶经典性质，推导梅森数、费马数的分层强同余定理与强化结构判据；阐明分圆多项式场景下平方自由前提与Wieferich素数的内在关联，划定清晰的适用边界。

2. 函数体系构建：将分层调和矩推广为一般分层算术函数，系统给出四类基本函数的生成函数、正交关系与二项式反演公式，构建完整的分层算术函数代数框架。

3. 检验效能量化：通过典型算例定量验证分层同余检验的约束强度，明确其作为分解后结构一致性校验工具的核心定位与实用价值。

二、预备知识

2.1 分层调和矩的核心定义

设 n 为正整数，\omega(d) 表示正整数 d 所含不同素因子的个数。k 阶王为民分层调和矩定义为所有恰好含 k 个不同素因子的正约数之和：

B_{W,k}^\star(n) = \sum_{\substack{d \mid n \\ \omega(d)=k}} d

约定边界条件：B_{W,0}^\star(n)=1；当 k>\omega(n) 时，B_{W,k}^\star(n)=0。

由定义直接可得约数和的分层分解恒等式，该式对全体正整数无条件成立：

\sigma(n) = \sum_{k=0}^{\omega(n)} B_{W,k}^\star(n)

2.2 通用同余定理

设 N 为平方自由正整数，记 t=\omega(N)。若 N 的所有素因子均满足 q \equiv 1 \pmod{m}，则对任意非负整数 k，有

B_{W,k}^\star(N) \equiv \binom{t}{k} \pmod{m}

其约数和满足 \sigma(N) \equiv 2^t \pmod{m}。该定理是本文序列性质与检验算法的核心理论基础。

三、经典特殊序列的分层精细同余性质

通用同余定理结合各类序列的素因子专属约束，可得到更强的分层同余结论与更具针对性的结构判据。本章所有结论默认限定于平方自由情形。

3.1 梅森数的分层强同余与素性判据

设 p 为奇素数，梅森数定义为 M_p = 2^p - 1。由乘法阶基本性质，其任意素因子均满足强同余约束。

定理3.1（梅森数分层强同余定理）

若平方自由梅森数 M_p 含有 t 个不同素因子，则对任意非负整数 k，有

B_{W,k}^\star(M_p) \equiv \binom{t}{k} \pmod{2p}

证明：设素数 q \mid M_p，由乘法阶性质，2在模 q 下的乘法阶为 p，故 p \mid q-1，即存在整数 k 使得 q = kp + 1。

由于 p 是奇素数，q 为奇素数，故 q \equiv 1 \pmod{2}，因此 kp 必为偶数；结合 p 为奇数可得 k 必为偶数，记 k=2m，代入得 q=2mp+1，即 q \equiv 1 \pmod{2p}。

因 M_p 的全体素因子均满足上述同余关系，代入通用同余定理即得结论。

推论3.1（梅森素性强化判据）

若 M_p 为素数，则其约数和满足

\sigma(M_p) = 2^p \equiv 2 \pmod{2p}

该式等价于 2^{p-1} \equiv 1 \pmod{p}，与费马小定理完全一致，验证了判据的自洽性。

命题3.1（梅森数素性的一阶否定判据）

若平方自由梅森数 M_p 的一阶分层调和矩满足 B_{W,1}^\star(M_p) \equiv c \pmod{2p}，则其素因子个数 t \equiv c \pmod{2p}。特别地，若 c \not\equiv 1 \pmod{2p}，则 M_p 必为合数。

注：该判据仅能证伪合数，不能证明素数；一阶矩模 2p 余1仅说明素因子个数模 2p 余1，不代表 M_p 为素数。

3.2 费马数的分层2-adic同余与半素判定

设 n 为非负整数，费马数定义为 F_n = 2^{2^n} + 1。当 n \ge 2 时，其素因子满足更高阶的2-adic同余约束。

定理3.2（费马数分层2-adic同余定理）

设 n \ge 2，若平方自由费马数 F_n 含有 t 个不同素因子，则对任意 0 \le k \le t，有

B_{W,k}^\star(F_n) \equiv \binom{t}{k} \pmod{2^{n+2}}

其约数和满足 \sigma(F_n) \equiv 2^t \pmod{2^{n+2}}。

证明：若素数 q \mid F_n，则2在模 q 下的乘法阶为 2^{n+1}，故 2^{n+1} \mid q-1；结合二次互反律可进一步加强为 2^{n+2} \mid q-1，即 q \equiv 1 \pmod{2^{n+2}}。代入通用同余定理即得结论。

推论3.2（费马数半素判定必要条件）

若 F_n 为半素数（两个不同素因子的乘积），则

\sigma(F_n) \equiv 4 \pmod{2^{n+2}}

即 \sigma(F_n)/4 必为奇数。该条件计算代价极低，可作为大费马数半素性猜想的快速校验工具。

3.3 分圆多项式的平方自由边界与Wieferich素数关联

分圆多项式是梅森数与费马数的共同推广，n 次分圆多项式 \Phi_n(a) 满足恒等式 a^n - 1 = \prod_{d \mid n} \Phi_d(a)。其非本原因子均满足 q \equiv 1 \pmod{n}，但平方自由性并非天然成立，而是与Wieferich型素数深度绑定。

定义3.1

若素数 p 满足 a^{p-1} \equiv 1 \pmod{p^2}，则称 p 为底数 a 的Wieferich素数。

命题3.2

素数 p 是 \Phi_n(a) 的平方因子，当且仅当 p 是底数 a 的Wieferich素数，且 a 在模 p 下的乘法阶恰好为 n。

证明：

- 必要性：若 p^2 \mid \Phi_n(a)，则 a^n \equiv 1 \pmod{p^2}，且 n 是满足该式的最小正整数，故 n \mid p-1，进而 a^{p-1} \equiv 1 \pmod{p^2}，即 p 为底数 a 的Wieferich素数。

- 充分性：若 p 是底数 a 的Wieferich素数且乘法阶为 n，则 a^n \equiv 1 \pmod{p^2}，且对任意 d<n 均有 a^d \not\equiv 1 \pmod{p}，故 p^2 \mid \Phi_n(a)。

该结论明确了通用同余定理在分圆多项式上的适用边界。以底数2为例，目前已知的Wieferich素数仅有1093和3511，对应次数的分圆多项式值存在平方因子；其余绝大多数情形下，平方自由假设成立。

四、分层算术函数的恒等式体系

将分层调和矩的构造思想推广至一般算术函数，可得到一套结构清晰、恒等式丰富的分层算术函数体系。本章所有结论均在平方自由整数范围内成立。

4.1 四类基本分层函数的生成函数

设 n 为平方自由正整数，\omega(n)=t，其不同素因子为 q_1, q_2, \dots, q_t。对四类经典算术函数进行分层分解，可得到显式的生成函数表达式：

1. 分层常函数：对常函数 f(d)=1 分层，1_k(n) = \sum_{\substack{d \mid n \\ \omega(d)=k}} 1 = \binom{t}{k}，生成函数为

I_n(x) = \sum_{k=0}^t \binom{t}{k} x^k = (1+x)^t

2. 分层调和矩：对恒等函数 f(d)=d 分层，即王为民分层调和矩，生成函数为

G_n(x) = \sum_{k=0}^t B_{W,k}^\star(n) x^k = \prod_{i=1}^t (1 + q_i x)

3. 分层莫比乌斯函数：对莫比乌斯函数 \mu(d) 分层，\mu_k(n) = \sum_{\substack{d \mid n \\ \omega(d)=k}} \mu(d) = (-1)^k \binom{t}{k}，生成函数为

M_n(x) = \sum_{k=0}^t (-1)^k \binom{t}{k} x^k = (1-x)^t

4. 分层欧拉函数：对欧拉函数 \phi(d) 分层，\phi_k(n) = \sum_{\substack{d \mid n \\ \omega(d)=k}} \phi(d)，生成函数为

\Phi_n(x) = \prod_{i=1}^t \left(1 + (q_i - 1) x\right)

4.2 生成函数的正交与变换关系

通过生成函数的代数运算，可直接推导各类分层函数之间的恒等式。

定理4.1（分层莫比乌斯与常函数的正交性）

对任意平方自由数 n，分层常函数与分层莫比乌斯函数的生成函数满足

I_n(x) \cdot M_n(x) = (1-x^2)^t

对应系数层面的恒等式：对任意 0 \le k \le t，有

\sum_{i=0}^k 1_i(n) \cdot \mu_{k-i}(n) =

\begin{cases}

(-1)^{k/2} \dbinom{t}{k/2}, & k \text{ 为偶数} \\

0, & k \text{ 为奇数}

\end{cases}

证明：分层常函数的生成函数为 I_n(x)=(1+x)^t，分层莫比乌斯函数的生成函数为 M_n(x)=(1-x)^t，二者相乘得

I_n(x) \cdot M_n(x) = (1+x)^t(1-x)^t = (1-x^2)^t.

将右端展开为幂级数：\displaystyle (1-x^2)^t = \sum_{j=0}^t (-1)^j \binom{t}{j} x^{2j}，仅含偶次幂项。

左端乘积的 x^k 次项系数为卷积和 \displaystyle \sum_{i=0}^k 1_i(n) \cdot \mu_{k-i}(n) = \sum_{i=0}^k (-1)^{k-i} \binom{t}{i}\binom{t}{k-i}，与右端展开式的 x^k 系数完全对应：

- 当 k 为奇数时，右端无对应次项，系数为0；

- 当 k 为偶数时，记 k=2j，系数为 (-1)^j \dbinom{t}{j}。

结论得证。

定理4.2（分层欧拉与分层调和矩的变换关系）

分层欧拉函数的生成函数可通过分层调和矩的生成函数表示为：

\Phi_n(x) = G_n(x) \cdot \prod_{i=1}^t \frac{1 + (q_i - 1)x}{1 + q_i x}

特别地，令 x=1 可得全层和性质：

\sum_{k=0}^t \phi_k(n) = \Phi_n(1) = \prod_{i=1}^t q_i = n

与经典欧拉函数约数和恒等式 \sum_{d \mid n}\phi(d)=n 完全自洽。

4.3 分层序列的二项式反演

对于任意定义在 0 \le k \le t 上的分层序列，纯组合层面的二项式反演无条件成立，是分层函数运算的核心工具。

定理4.3（二项式反演公式）

设 \{f_k\}, \{g_k\} 为两组长度为 t+1 的序列，则以下两个命题等价：

1. 对所有 0 \le k \le t，\displaystyle g_k = \sum_{i=0}^k \binom{k}{i} f_i

2. 对所有 0 \le k \le t，\displaystyle f_k = \sum_{i=0}^k (-1)^{k-i} \binom{k}{i} g_i

证明：将1式代入2式右端，交换求和顺序得

\sum_{i=0}^k (-1)^{k-i} \binom{k}{i} \sum_{j=0}^i \binom{i}{j} f_j = \sum_{j=0}^k f_j \sum_{i=j}^k (-1)^{k-i} \binom{k}{i} \binom{i}{j}.

利用组合恒等式 \dbinom{k}{i} \dbinom{i}{j} = \dbinom{k}{j} \dbinom{k-j}{i-j}，内层和可化为

\binom{k}{j} \sum_{m=0}^{k-j} (-1)^m \binom{k-j}{m} = \binom{k}{j} (1-1)^{k-j}.

当 j<k 时该式为0，当 j=k 时等于1，因此等式右端化简为 f_k，反演成立。

五、分层同余检验的效能量化分析

分层同余检验的核心价值在于，利用整数的全部素因子分解结果，快速验证其是否满足序列对应的素因子同余约束与平方自由假设，是因子分解后的高效结构一致性校验工具。本章所有算例均基于平方自由前提。

5.1 算法基本流程

输入：待检验整数 N、同余模 m、N 的全部素因子列表、检验阶数上限 K

输出：结构一致性校验结果（通过/不通过），以及匹配的素因子个数候选值

1. 前提校验：确认 N 所属序列满足素因子一致同余约束，确认平方自由假设或已完成幂次修正。

2. 矩值计算：根据全部素因子，计算前 K 阶分层调和矩的模值 c_1, c_2, \dots, c_K。

3. 联立检验：对候选值 t=1,2,\dots,K，逐一验证 \dbinom{t}{k} \equiv c_k \pmod{m}，保留满足所有阶数条件的 t。

4. 结果输出：若存在唯一匹配的 t 且与实际素因子个数一致，则校验通过；否则校验不通过，提示分解结果可能存在错误。

5.2 梅森数场景算例

取梅森数 M_{11} = 2047 = 23 \times 89，同余模取强化模 m=22，真实素因子个数 t=2。

已知全部素因子为23和89，计算各阶矩的模值：

- 一阶矩：B_{W,1}^\star = 23 + 89 = 112，112 \equiv 2 \pmod{22}

- 二阶矩：B_{W,2}^\star = 23 \times 89 = 2047，2047 \equiv 1 \pmod{22}

联立检验：

- t=1 时，\binom{1}{1}=1 \not\equiv 2 \pmod{22}，不通过

- t=2 时，\binom{2}{1}=2，\binom{2}{2}=1，全部匹配，校验通过

结论：两阶联检可唯一确定素因子个数为2，与分解结果一致，验证了分解的结构一致性。

5.3 费马数场景算例

取费马数 F_5 = 4294967297 = 641 \times 6700417，同余模取加强模 m=128，真实素因子个数 t=2。

已知全部素因子为641和6700417，二者均满足 q \equiv 1 \pmod{128}，计算各阶矩的模值：

- 一阶矩：B_{W,1}^\star = 641 + 6700417 = 6701058，6701058 \equiv 2 \pmod{128}

- 二阶矩：B_{W,2}^\star = 641 \times 6700417 = 4294967297，4294967297 \equiv 1 \pmod{128}

联立检验：

- t=1 时，\binom{1}{1}=1 \not\equiv 2 \pmod{128}，不通过

- t=2 时，\binom{2}{1}=2，\binom{2}{2}=1，全部匹配，校验通过

结论：因同余模更大，两阶联检的区分度更强，可高效验证分解结果的结构合理性。

5.4 效能结论与适用边界

综合理论分析与数值算例，可得出三点结论：

1. 约束强度与同余模正相关：同余模越大，各阶矩的模值区分度越高，校验的可靠性越强；对于大索引费马数、大素数索引梅森数，仅需低阶矩即可完成强一致性校验。

2. 计算代价极低：校验过程仅涉及模运算与二项式系数求值，时间复杂度为 O(K^2)，相对于整数因子分解的计算代价可忽略不计。

3. 核心适用场景明确：该算法的核心定位是大整数分解完成后的结构一致性校验工具，可快速排查错误的分解结果；对于无特殊同余结构的一般整数，实用价值显著下降。

注：上述分析均基于平方自由前提；对于梅森数、费马数等序列，目前尚未发现非平方自由的实例，该假设在实际应用中具备合理性。若待检验数含素数幂因子，需采用非平方自由修正公式重新计算校验值。

1. 序列性质层面：将通用同余定理与特殊序列的素因子约束结合，得到了梅森数、费马数的分层强同余结论与强化结构判据；通过Wieferich素数关联精准划定了分圆多项式场景的适用边界。

3. 算法应用层面：明确了分层同余检验的定位与适用场景，通过数值算例验证了其作为分解后结构校验工具的高效性，为算法落地提供了量化依据。
