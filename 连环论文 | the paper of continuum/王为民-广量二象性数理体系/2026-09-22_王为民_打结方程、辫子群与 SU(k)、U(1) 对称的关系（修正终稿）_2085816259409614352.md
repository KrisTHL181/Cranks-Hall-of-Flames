一、基本框架

1.1 打结方程

n 股辫子群 B_n 的生成元 \sigma_1,\dots,\sigma_{n-1} 满足：

\boxed{

\sigma_i\sigma_{i+1}\sigma_i=\sigma_{i+1}\sigma_i\sigma_{i+1}

}

\sigma_i\sigma_j=\sigma_j\sigma_i,\qquad |i-j|\ge2

这是拓扑杨‑巴克斯特方程的离散辫子形式。

1.2 层级演化链条

\boxed{

\begin{array}{c}

\text{打结方程（拓扑公理）}\\

\downarrow\\

\text{辫子群 }B_n\\

\downarrow\\

\text{Hecke 代数 }H_n(q)\\

\downarrow\\

\text{Temperley-Lieb 代数 }TL_n(q)\\

\downarrow\\

\text{量子群 }U_q(sl_k)\\

\downarrow\ q\to1\\

\text{半单李代数 }sl_k\\

\downarrow\\

\text{紧致规范群 }SU(k)\\[6pt]

\text{（阿贝尔分支）}\\

B_n\xrightarrow{\text{阿贝尔化}}B_n^{\rm ab}\cong\mathbb Z\xrightarrow{\text{紧致化}}U(1)

\end{array}}

二、打结方程 → Hecke 代数

2.1 Hecke 二次关系

Hecke 代数 H_n(q) 由 \sigma_i 生成，除打结关系外，还满足：

\boxed{

(\sigma_i-q)(\sigma_i+q^{-1})=0

}

展开：

\boxed{

\sigma_i^2=(q-q^{-1})\sigma_i+1

}

2.2 王为民参数

q+q^{-1}=3

q=\lambda_+=\frac{3+\sqrt5}{2}=2.618034,\qquad q^{-1}=\lambda_-=\frac{3-\sqrt5}{2}=0.381966

q-q^{-1}=\sqrt5=2.236068

特征方程：

\lambda^2-3\lambda+1=0

2.3 Hecke 关系的王为民形式

\boxed{

\sigma_i^2=\sqrt5\,\sigma_i+1

}

三、Hecke 代数 → Temperley-Lieb 代数

3.1 变换

\boxed{

e_i=\sigma_i+q^{-1}\mathbb 1

}

\sigma_i=e_i-q^{-1}\mathbb 1

3.2 验证 TL 关系

验证一：

e_i^2=(\sigma_i+q^{-1})^2=\sigma_i^2+2q^{-1}\sigma_i+q^{-2}

代入 \sigma_i^2=(q-q^{-1})\sigma_i+1：

e_i^2=(q+q^{-1})\sigma_i+(1+q^{-2})

用 \sigma_i=e_i-q^{-1}：

=(q+q^{-1})(e_i-q^{-1})+(1+q^{-2})

=(q+q^{-1})e_i-1-q^{-2}+1+q^{-2}

=(q+q^{-1})e_i

在王为民参数下：

\boxed{

e_i^2=3e_i

}

验证二：

由 Hecke 关系和变换直接展开可验证：

\boxed{

e_ie_{i\pm1}e_i=e_i

}

验证三：

由 \sigma_i\sigma_j=\sigma_j\sigma_i 直接得到：

\boxed{

e_ie_j=e_je_i,\qquad |i-j|\ge2

}

3.3 TL 代数公理

\boxed{

\begin{array}{l}

e_i^2=3e_i\\

e_ie_{i\pm1}e_i=e_i\\

e_ie_j=e_je_i,\quad |i-j|\ge2

\end{array}}
