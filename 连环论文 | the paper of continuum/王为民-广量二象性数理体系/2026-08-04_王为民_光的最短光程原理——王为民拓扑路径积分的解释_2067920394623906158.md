一、问题的提出

经典几何光学中，费马原理表述为：光线自 A 点传播至 B 点，真实路径满足光程泛函取极值（通常为极小值）：

\delta\int_A^B n(\boldsymbol{x})\,ds = 0

凭借这一原理，可统一推导光的直线传播、反射定律与斯涅尔折射定律，构成几何光学的理论基石。

然而在传统理论体系中，费马原理属于公理，其深层微观起源无法依靠经典理论解释。量子电动力学借助费曼路径积分提供物理图像：光子遍历一切可行路径，所有路径贡献相干叠加，经典光路对应作用量取极值的轨道。但费曼路径积分依赖连续泛函积分——路径集合不可数，泛函测度 \mathcal{D}\boldsymbol{x} 长久缺乏严格数学定义，理论根基存在固有瑕疵。

王为民拓扑路径积分以可数、有限的离散组态相干求和替代连续泛函积分，从根源规避测度难题，为费马原理搭建起从离散微观拓扑到连续宏观几何的完整推导链条。本文完整呈现这套推导结构。

二、光子传播的拓扑路径积分表述

2.1 拓扑基元与光子本质

在王为民拓扑路径积分体系中，时空由素数阶拓扑基元 T_p（p\in\mathbb{P}）构筑。单个基元拥有 p 个可区分的拓扑单元，其内部组态由分拆簇数 k（1\leq k\leq p）刻画。根据素数刚性定理，第二类斯特林数 S(p,k) 在 1<k<p 时满足 S(p,k)\equiv 0\pmod{p}，赋予组态空间以不可均分的拓扑刚性。

基元的物理状态分为两个基本类型：

· k=1：真空不动点构型，基元处于最低拓扑能态；

· k>1：拓扑激发态，对应外界场扰动引发的内部拓扑重组。

假设1（光子的拓扑诠释）

光子不是独立于时空的实体，而是拓扑基元集体激发态的相干传播模式。具体而言，光子对应基元分拆簇数偏离真空值（k=1）的局域扰动，该扰动以拓扑相位同步的方式在相邻基元间传递，形成传播的波包。光子频率 \nu 与基元响应特征频率 \nu_W = c/\ell_W 通过色散关系关联。

假设2（光子-基元耦合）

光子传播过程中，电磁振荡与途经基元发生拓扑耦合。在弱场线性近似下，基元分拆簇数的偏离量 \delta k^{(i)} = k^{(i)}-1 与局域电磁场强度 |\boldsymbol{E}(\boldsymbol{x}_i)| 成正比：

\frac{\delta k^{(i)}}{p_i} = \alpha_W \cdot |\boldsymbol{E}(\boldsymbol{x}_i)| \cdot \ell_W

其中 \alpha_W 为拓扑耦合常数，\ell_W 为基元特征尺度。该线性关系在分拆簇数远小于素数阶数（\delta k^{(i)} \ll p_i）的条件下成立，涵盖常规光强下的全部光学现象。

2.2 组态空间与传播子定义

设光子从时空点 A 传播至 B。将 A 与 B 之间时空区域内全部可能被途经的基元记为集合 \mathcal{T}_{AB}，其基数为 N_{AB}。不同传播路径对应 \mathcal{T}_{AB} 的不同子集及不同的分拆簇数分配方案。所有满足边界条件（起止点基元处于指定构型）的合法组态构成组态空间 \mathscr{S}_{AB}。

定义1（光子拓扑传播子）

光子从 A 到 B 的传播振幅定义为组态空间 \mathscr{S}_{AB} 上的相干求和：

\boxed{

K(B,A) = \sum_{\alpha\in\mathscr{S}_{AB}} \mathcal{W}(\alpha)\, \exp\!\big(i\,\mathcal{F}[\alpha]\big)

}

其中 \mathcal{W}(\alpha) 为组态 \alpha 的归一化权重，\mathcal{F}[\alpha] 为其拓扑相干泛函。

2.3 拓扑相干泛函的结构

对于光子传播过程，拓扑相干泛函由拓扑相位项与贝尔模贡献构成：

\mathcal{F}[\alpha] = \sum_{i\in\gamma_{AB}} \frac{2\pi k^{(i)}}{p_i} + \mathcal{F}_{\text{贝尔}}[\alpha]

其中 \gamma_{AB} \subseteq \mathcal{T}_{AB} 为组态 \alpha 中实际被激发的基元序列（拓扑意义上的传播路径），k^{(i)} 为路径上第 i 个基元的分拆簇数，p_i 为其素数阶数。\mathcal{F}_{\text{贝尔}}[\alpha] 来自贝尔多项式零点模贡献，在路径连续形变下变化缓慢，对稳相分析的一阶变分贡献为零，后续推导中可忽略。

线性拓扑相位项 \sum 2\pi k^{(i)}/p_i 是产生路径干涉的核心——不同传播路径上基元分拆簇数的累积差异，直接体现为量子相位差。

三、拓扑相位与经典光程的对应

定理1（拓扑相位-光程对应定理）

在宏观连续极限 \ell \gg \ell_W（观测尺度远大于基元特征尺度）且弱场线性条件 \delta k^{(i)} \ll p_i 满足时，拓扑相位求和项收敛为经典光程相位：

\boxed{

\lim_{\substack{\ell\gg\ell_W \\ \delta k\ll p}} \sum_{i\in\gamma_{AB}} \frac{2\pi k^{(i)}}{p_i} = \frac{2\pi}{\lambda} \int_A^B n(\boldsymbol{x})\,ds + \Phi_0

}

其中 \lambda 为光在真空中的波长，n(\boldsymbol{x}) 为介质局域折射率，\Phi_0 = \sum_i 2\pi/p_i 为真空基态常数相位（对所有路径相同，不影响干涉）。

证明：

将分拆簇数分解为真空部分与激发部分：k^{(i)} = 1 + \delta k^{(i)}。拓扑相位相应分解为：

\sum_i \frac{2\pi k^{(i)}}{p_i} = \sum_i \frac{2\pi}{p_i} + \sum_i \frac{2\pi\delta k^{(i)}}{p_i} = \Phi_0 + \sum_i \frac{2\pi\delta k^{(i)}}{p_i}

由假设2的线性关系 \delta k^{(i)}/p_i = \alpha_W |\boldsymbol{E}(\boldsymbol{x}_i)| \ell_W，激发部分相位为：

\sum_i \frac{2\pi\delta k^{(i)}}{p_i} = 2\pi\alpha_W \sum_i |\boldsymbol{E}(\boldsymbol{x}_i)| \ell_W

介质的宏观折射率 n(\boldsymbol{x}) 与局域电场响应之间存在唯象关系。在弱场线性介质中，极化矢量 \boldsymbol{P} = \epsilon_0 \chi \boldsymbol{E}，折射率 n = \sqrt{1+\chi}。局域电场强度与折射率梯度的关系为 |\boldsymbol{E}| \propto n(\boldsymbol{x}) \cdot \bar{E}，其中 \bar{E} 为平均场强。将离散基元求和过渡为空间积分：

\sum_i |\boldsymbol{E}(\boldsymbol{x}_i)| \ell_W \;\longrightarrow\; \int_A^B |\boldsymbol{E}(\boldsymbol{x})|\,ds \propto \int_A^B n(\boldsymbol{x})\,ds

比例常数由光子频率与基元响应频率的匹配条件确定：基元完成一轮完整拓扑分拆循环所需的相位变化为 2\pi，该周期在时域对应光的振荡周期 1/\nu，在空域对应传播距离 \lambda/n。由此标定系数 2\pi\alpha_W \bar{E} = 2\pi/\lambda，代入即得定理结论。\square

定理1的适用范围：该对应在线性光学介质中严格成立。对非线性介质或极端强场情形，假设2的线性关系需替换为非线性响应函数，费马原理的修正形式将在另文中讨论。

四、稳相近似与费马原理的涌现

定理2（离散体系稳相条件）

设参与传播过程的拓扑基元总数 M 满足 M \gg p_{\max}（p_{\max} 为沿途基元的最大素数阶数），且基元特征尺度远小于光波长（\ell_W \ll \lambda）。则传播子 K(B,A) 的主导贡献来自满足拓扑相干泛函一阶变分为零的组态序列 \bar{\alpha}：

\delta\mathcal{F}[\bar{\alpha}] = 0

证明：

传播子 K = \sum_\alpha \mathcal{W}(\alpha) e^{i\mathcal{F}[\alpha]} 是 |\mathscr{S}_{AB}| 个复数的相干求和。将组态按传播路径的连续形变参数化：设 \gamma(\tau) 为一族连续可形变的路径，\tau\in[0,1] 为形变参数，\gamma(0) 为参考路径。

两条相邻路径 \gamma 与 \gamma+\delta\gamma 的拓扑相位差，由定理1在连续极限下给出：

\Delta\mathcal{F} = \mathcal{F}[\gamma+\delta\gamma] - \mathcal{F}[\gamma] \approx \frac{2\pi}{\lambda}\,\delta\!\left(\int_\gamma n\,ds\right)

现分析该相位差对相干求和的影响。将求和按路径形变参数分组：

K = \sum_{\tau} \left[ \sum_{\alpha\in\text{bin}(\tau)} \mathcal{W}(\alpha) \right] \cdot e^{i\mathcal{F}[\gamma(\tau)]}

其中 \text{bin}(\tau) 为形变参数在 [\tau, \tau+\Delta\tau] 内的组态集合。每个bin内包含大量微观组态，其拓扑相位近似相同。

当 \delta\int n\,ds \neq 0 时，相邻bin的相位差 \Delta\mathcal{F} 为 2\pi/\lambda 量级的有限值。在 M \gg p_{\max} 条件下，路径形变的总跨度 \Delta\tau_{\text{total}} 包含 M/p_{\max} 个独立可分辨的bin。不同bin的相位因子 e^{i\mathcal{F}} 在复平面上近似均匀分布在单位圆上，大量bin的复数求和因对称性而趋近于零。具体地，非稳相区域的bin数量 N_{\text{bin}} \sim M/p_{\max}，其复数和的数量级为 \mathcal{O}(\sqrt{N_{\text{bin}}})，而总组态数 |\mathscr{S}_{AB}| \sim e^{M}，非稳相贡献的相对权重被指数压制：

\frac{|K_{\text{非稳相}}|}{|K_{\text{稳相}}|} \sim \frac{\sqrt{M/p_{\max}}}{e^{M}} \xrightarrow{M\gg 1} 0

仅在 \delta\int n\,ds = 0 的路径邻域内——即光程泛函的极值点附近——相邻bin的相位差一阶为零，二阶以上缓慢变化，大量bin保持相位相干，产生相长干涉，贡献不被压制。该极值路径即 \bar{\alpha}，满足 \delta\mathcal{F}[\bar{\alpha}] = 0。

由此，在大 M 极限下，传播子的主导贡献严格来自拓扑相干泛函取极值的组态序列。非稳相路径的残余贡献在 M 充分大时被指数压制至不可观测量级。\square

定理3（费马原理的涌现）

在宏观连续极限下，稳相条件 \delta\mathcal{F}=0 等价于费马原理：

\boxed{

\delta\int_A^B n(\boldsymbol{x})\,ds = 0

}

即光线沿光程取极值的轨道传播。

证明：由定理1，连续极限下拓扑相干泛函的激发部分正比于光程泛函：\mathcal{F}_{\text{exc}} = \frac{2\pi}{\lambda}\int n\,ds。真空常数相位 \Phi_0 对所有路径相同，变分下为零。因此 \delta\mathcal{F}=0 等价于 \delta\int n\,ds = 0。由于拓扑相位项中 \delta k^{(i)}/p_i \geq 0（基元激发分拆簇数不小于真空值），相位贡献非负，在均匀介质或缓变介质中光程极值表现为极小值，即通常所谓“最短光程”。\square

五、微观物理图像

按照王为民拓扑路径积分，“光选择最短光程”不能理解为光子拥有自主选择路径的能力，而是量子相干叠加自然演化的统计结果。完整过程分解为四个层次：

第一层：全组态参与。 光子从 A 至 B 的传播，不预先指定任何单一几何路径。时空区域 \mathcal{T}_{AB} 内所有基元的合法分拆组态全部参与量子叠加。不同的组态对应沿途基元不同的拓扑激发模式——有的基元处于真空态（k=1），有的被局域激发（k>1）。激发基元的空间分布构成一条“拓扑路径”。

第二层：相位累积。 每条拓扑路径携带累积相位 \sum 2\pi k^{(i)}/p_i。路径越长、途经高折射率区域的基元越多，累积的拓扑激发越强，总相位越大。相位对路径形变的一阶敏感度正比于光程梯度 \nabla(\int n\,ds)。

第三层：极值轨道相长干涉。 在光程取极值的路径邻域内，一阶变分为零，相位随路径形变保持平稳。该邻域内大量微观组态的拓扑相位近乎一致，复振幅在复平面上沿相同方向叠加，发生相长干涉，形成宏观可观测的信号。

第四层：偏离轨道指数相消。 偏离极值光路的路径，相位随形变快速累积。在复平面上，相邻路径的振幅矢量指向不同方位，正负交替，在大量基元参与的极限下，非稳相区域的净贡献被指数压制至不可观测量级。

最终的宏观观测结果：仅光程取极值的路径及其紧邻的微观邻域对传播振幅有不可忽略的贡献。光子并非“预先知晓”最短路线——恰恰相反，所有路径平等参与了量子叠加，只是其中绝大多数的贡献在干涉中相互湮灭，唯有极值路径幸存的信号达到宏观可分辨的强度。

七、离散-连续过渡与几何光学定律

定理4（光线方程的对应）

在连续极限下，稳相条件 \delta\int n\,ds = 0 通过变分法标准推导给出光线微分方程：

\frac{d}{ds}\left(n\frac{d\boldsymbol{x}}{ds}\right) = \nabla n

该方程描述非均匀介质中光线的弯曲轨迹。当介质均匀（n=\text{常数}）时，方程简化为 d^2\boldsymbol{x}/ds^2 = 0，对应光的直线传播。

定理5（界面光学定律的推导）

在两种均匀介质（折射率分别为 n_1, n_2）的平滑分界面处，光程泛函 \int n\,ds 的极值条件等价于：

· 反射定律：入射角等于反射角，\theta_i = \theta_r；

· 折射定律（斯涅尔定律）：n_1\sin\theta_1 = n_2\sin\theta_2。

证明：设界面法向沿 z 轴，光在 x-z 平面内传播。光程为 L = n_1\sqrt{x_1^2+z_1^2} + n_2\sqrt{(x_2-x_1)^2+z_2^2}。由 \partial L/\partial x_1 = 0 直接给出斯涅尔定律，反射定律为其 n_1=n_2 的特例。王为民拓扑路径积分通过定理3为这一变分推导提供了量子统计基础。\square

反射与折射定律由此不再是需要独立验证的实验规律，而是离散拓扑量子相干在介质界面条件下的宏观推论。

八、总结

依托王为民拓扑路径积分体系，费马最短光程原理获得自洽的微观推导。核心结论归纳为以下四条：

1. 光子是拓扑基元集体激发态的相干传播模式，其传播振幅为连接起止时空点全部合法拓扑组态序列的相干叠加；

2. 各组态序列累积的拓扑相位，在弱场线性近似与宏观连续极限下严格对应于经典光程相位；

3. 当参与传播的拓扑基元总数 M 满足 M\gg p_{\max} 且基元尺度远小于波长（\ell_W\ll\lambda）时，稳相近似成立——仅拓扑相干泛函取极值的组态序列产生相长干涉，非稳相贡献被指数压制；

4. 该极值条件在连续极限下严格等价于费马原理 \delta\int n\,ds = 0。

最短光程原理由此不再作为独立公理存在。它是定义在离散拓扑空间上的量子相干叠加效应，在观测尺度远大于基元微观尺度、参与基元数目远大于1的宏观极限下，自发涌现出的经典几何规律。几何光学全部定律——直线传播、反射、折射——本质是底层离散拓扑基元集体量子行为的宏观统计表象。
