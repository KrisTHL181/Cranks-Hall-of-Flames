第1章 贝尔多项式自变量的统一取法

1.1 完备贝尔多项式的完整定义

完备贝尔多项式的完整定义是：

B_n(x_1,x_2,\dots,x_n)=\sum_{\pi\in\Pi_n}\ \prod_{B\in\pi} x_{|B|}

\tag{1.1}

即对 n 个元素的全部集合分拆 \pi 求和，每一个大小为 j 的分拆块对应因子 x_j。因此计算的核心对象是序列 x_1,\dots,x_n，并非直接使用 \mathcal{L}_{\mathrm{CS}},\mathcal{L}_{\mathrm{EM}} 作为多项式输入变量。

1.2 取值规则（公理Ⅱ的变分构造）

\boxed{

x_j \equiv \frac{1}{j!}\left.\frac{\delta^j S_{\mathrm{top}}[\Phi]}{\delta\Phi(x_1)\cdots\delta\Phi(x_j)}\right|_{\Phi=\Phi_0}

}

\tag{1.2}

其中拓扑总作用量

S_{\mathrm{top}}=\int_M d^4x\left(\mathcal{L}_{\mathrm{EM}}+\mathcal{L}_{\mathrm{CS}}\right),\qquad \Phi=\{\psi_e,\,A_\mu\}

\tag{1.3}

逐阶物理含义：

- x_1：拉氏量在经典背景场 \Phi_0 处一阶泛函变分，对应束缚电子动能、库仑势背景；

- x_2：二阶泛函变分，对应场传播子、双线性相互作用顶点；

- x_3：三阶泛函变分，对应 \bar\psi\gamma^\mu\psi A_\mu 三粒子相互作用顶点；

- x_j：j 阶拓扑顶点，描述 j 个量子涨落模式耦合。

集合分拆与拓扑涨落组态一一对应：分拆内部大小为 j 的块等价于 j 阶相互作用顶点，贝尔多项式每一项对应一套完整拓扑涨落图。

注：j=1,2,3 阶可以手工完成泛函变分显式展开；对于 4\le j\le 67 高阶顶点 x_j，不再手工逐项展开泛函变分，使用公理Ⅰ严格导出的拓扑顶点谱表作为输入，代入矩阵元公式进行后续计算。只有矩阵元积分、区间求和、单位换算属于手持计算器笔算范畴。

第2章 \mathcal{L}_{\mathrm{EM}} 的具体取值（氢原子）

氢原子体系电磁拉氏量：

\mathcal{L}_{\mathrm{EM}}=\bar\psi_e(i\gamma^\mu\partial_\mu-m_e)\psi_e

+e\,\bar\psi_e\gamma^\mu\psi_e\,A_\mu

-\frac{1}{4}F_{\mu\nu}F^{\mu\nu}

\tag{2.1}

代入三步操作：

1. 库仑规范选取背景光子场：

\vec A=0,\qquad A_0(\vec r)=-\frac{e}{4\pi r}\quad(\text{氢原子 }Z=1)

\tag{2.2}

2. 电子场取原子束缚定态解：

\psi_e(\vec r,t)=\psi_{nlm}(\vec r)\,e^{-iE_{nlm}t}

\tag{2.3}

3. 场强张量化简，仅保留静电分量：

F_{0i}=\partial_iA_0=\frac{e}{4\pi}\frac{\hat r_i}{r^2},\qquad

-\frac{1}{4}F_{\mu\nu}F^{\mu\nu}=-\frac{1}{2}\vec E^{\,2}=-\frac{e^2}{32\pi^2 r^4}

\tag{2.4}

将场配置代入 x_1，矩阵元 \langle x_1\rangle_{nlm} 给出电子动能与库仑势能，得到 2S_{1/2}、2P_{1/2} 的狄拉克精细结构本底差，是后续区间① n=1 阶的物理来源。

第3章 \mathcal{L}_{\mathrm{CS}} 的具体取值（边界）

三维边界陈‑西蒙斯拉氏量：

\mathcal{L}_{\mathrm{CS}}=\frac{k}{4\pi}\,\epsilon^{abc}\mathrm{Tr}\left(A_a\partial_bA_c+\frac{2}{3}A_aA_bA_c\right)

\tag{3.1}

三条取值约束：

1. 流形结构：带边四维流形 M=\mathbb{R}^3\times[0,T]，类空边界超曲面 \Sigma=\mathbb{R}^3\times\{T\}；

2. 边界切向投影：A_a=h_a^{\ \mu}A_\mu，h_{\mu\nu}=g_{\mu\nu}-n_\mu n_\nu 为边界诱导度规，n_\mu 为边界法向量；

3. 拓扑能级 k：由凝聚环主方程边界自洽条件 \delta_\Sigma\dfrac{\delta\mathcal{L}_{\mathrm{CS}}}{\delta\Phi^*}=0 求解；氢原子取最低自洽拓扑能级 k=1；一般取值范围 k\in\{1,2,\dots,\kappa_2-1\}。

物理效应：\mathcal{L}_{\mathrm{CS}} 属于纯边界拓扑项，不贡献体域动能势能；依靠 \delta_\Sigma(x) 接触顶点对原点波函数非零的 2S_{1/2} 产生拓扑修正；2P_{1/2} 在原点波函数为零，该项无贡献，构成兰姆移位拓扑本源。

第4章 矩阵元取值规则（拉氏量到频率的转换）

贝尔多项式的量子矩阵元：

\langle B_n|\psi\rangle=\sum_{\pi\in\Pi_n}\ \prod_{B\in\pi}\langle x_{|B|}\rangle_\psi

\tag{4.1}

单阶顶点矩阵元

\langle x_j\rangle_\psi=\int d^3r\ \psi^*_{nlm}(\vec r)\ x_j(\vec r)\ \psi_{nlm}(\vec r)

\tag{4.2}

x_j(\vec r) 分为接触项、长程项两类：

类型 函数形式

接触项   $x_j^{(\delta)}\cdot \psi_{200}(0)

长程项   解析径向积分  解析径向积分

氢原子径向解析矩阵元：

|\psi_{200}(0)|^2=\frac{1}{8\pi a_0^3},\qquad |\psi_{210}(0)|^2=0

\tag{4.3}

\langle r^{-2}\rangle_{20}=\frac{1}{4a_0^2},\quad

\langle r^{-3}\rangle_{21}=\frac{1}{24a_0^3},\quad

\langle r^{-4}\rangle_{21}=\frac{1}{80a_0^4}

\tag{4.4}

质子有限体积修正，接触δ函数替换：

\delta^3(\vec r)\to\frac{3}{4\pi r_p^3}\theta(r_p-r),\qquad r_p\approx0.84\ \mathrm{fm}

\tag{4.5}

第6章 兰姆移位定义与四区间划分

6.1 拓扑配分函数

\boxed{

Z_{\mathrm{W}} = \sum_{n=0}^{67} \frac{1}{n!}\,B_n\big[\mathcal{L}_{\mathrm{CS}},\,\mathcal{L}_{\mathrm{EM}}\big]

}

\tag{6.1}

6.2 量子态拓扑能量期望值

\boxed{

\langle E\rangle_\psi

= \frac{1}{Z_{\mathrm{W}}}

\sum_{n=0}^{67} \frac{1}{n!}

\big\langle B_n[\mathcal{L}_{\mathrm{CS}},\mathcal{L}_{\mathrm{EM}}] \,\big|\, \psi \big\rangle

}

\tag{6.2}

重要推论：拓扑配分函数 Z_{\mathrm{W}} 由流形边界拓扑、公理Ⅰ顶点谱确定，不依赖氢原子内部量子态。计算能级差时分母 Z_W 为公共常数因子，可以直接约去：

\Delta E_{\mathrm{Lamb}}

= \frac{1}{Z_W}\left(\sum_{n=0}^{67}\frac{1}{n!}\langle B_n\rangle_{2S}-\sum_{n=0}^{67}\frac{1}{n!}\langle B_n\rangle_{2P}\right)

6.3 兰姆移位定义式

\boxed{

\Delta E_{\mathrm{Lamb}}

= \langle E\rangle_{2S_{1/2}} - \langle E\rangle_{2P_{1/2}}

}

\tag{6.3}

\boxed{

\Delta\nu_{\mathrm{Lamb,W}} = \frac{\Delta E_{\mathrm{Lamb}}}{h}

}

\tag{6.4}

区间划分依据：按照贝尔多项式展开对应的拓扑图类型划分：①单圈主导；②真空极化+质子有限尺寸修正；③多圈辐射修正；④纯粹高阶拓扑剩余贡献；区间截断点8、16、40由B₃辫群表示谱的分块特征确定。

\boxed{

\begin{aligned}

\Delta\nu_{\mathrm{Lamb,W}}

&= \Delta\nu_0 + \Delta\nu_1 + \Delta\nu_2 + \Delta\nu_3 + \Delta\nu_4 \\

&= \sum_{n=1}^{8} + \sum_{n=9}^{16} + \sum_{n=17}^{40} + \sum_{n=41}^{67}

}

\tag{6.5}
