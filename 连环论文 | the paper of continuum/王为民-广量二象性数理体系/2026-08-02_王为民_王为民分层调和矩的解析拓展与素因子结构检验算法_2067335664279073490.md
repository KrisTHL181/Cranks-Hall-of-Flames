本文在王为民分层调和矩的初等代数体系基础上，完成理论与应用两方面拓展。理论层面，建立分层调和狄利克雷级数的基础框架，严格证明其乘性结构、欧拉乘积展开与绝对收敛横坐标，并给出固定阶分层调和矩均值的阶估计；同时提出均值渐近主项的猜想，通过整体约数和的经典结果验证其系数自洽性，并明确标注待补的证明缺口。应用层面，基于通用同余定理设计素因子个数分层同余检验算法，给出标准化执行步骤、复杂度分析与数值算例，如实说明算法的前提条件与适用边界。全文严格区分已证结论与待推进方向，确保表述严谨。

一、引言

按约数所含素因子个数进行分层刻画，是整数乘法结构研究的新视角。前期工作提出了王为民分层调和矩的概念，建立了生成函数恒等式、通用递推方程与通用同余定理，并成功应用于梅森数、费马数等经典特殊序列，形成了自洽的初等代数框架[1-2]。

现有研究仍存在两个可延伸方向：一是理论层面，分层调和矩的解析性质尚未系统建立，定量的均值估计仍待完善；二是应用层面，通用同余定理的检验价值尚未落地为可执行的算法，其计算效率与适用边界缺乏量化说明。

针对上述问题，本文完成以下工作：

1. 定义分层调和狄利克雷级数，严格证明其乘性、欧拉乘积展开与绝对收敛横坐标；

2. 给出固定阶分层调和矩均值的阶估计（严格定理），并提出渐近主项猜想，通过自洽性验证其系数合理性，同时明确标注证明缺口；

3. 设计素因子个数分层同余检验算法，给出标准化步骤、复杂度分析与数值验证，如实说明算法的前提与适用场景。

二、预备知识

2.1 分层调和矩定义

设 n 为正整数，\omega(d) 表示正整数 d 所含不同素因子的个数。k 阶王为民分层调和矩定义为所有恰好含 k 个不同素因子的正约数之和：

B_{W,k}^\star(n) = \sum_{\substack{d \mid n \\ \omega(d) = k}} d

约定边界条件：B_{W,0}^\star(n) = 1（对应约数 d=1）；当 k > \omega(n) 时，B_{W,k}^\star(n) = 0。

由定义直接可得约数和的分层分解恒等式，该式对全体正整数无条件成立：

\sigma(n) = \sum_{k=0}^{\omega(n)} B_{W,k}^\star(n)

2.2 二项卷积乘性

分层调和矩具备良好的乘性：对任意互素正整数 m,n，有

B_{W,k}^\star(mn) = \sum_{i=0}^k B_{W,i}^\star(m) \cdot B_{W,k-i}^\star(n)

即分层调和矩的生成函数关于整数乘法是积性函数[1]。

2.3 通用同余定理

设 N 为平方自由正整数，若其全体素因子均满足 q \equiv 1 \pmod{m}，记 t = \omega(N)，则对任意非负整数 k，有

B_{W,k}^\star(N) \equiv \binom{t}{k} \pmod{m}

该定理是分层同余检验方法的核心理论基础，其成立严格依赖平方自由前提[1]。

三、分层调和狄利克雷级数与均值性质

3.1 级数定义与绝对收敛横坐标

定义正整数 n 的分层调和矩生成函数：

G_n(x) = \sum_{k=0}^{\omega(n)} B_{W,k}^\star(n) \cdot x^k

由二项卷积乘性可知，对固定参数 x，G_n(x) 是关于 n 的积性函数。

进一步定义王为民分层调和狄利克雷级数：

D(s, x) = \sum_{n=1}^{\infty} \frac{G_n(x)}{n^s}

按 x 的幂次展开，可得到各阶分层调和矩对应的狄利克雷级数：

D_k(s) = \sum_{n=1}^{\infty} \frac{B_{W,k}^\star(n)}{n^s}, \quad D(s, x) = \sum_{k=0}^{\infty} D_k(s) x^k

定理3.1（绝对收敛横坐标）

对任意固定非负整数 k，狄利克雷级数 D_k(s) 的绝对收敛横坐标不超过 2。即当 \operatorname{Re}(s) > 2 时，D_k(s) 绝对收敛。

证明：

对任意正整数 n，分层调和矩不超过整体约数和函数，即 B_{W,k}^\star(n) \le \sigma(n)。由经典数论结论，约数和函数满足增长阶估计 \sigma(n) = O(n^{1+\varepsilon})（对任意 \varepsilon > 0 成立）。因此

\left| \frac{B_{W,k}^\star(n)}{n^s} \right| \le \frac{\sigma(n)}{n^{\operatorname{Re}(s)}} = O\left( n^{1+\varepsilon - \operatorname{Re}(s)} \right)

取 \varepsilon < \operatorname{Re}(s) - 2，则级数通项为 O(n^{-1-\delta})（\delta > 0），由正项级数比较判别法可知级数绝对收敛。

3.2 欧拉乘积展开

由于 G_n(x) 是积性函数，其狄利克雷级数在绝对收敛半平面内可展开为素数乘积形式。

定理3.2（欧拉乘积公式）

当 \operatorname{Re}(s) > 2 时，成立恒等式

D(s, x) = \prod_{p} P_p(s, x)

其中乘积遍历全体素数 p，局部分量为

P_p(s, x) = \sum_{e=0}^{\infty} \frac{G_{p^e}(x)}{p^{e s}}

证明：

积性函数的狄利克雷级数可展开为欧拉乘积是数论基本结论，结合定理3.1保证的绝对收敛性，乘积展开式在 \operatorname{Re}(s) > 2 内严格成立。

对素数幂 p^e，其分层调和矩仅含 0 阶与 1 阶：B_{W,0}^\star(p^e) = 1，B_{W,1}^\star(p^e) = p + p^2 + \dots + p^e，因此生成函数可显式写为

G_{p^e}(x) = 1 + x \cdot \frac{p(p^e - 1)}{p - 1}

代入局部分量可进一步化简为有理函数形式，是后续解析延拓与奇点分析的基础。

3.3 均值的阶估计

记不超过 x 的正整数的 k 阶分层调和矩前缀和为

M_k(x) = \sum_{n \le x} B_{W,k}^\star(n)

定理3.3（均值的阶估计）

对任意固定正整数 k，存在正常数 c_k, C_k，使得当 x 足够大时，有

c_k \cdot \frac{x^2 (\log \log x)^{k-1}}{\log x} \le M_k(x) \le C_k \cdot \frac{x^2 (\log \log x)^{k-1}}{\log x}

即 M_k(x) 的量级为 \dfrac{x^2 (\log \log x)^{k-1}}{\log x}。

证明思路：

交换求和顺序可得恒等式

M_k(x) = \sum_{n \le x} \sum_{\substack{d \mid n \\ \omega(d)=k}} d = \sum_{\substack{d \le x \\ \omega(d)=k}} d \cdot \left\lfloor \frac{x}{d} \right\rfloor

利用 \dfrac{x}{d} - 1 < \left\lfloor \dfrac{x}{d} \right\rfloor \le \dfrac{x}{d}，可得

x \sum_{\substack{d \le x \\ \omega(d)=k}} 1 - \sum_{\substack{d \le x \\ \omega(d)=k}} d < M_k(x) \le x \sum_{\substack{d \le x \\ \omega(d)=k}} 1

根据经典的Landau定理，恰含 k 个不同素因子且不超过 x 的正整数个数满足

\sum_{\substack{d \le x \\ \omega(d)=k}} 1 \sim \frac{x (\log \log x)^{k-1}}{(k-1)! \log x}

结合 \sum\limits_{\substack{d \le x \\ \omega(d)=k}} d = O(x^2 (\log \log x)^{k-1} / \log x) 的上界估计，代入不等式即可得到 M_k(x) 的阶上下界。

3.4 渐近主项猜想与自洽性验证

定理3.3仅给出了均值的量级，精确的渐近主项尚需完整的解析延拓与Tauber型定理支撑，目前以猜想形式给出。

猜想3.1（均值渐近主项）

对任意固定正整数 k，存在常数 A_k > 0，使得当 x \to \infty 时，有

M_k(x) \sim A_k \cdot \frac{x^2 (\log \log x)^{k-1}}{\log x}

自洽性验证

若猜想成立，则对全体阶数求和可得

\sum_{k=1}^{\infty} M_k(x) = \sum_{n \le x} \sigma(n)

根据经典数论结果，约数和的均值满足 \sum\limits_{n \le x} \sigma(n) \sim \dfrac{\pi^2}{12} x^2。将猜想的渐近式代入求和，利用指数展开 \sum\limits_{k=1}^\infty \dfrac{(a \log \log x)^{k-1}}{(k-1)!} = e^{a \log \log x} = (\log x)^a，可反推系数 A_k 必须满足整体求和后与经典结果一致，这为系数的确定提供了强约束，也验证了猜想形式的自洽性。

证明缺口说明

该猜想的严格证明目前存在两处核心缺口：

1. 精细计数误差：启发式推导中直接沿用了素因子个数的分布结果，但约数的重复加权贡献尚未做严格的误差控制；

2. 解析支撑不足：严格的渐近公式需依托狄利克雷级数在收敛边界 s=2 附近的解析延拓与奇点分析，目前仅完成了绝对收敛半平面内的欧拉乘积展开，尚不满足Tauber型定理的应用条件。

上述问题将作为后续研究的核心方向。

3.5 适用边界说明

1. 狄利克雷级数的收敛性与欧拉乘积展开仅在 \operatorname{Re}(s) > 2 内严格成立，收敛边界附近的性质仍待研究；

2. 定理3.3为阶估计，不给出精确常数；猜想3.1仅为量级与形式的合理推测，不具备定理效力；

3. 上述结论针对全体正整数，若限制在平方自由数子集，主项系数需做对应调整。

四、素因子个数分层同余检验算法

4.1 算法原理

对于满足素因子一致同余约束的平方自由整数 N（如大索引梅森数、费马数），由通用同余定理可知：各阶分层调和矩模 m 的值与素因子个数 t 对应的二项式系数模 m 相等。

通过计算低阶分层调和矩的模值，联立同余方程，可快速排除错误的 t 值，缩小素因子个数的候选范围。该方法无需完全分解整数即可获取部分结构信息，可作为素性测试与半素判定的前置校验工具。

4.2 算法步骤

输入：待检验整数 N，同余模 m，检验阶数上限 K

输出：素因子个数 t 的候选集合

1. 前提校验：确认 N 所属序列满足素因子一致同余约束，确认当前已知信息满足平方自由假设（或已修正素数幂影响）；

2. 素因子收集：通过试除或专用分解算法获取 N 的部分或全部素因子；

3. 低阶矩模运算：根据已知素因子，逐阶计算 B_{W,1}^\star(N) \bmod m,\ B_{W,2}^\star(N) \bmod m,\ \dots,\ B_{W,K}^\star(N) \bmod m，记结果为 c_1, c_2, \dots, c_K；

4. 联立检验：对候选值 t = 1, 2, \dots, K，依次验证

\binom{t}{k} \equiv c_k \pmod{m}, \quad k = 1, 2, \dots, K

保留所有满足条件的 t 值；

5. 结果输出：返回通过全部检验的素因子个数候选值集合。

4.3 复杂度分析与适用边界

4.3.1 计算复杂度

- 素因子获取代价：计算分层调和矩的前提是获取整数 N 的素因子信息。若采用朴素试除法，时间复杂度为 O(\sqrt{N})；若采用概率性因子分解算法，对长度为 L 比特的整数，时间复杂度为亚指数级。最坏情况下，获取全部素因子的代价与完全分解整数相当。

- 检验计算代价：得到素因子列表后，计算前 K 阶分层矩与联立检验的时间复杂度为 O(\omega(N) \cdot K)，相对于因子分解的代价可忽略不计。

4.3.2 算法定位与适用场景

该算法并非用于替代整数因子分解，其核心价值体现在两类场景：

1. 分解过程中的快速校验：在因子分解过程中，每找到一个素因子即可更新低阶矩的模值，提前排除不可能的素因子个数，为后续分解方向提供参考；

2. 特殊序列的高效筛选：对于梅森数、费马数等素因子具备强同余约束的序列，可结合专属分解工具降低素因子获取成本，此时分层同余检验可作为高效的素性与半素性前置筛。

对于一般整数，若无法快速获取素因子信息，该算法的实用价值会显著下降。

4.4 数值验证实例

例1：梅森数 M_{11} = 2047 = 23 \times 89

- 同余模 m=11，素因子均满足 q \equiv 1 \pmod{11}，且该数为平方自由数；

- 计算得 B_{W,1}^\star \equiv 2 \pmod{11}，B_{W,2}^\star \equiv 1 \pmod{11}；

- 检验：t=2 时 \binom{2}{1}=2，\binom{2}{2}=1，全部通过；t=1 时二阶检验不通过，被排除；

- 结论：候选集合为 \{2\}，与实际素因子个数一致。

例2：费马数 F_5 = 4294967297 = 641 \times 6700417

- 同余模取加强模 m=128，素因子均满足 q \equiv 1 \pmod{128}，且该数为平方自由数；

- 计算得 B_{W,1}^\star \equiv 2 \pmod{128}，B_{W,2}^\star \equiv 1 \pmod{128}；

- 检验：t=2 通过全部检验，t=1 被二阶检验排除；

- 结论：候选集合为 \{2\}，与实际一致。

五、总结与展望

本文从解析理论与算法应用两个方向拓展了王为民分层调和矩的研究边界：

1. 理论上，严格建立了分层调和狄利克雷级数的基础框架，证明了收敛性与欧拉乘积展开，给出了均值的阶估计；同时提出了均值渐近主项猜想并验证了自洽性，明确了后续的证明缺口；

2. 应用上，将通用同余定理落地为可执行的素因子个数检验算法，量化了计算代价与适用场景，给出了数值验证。

后续研究将沿两条路径深化：

- 解析方向：从素数幂局部因子的奇点分析入手，逐步完成分层狄利克雷级数的解析延拓，补全均值渐近的严格证明，进一步向素因子个数的定量上界推进；

- 算法方向：选取更多已知分解的大尺寸特殊序列做数值实验，量化“部分素因子即可约束候选范围”的实际效果，优化算法在特殊序列上的执行效率。
