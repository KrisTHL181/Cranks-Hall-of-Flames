二、基础定义与前置准备

2.1 贝尔多项式与零点集

由L0级核心公理——第二类斯特林数分拆规则

S(n,k) = S(n-1,k-1) + k\cdot S(n-1,k)

出发，构造第k阶王为民无调和贝尔多项式：

\mathcal{B}_k(\tau) = \sum_{m=1}^k S(k,m)\, \tau^m

其零点集记为Z_k = \{\tau_i\mid \mathcal{B}_k(\tau_i)=0,\, i=1,2,\dots,k\}，其中\tau=0为平凡零点，剩余k-1个为非平凡零点。

由零点反演对称定理（L1级），非平凡零点满足严格反演对称性：若\tau_i\in Z_k，则1/\tau_i\in Z_k，且全体非平凡零点的模长乘积恒为1：

\prod_{i=2}^k |\tau_{k,i}| = 1

所有零点均为互异单根，无重根与重合。

2.2 拓扑荷的围道积分表示

由拓扑荷围道积分定理（L1级），对任意不穿过零点的闭合围道\Gamma，围道内的净拓扑荷等于零点计数：

Q(\Gamma) = \frac{1}{2\pi i}\oint_{\Gamma} \frac{\mathcal{B}_k'(\tau)}{\mathcal{B}_k(\tau)} d\tau = N_\text{zeros}(\Gamma)

其中N_\text{zeros}(\Gamma)为\Gamma包围的非平凡零点数。该结论是后续所有场量构造的核心数学基础。

三、相位场的拓扑构造：规范场的微观源头

规范场的核心载体是相位场，而相位的全部自由度都源于零点的拓扑涡旋结构，无任何额外输入。

3.1 拓扑相位场的定义

定义复平面上的拓扑相位场为贝尔多项式的辐角，即复对数的虚部：

\theta(\tau) = \arg\mathcal{B}_k(\tau) = \operatorname{Im}\left[\ln \mathcal{B}_k(\tau)\right]

由多项式的零点分解，相位场可展开为全部零点的辐角叠加：

\theta(\tau) = \sum_{i=1}^k \arg(\tau - \tau_i)

每一个非平凡零点对应一个单位强度的相位涡旋：观测点绕零点一周，该零点贡献的辐角增加2\pi。

3.2 相位多值性的拓扑必然性

对包围全部k-1个非平凡零点的闭合围道\Gamma，由幅角原理，相位沿围道的总跳变量为：

\Delta\theta = \oint_\Gamma d\theta = \operatorname{Im}\left[ \oint_\Gamma \frac{\mathcal{B}_k'(\tau)}{\mathcal{B}_k(\tau)} d\tau \right] = 2\pi (k-1)

相位的多值性（相差2\pi整数倍）并非人为赋予的自由度，而是零点分布的拓扑约束结果：包围n个零点，相位就必然获得2\pi n的跳变，跳变整数严格等于包围的零点数。

核心结论：量子相位的全部多值结构，都由零点计数的拓扑性质唯一确定，完全是斯特林数分拆规则的必然产物。物理上观测到的波函数相位，本质是局域零点绕数的宏观统计平均。

四、规范联络与曲率的演生：从相位梯度到规范场

有了拓扑相位场，规范联络会作为其梯度自然演生，无需人为引入规范场的定义。

4.1 规范联络的自然导出

定义凝聚环上的有效规范联络为相位场的空间梯度：

A_\mu(\tau) = \frac{1}{g}\, \partial_\mu \theta(\tau)

其中g为拓扑耦合常数，后续将由通量归一化定理刚性确定，仅起量纲归一化作用。

代入曲率的定义式直接计算：

F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu = \frac{1}{g}\left( \partial_\mu\partial_\nu \theta - \partial_\nu\partial_\mu \theta \right) \equiv 0

即该联络为平坦纯规范联络，局域曲率恒为零。规范场的非平凡性完全不来自局域曲率，而来自相位的整体拓扑绕数——绕非平凡零点一周获得的2\pi整数倍相位跳变，对应规范场的整体拓扑通量。

4.2 第一陈数与零点拓扑荷的等价性

全纯线丛的第一陈数（总拓扑通量）为通量沿闭合边界的积分：

c_1(\mathcal{L}) = \frac{1}{2\pi} \oint_{\partial\mathcal{A}} A_\tau d\tau

将联络表达式代入，结合拓扑荷围道积分定理，可得：

c_1(\mathcal{L}) = \frac{1}{2\pi i} \oint_{\partial\mathcal{A}} \frac{\mathcal{B}_k'(\tau)}{\mathcal{B}_k(\tau)} d\tau = k-1

规范场的总通量与零点的净拓扑荷严格相等（零点-拓扑陈数等价定理，L1级）。

至此，规范场的完整结构已经从零点拓扑中完全演生出来：它不是独立的基本场，而是相位涡旋的梯度描述，其整体性质完全由零点的拓扑分布决定。

五、定域规范变换的拓扑实现

定域规范变换不是对场量的人为重定义，而是零点位置的局域重标度操作，二者严格对应。

5.1 零点定域重标度变换

定义定域零点重标度变换\mathcal{T}_\alpha：每个零点发生与定域相位\alpha(\tau)对应的局部位移

\mathcal{T}_\alpha: \quad \tau_i \longmapsto \tau_i + \epsilon_i(\alpha)

其中零点位移的闭合解析形式由柯西核位移性质严格导出：

\epsilon_i(\alpha) = \frac{1}{2\pi i} \oint_{\Gamma_i} \frac{\mathcal{B}_k'(\tau)}{\mathcal{B}_k(\tau)} \cdot \alpha(\tau)\, d\tau

\Gamma_i为仅包围第i个零点的小围道，结果与围道形状无关，满足拓扑不变性。

5.2 与规范变换律的严格对应

在零点重标度变换下，相位场获得局域增量\alpha(\tau)，代入联络的定义可得联络的变化量：

\delta A_\mu = \frac{1}{g}\, \partial_\mu \left( \arg\left( \mathcal{B}_k(\tau-\epsilon) \right) - \arg\mathcal{B}_k(\tau) \right) = \frac{1}{g}\, \partial_\mu \alpha(\tau)

该式与量子场论中U(1)定域规范变换的联络变换律

A_\mu \to A_\mu + \frac{1}{g}\partial_\mu\alpha

完全一致。

物理中的定域规范变换，本质就是拓扑空间中零点的定域重标度操作；规范不变性则对应零点重标度下物理可观测量的几何对称性，无需人为设定规范原理。

六、规范对称群的严格同构证明

零点重标度变换构成的群，与U(1)定域规范变换群严格同构，规范对称性是零点几何对称的连续有效描述。

6.1 零点变换群的公理验证

记所有零点重标度变换构成集合\mathscr{T} = \{\mathcal{T}_\alpha \mid \alpha: \mathbb{R}^4\to\mathbb{R}/\mathbb{Z}\}，逐项验证群公理：

1. 封闭性：由显式映射对\alpha的线性性，\mathcal{T}_\alpha \circ \mathcal{T}_\beta = \mathcal{T}_{\alpha+\beta} \in \mathscr{T}；

2. 结合律：由复合函数普遍结合律自然成立；

3. 单位元：\alpha=0对应恒等变换\mathcal{T}_0；

4. 逆元：对任意\mathcal{T}_\alpha，逆元为\mathcal{T}_{-\alpha}。

因此\mathscr{T}构成一个群，称为零点重标度变换群。

6.2 群同构关系

构造群同态映射\Phi: \mathscr{T} \to U(1)：

\Phi(\mathcal{T}_\alpha) = e^{i\alpha(x)}

\Phi(\mathcal{T}_\alpha \circ \mathcal{T}_\beta) = \Phi(\mathcal{T}_{\alpha+\beta}) = e^{i(\alpha+\beta)} = \Phi(\mathcal{T}_\alpha)\cdot\Phi(\mathcal{T}_\beta)

S_W(k) = (k-1) + \frac{1}{2} = \frac{2k-1}{2}

根据李群表示论的正交归一性，总有效通量在基础表示的d_k个荷分量中均匀分配，单分量的耦合强度平方等于总通量除以分量数：
