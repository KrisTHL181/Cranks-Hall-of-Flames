确认互卦的爻位提取规则完全符合传统定义：取原卦二、三、四爻为互卦下卦，取原卦三、四、五爻为互卦上卦，无自定义篡改

2. 数理公式自洽性校验 🧮

通过代数运算直接锁定互卦映射的唯一解，排除人工查表的笔误风险：

6位二进制位映射：原卦二进制为b5 b4 b3 b2 b1 b0（b5为上爻，b0为初爻）

互卦上卦计算公式：H = 4*b4 + 2*b3 + 1*b2

互卦下卦计算公式：L = 4*b3 + 2*b2 + 1*b1

互卦最终系数：M = H * 8 + L

逐卦代入公式计算，64个结果全部唯一且落在0~63区间，无溢出、无冲突

def f8c_mutual(n):

bits = [(n >> i) & 1 for i in range(6)]

H = bits + bits*2 + bits*4

L = bits + bits*2 + bits*4

return H * 8 + L

mutual_map = {i: f8c_mutual(i) for i in range(64)}
