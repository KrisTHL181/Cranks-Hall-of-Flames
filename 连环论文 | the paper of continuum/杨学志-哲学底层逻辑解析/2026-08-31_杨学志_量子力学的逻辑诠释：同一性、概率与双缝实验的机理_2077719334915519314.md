摘要

量子力学的长期困惑源于一个从未被明确提出的问题：量子对象何时表现为波，何时表现为粒子？本文提出一个简洁的回答：传播过程中表现为波，与外部系统相互作用时表现为粒子。这一区分的理论基础是“同一性”概念——量子对象在传播过程中其位置属性不具有同一性，只能以概率描述；概率本身具有同一性，是薛定谔方程描述的对象。本文进一步区分两类相互作用：编码在系统哈密顿量中的幺正演化（如波片对偏振态的改变）不构成观测；与外部系统之间的局域、量子化的能量传递（如光子被吸收）构成观测并触发坍缩。以单光子双缝实验为验证案例，本文证明：无探测器时两条路径的波函数相干叠加产生干涉条纹；有波片标记时两条路径的波函数偏振态正交，相干项消失，屏幕上呈现两条亮斑——这一结果并非“路径探测”所致，而是波函数分支正交化的直接数学后果。本文进一步指出，“路径信息”是一个多余的概念，它将“偏振正交”这一物理事实翻译为拟人化表述，再用该表述来解释干涉消失，构成一个概念跳跃。整个过程中不存在从“波”到“粒”的转变，只有波函数的幺正演化与坍缩两种物理状态。

### 一、引言

量子力学因其反直觉的特征而著称：一个微观粒子在未被观测时似乎同时处于多个状态，其行为更像一列波，可以发生干涉和衍射；然而，一旦被观测，它则表现为一个局域化的粒子。如何理解这种“波粒二象性”，构成了量子力学基础研究的核心困惑。

自量子力学建立以来，物理学家提出了多种诠释。哥本哈根诠释[7]引入了“观测者”和“宏观测量仪器”的经典概念，将测量视为量子世界与经典世界的接触点，但这人为地引入了“量子-经典”鸿沟。多世界诠释[2]试图消除这道鸿沟，却以引入无法验证的平行宇宙为代价。退相干理论[3][4][5]解释了量子信息如何泄露到环境中，但它并未解决“为什么我们只感知到一个确定结果”的根本问题。

本文认为，这些诠释都未能解决一个更基本的问题：量子对象何时表现为波，何时表现为粒子？这个问题从未被明确地提出和回答。本文旨在回答这个问题，并以此为双缝实验中的路径标记现象提供一个精确的物理机制解释。

### 二、同一性概念

同一性是认知的基础。要认知任何事物，必须假定该对象具备同一性——它是一个稳定的、持续的、可以被反复指称的对象。一个对象具备同一性，是指在被观察、思考或讨论的时间窗口内，它保持自身稳定不变。例如，一个苹果在不同时间被观察，我们仍能认出它是“同一个苹果”。与之相对，一颗流星转瞬即逝，无法被稳定地指称，因此它没有同一性。

这一概念揭示了量子力学困惑的根源。在量子传播过程中，“光子在时刻 t_k 的位置”缺乏同一性。不存在一个可随时间稳定追踪的“光子在时刻 t_k 的位置”属性。在其与外部系统发生相互作用之前，不存在对应于“光子在时刻 t_k 的位置在某一点”这一断言的事实。

然而，具有同一性的是概率——“光子在位置 r 和时间 t 被发现的概率”。这一概率是一个确定的数值，不因单次测量的随机结果而改变。概率分布 |Ψ(r,t)|² 是一个稳定的函数，具有同一性。薛定谔方程[6]描述的是概率的确定性演化，而非粒子轨迹的确定性演化。概率是量子世界中唯一具有同一性的对象。

### 三、传播与相互作用的区分

基于上述同一性分析，本文提出一个核心区分：

> **传播过程中表现为波，与外部系统相互作用时表现为粒子。**

这一区分具体化为两类理论的分工：

- **传播理论** （薛定谔[6]、狄拉克[5]）描述量子对象的自由演化过程——表现为波动性。
- **量子作用理论** （普朗克[1]、爱因斯坦[2]）描述与外部系统的相互作用过程——能量以分立量子形式传递，表现为粒子性。

传播阶段，量子对象的位置属性不具有同一性，只能以概率描述。当量子对象与外部系统发生局域、不可逆的相互作用时，位置获得瞬时同一性——此即波函数坍缩。

这一区分明确了波恩概率诠释[6]的适用范围：概率描述适用于传播阶段。当量子对象与外部系统发生相互作用时，量子作用理论适用，事件是确定性的——能量要么传递，要么不传递。

### 四、两类相互作用的区分与观测的定义

上述传播与相互作用的区分引出一个更深层的问题：什么算“与外部系统的相互作用”？“相互作用”一词在量子力学中实际涵盖了两类性质完全不同的事物。

### 4.1 编码在系统哈密顿量中的幺正演化

这类相互作用是系统“自身的”——被写入哈密顿量中，定义了系统的结构、能级和演化规律。它们的作用是 **约束** 系统，使波函数按照确定的模式演化，而不是使波函数“选择”某个结果。

常见的光学元件都属于这一类。它们只改变波函数的相位、方向、偏振或路径分幅，不吸收光子，不触发坍缩：

| 光学元件 | 作用 |
| --- | --- |
| 双缝 | 波函数分裂为两个相干分支 |
| 波片（四分之一波片、半波片） | 改变光子偏振态 |
| 分束器（半透半反镜） | 将一束光分为透射和反射两束 |
| 全反射镜 | 改变光子传播方向 |
| 透镜 | 聚焦或准直光束，改变波前相位 |
| 光栅 | 将不同波长分散，或分裂为多个衍射级次 |
| 棱镜 | 折射改变传播方向，同时色散 |
| 偏振分束器 | 根据偏振态将光束分成两路 |
| 相位调制器 | 对光子相位进行时间或空间调制 |
| 空间光调制器 | 对波前进行空间相位调制 |
| 光纤/波导 | 约束并引导光子沿特定路径传播 |
| 延迟线 | 引入可控的时间/相位延迟 |
| 量子逻辑门 | 对量子态进行幺正变换 |
| 谐振腔 | 选择性增强特定频率的光 |

所有这些元件的共同特征是：它们都被编码在系统的哈密顿量中。它们对光子波函数施加的是幺正演化——改变方向、相位、偏振或路径分幅，但不吸收光子，不暴露路径信息，不触发坍缩。光子在整个传播过程中始终保持为波。

### 4.2 与外部系统的相互作用

这类相互作用不是系统“自身的”——发生在被描述的系统与一个外部系统之间。它涉及分立量子能量的局域传递，并在外部系统中留下可记录的痕迹。它的作用是 **记录** ——将一种“可能性”转化为一个“事实”。

- 光电效应[2]中光子与电子的能量传递。
- 探测器中光子被原子吸收的事件。
- 荧光屏上光子被吸收产生亮点。

只有第二类相互作用才构成“观测”。本文提出观测的操作性定义：

> **观测（= 坍缩）是指一个量子系统与一个外部系统之间发生的局域、不可逆的相互作用，该相互作用涉及分立量子能量的传递，并在外部系统中产生一个可记录的痕迹。**

### 五、双缝实验的机理验证

双缝实验是检验上述框架的理想案例。本节分析三种实验配置。

### 5.1 无探测器：干涉条纹

光子从光源到屏幕的整个飞行过程属于传播阶段。其波函数在双缝处分裂为两个分支：

|Ψ⟩ = (1/√2)(|ψ₁⟩ + |ψ₂⟩)

两个分支在传播过程中保持相干。到达屏幕时，两个分支的波函数叠加。光子在屏幕 x 处被发现的概率为：

P(x) = |ψ₁(x) + ψ₂(x)|² = |ψ₁(x)|² + |ψ₂(x)|² + 2Re(ψ₁(x)ψ₂*(x))

干涉项不为零，因此呈现干涉条纹。整个过程中没有发生坍缩。光子位置没有同一性，不存在“光子走了哪条缝”这个事实。

### 5.2 有波片标记：偏振正交化

Walborn等人[8]报道了一个双缝量子擦除实验，该实验使用杨氏双缝产生干涉。实验的具体做法是：在两个缝前放置快轴互相垂直的四分之一波片，作为路径标记。这些波片将干涉光子的偏振状态进行标记，从而破坏干涉图样。

在这个配置中，波片的作用是 **哈密顿量中的幺正演化** 。它不吸收光子，不触发坍缩。但波函数两个分支的偏振态变为正交：

|Ψ⟩ = (1/√2)(|ψ₁⟩ ⊗ |V⟩ + |ψ₂⟩ ⊗ |H⟩)

其中 ⟨V|H⟩ = 0。到达屏幕时，对偏振自由度求迹（屏幕不记录偏振），屏幕上的概率分布为：

P(x) = Tr_pol(|Ψ(x)⟩⟨Ψ(x)|) = (1⁄2)(|ψ₁(x)|² + |ψ₂(x)|²)

干涉交叉项 ψ₁(x)ψ₂*(x)⟨V|H⟩ 为零。屏幕上呈现两条亮斑。

Walborn等人还进一步进行了“延迟擦除”实验，通过测量纠缠光子的偏振来恢复干涉，这进一步证明了干涉的消失与恢复完全取决于波函数分支是否携带可区分的标记。

Qureshi[9]对此类实验进行了理论分析，通过引入光子的两个正交偏振态作为路径标记，指出“引起干涉并到达特定探测器的光子总是同时来自两个狭缝”。这一结论与本文框架的核心观点完全一致：波函数的两条分支同时存在，从未选择路径。

### 5.3 有吸收型探测器：坍缩发生

在每条缝口放置吸收型探测器。光子到达缝口时与探测器（外部系统）发生局域、量子化的能量传递，光子被吸收，探测器记录信号。此即坍缩。

坍缩发生后，光子的位置被确定到某一条缝。如果原子退激发重新发射光子，发射是各向同性的。两个缝口的原子相当于两个 **不相干的点光源** ，各自在屏幕上形成单缝衍射包络。两个包络的叠加是宽而平滑的亮度分布。如果没有额外的聚光设备，屏幕上不会出现两条清晰的亮斑；如果有聚光设备将各向同性的发射光收集并准直，则会形成两条亮斑——但这是外部光学系统的后果，不是干涉消失本身的直接结果。

### 5.4 机理对比

| 配置 | 波函数状态 | 是否坍缩？ | 屏幕图样 |
| --- | --- | --- | --- |
| 无探测器 | 同偏振，ψ₁ + ψ₂ 叠加 | 否 | 干涉条纹（相干叠加） |
| 波片标记 | 正交偏振，ψ₁⊗ | V⟩ + ψ₂⊗ | H⟩ |
| 吸收型探测器 | 坍缩后从不相干点光源重发 | 是 | 宽而平滑的亮度分布，或经聚光后的亮斑 |

### 六、“路径信息”概念的消解

### 6.1 “路径信息”概念的来源

在波片标记实验中，Walborn等人[8]将四分之一波片称为“which-path markers”——路径标记。这一术语本身来源于Scully、Englert和Walther（1991）的思想实验，以及更早的爱因斯坦-玻尔关于“哪条路径信息”与干涉条纹可见度互补性的对话。

其推理链条是：

1. 偏振正交（物理事实）
2. 可以判断路径（物理推论）
3. “路径信息存在”（术语命名）
4. “路径信息导致干涉消失”（用术语解释现象）

问题在于第3步和第4步。第3步把一个描述性标签（“路径标记”）转化为了一个实体化的概念（“路径信息”）。第4步把这个概念当作干涉消失的原因。

### 6.2 为什么“路径信息”概念是多余的？

在标准的量子力学数学形式中，没有“路径信息”这个算符，没有“路径信息”这个变量，没有“路径信息”对应的演化方程。只有波函数、哈密顿量、薛定谔方程。

屏幕上的图样——无论干涉条纹还是两条亮斑——完全由波函数在屏幕处的数学形式决定：

P(x) = |ψ₁ + ψ₂|² （同偏振时：有干涉条纹） P(x) = |ψ₁|² + |ψ₂|² （正交偏振时：两条亮斑）

波片标记实验中的两条亮斑，不是“粒子化”的证据，而是波函数分支正交化的直接数学后果。Walborn等人的实验发现，四分之一波片“标记了干涉光子的偏振并从而破坏了干涉图样”。而Qureshi[9]进一步指出，到达特定探测器的光子“总是同时来自两个狭缝”——这恰恰说明两条路径的波函数仍然同时存在。

### 6.3 主流表述与本文框架的对比

| 主流表述 | 本文框架表述 |
| --- | --- |
| 波片标记了路径 | 波片使两个分支的偏振态正交 |
| 路径信息破坏了干涉 | 正交分支之间没有相干项 |
| 偏振片擦除了路径信息 | 偏振片将正交偏振投影到同一偏振态 |
| 路径信息被擦除，干涉恢复 | 分支恢复相干性 |
| 光子知道自己的路径 | 没有“知道”这回事。只有波函数演化 |

### 6.4 取消“路径信息”概念后，一切都更清晰

取消“路径信息”概念后，整个物理图景变得干净：

- 波片是哈密顿量的一部分
- 波函数从光源演化到屏幕
- 到达屏幕时，有没有条纹由波函数的数学形式决定
- 有无坍缩，由是否与外部系统发生局域、不可逆的能量传递决定
- 不需要“路径信息”这个中间实体

正如Qureshi[9]所指出的，通过使用可测试的量子关联来分析偏振，可以为理解此类实验提供清晰的思路。本文框架正是沿着这一方向，进一步取消了“路径信息”这一多余概念，将整个现象还原到波函数的数学结构本身。

### 七、结论

本文提出了量子力学的一个逻辑诠释框架。核心结论是：

1. **同一性区分** ：量子对象在传播过程中位置没有同一性；概率具有同一性，是薛定谔方程描述的对象。
2. **传播/作用区分** ：传播过程中表现为波，与外部系统相互作用时表现为粒子。
3. **两类相互作用区分** ：编码在哈密顿量中的幺正演化不构成观测；与外部系统的局域、量子化、不可逆能量传递构成观测并触发坍缩。
4. **双缝实验验证** ：干涉条纹是波函数相干叠加的结果；波片标记通过分支正交化产生两条亮斑——后者不是“路径探测”的结果，而是波函数内部自由度演化的直接后果。这一解释获得了Walborn等人[8]的双缝量子擦除实验和Qureshi[9]的路径标记理论分析的支持。
5. **“路径信息”概念的消解** ：“路径信息”是一个拟人化的多余概念。它把“偏振正交”这一物理事实翻译为“光子知道自己的路径”，再用这个拟人化表述来解释现象。取消这个概念后，物理图景更加清晰：只有波函数、哈密顿量和测量，没有“路径信息”作为中间实体。

本文的框架不引入额外假设，不修改薛定谔方程，只通过逻辑澄清来消解量子力学的概念困惑。双缝实验的三种配置（无探测、波片标记、吸收探测）为这一框架提供了完整的验证案例。
