### 引子：一个被写模糊的说法

在涌现引力纲领里，桥 B 长期被写成一句话：

> “加曲率项 $F^2$ → 爱因斯坦-希尔伯特（EH）。”

这句话看起来很自然——曲率项嘛，加到作用量里，变分一下，不就是引力方程？

**但它错了。**

$F^2$ 变分出来的是 **Yang-Mills 方程** ，不是 **Einstein 方程** 。这两者是谱作用量热核展开里 **两个不同阶、两种不同曲率** 。把它们混在一起，是一条断链。

这篇文章把这个说法拆清楚。

### 一、数学框架：磁平移与谱作用量

### 1.1 设定

理论底层的自指关系网络 $D$（厄米 $D_{ij} = D_{ji}^*$、零对角）。在结构选择门里，$D$ 自发落到 **π 磁通 toroidal** （4-正则、等模长），其“时间演化”由 **磁平移** $T_\mu$ 生成。

磁平移是 **平移 + U(1) 磁通 + SU(2) 自旋** 的统一。

### 1.2 磁平移与曲率

π 磁通离散模型里，两个方向的磁平移 $T_x, T_y$ 满足 **反对易** ：

$$
T_x T_y = -T_y T_x
$$

（这是 π 磁通里非阿贝尔 Cl(3) 的精确落点。）

**曲率定义为对易子** ：

$$
F_{\mu\nu} = [T_\mu, T_\nu] = T_\mu T_\nu - T_\nu T_\mu = 2T_\mu T_\nu
$$

推导（一步步）：

$$
[T_x, T_y] = T_x T_y - T_y T_x = T_x T_y - (-T_x T_y) = 2T_x T_y.
$$

### 1.3 $F^2$ 是 sector 常数（核心推导）

设 $s_\mu = T_\mu^2$（平移平方，本征值 $\in \{\pm 1\}$ 的 sector 标量）。则：

$$
F_{xy}^2 = -4s_x s_y I
$$

**关键** ：$F^2$ 在 **每个不可约 sector 里是常数倍单位矩阵** 。因此 $S = \text{Tr}(F^2)$ 在 sector 内是常数 $\Rightarrow$ 变分 $\delta S = 0$ 恒成立 $\Rightarrow$ **给不出任何场方程** 。

**数值验证** （$L = 4$，全 True）：

- $T_x T_y = -T_y T_x$：反对易 = Cl(3)，成立
- $F_{xy} = 2T_x T_y$：曲率来自反对易，成立
- $F_{xy}^2 = -4s_x s_y I$：sector 常数，变分恒 0，成立
- $\text{tr}(F_{xy}) = 0$：无迹 = 规范曲率，成立
- $\text{Tr}(F_{xy}F_{xy})$（裸迹）= 0：signed sector 抵消（陷阱）
- $\|F\|^2 = \text{Tr}(FF^\dagger) = 768$：非零 = 规范动能（YM 型）
- $\|F\|^2$ 无磁通 = 0：对易 = F = 0

**陷阱（重要）** ：$F_{xy}$ 是实矩阵（非对称）， **裸迹** $\text{Tr}(F_{xy}F_{xy}) = 0$ 是 signed sector 正负抵消， **不是** $F = 0$。正确的规范动能项是 $\text{Tr}(FF^\dagger) = 768$，别误读裸迹。

### 二、谱作用量热核展开：两个不同阶、两种曲率

### 2.1 Seeley–DeWitt 展开

谱作用量 $S = \text{Tr}\, f(D/\Lambda)$（$D$ 为 Dirac 算子，$f$ 光滑截断，$\Lambda$ 能标）的热核展开：

$$
S \sim f_0 \Lambda^4 a_0 + f_2 \Lambda^2 a_2 + f_4 a_4 + \cdots
$$

其中 Seeley–DeWitt 系数 $a_k$ 是流形上的曲率不变量积分。

### 2.2 系数对应的曲率类型

- 系数 $a_0$：物理 = 体积 $\sqrt{g}$；曲率类型 = 体积；变分给出 = 宇宙学常数
- 系数 $a_2$：物理 = 标量曲率 $\mathcal{R}$；曲率类型 = **时空曲率** （标量曲率 $\mathcal{R}$，度规/自旋联络 $\omega_\mu^{ab}$ 的曲率）；变分给出 = **Einstein–Hilbert**
- 系数 $a_4$：物理 = $F_{\mu\nu}F^{\mu\nu}$ + 曲率平方；曲率类型 = **规范曲率** （$F_{\mu\nu} = [D_\mu, D_\nu]$，内涨落/规范联络 $A_\mu$ 的 field strength）；变分给出 = **Yang–Mills**

### 2.3 两种曲率的精确区分

**规范曲率 $F_{\mu\nu}$** ：联络的 **内部** 曲率（内涨落 $A_\mu$ 的 field strength），作用在 **内部指标** ，给 YM 方程 $D_\mu F^{\mu\nu} = 0$。理论已有的 $F_{\mu\nu} = 2T_\mu T_\nu$ 就是这个（U(1) 磁通 × SU(2) 自旋的统一规范曲率）。

**时空曲率 $\mathcal{R}$** ：度规 $g_{\mu\nu}$（等价地自旋联络 $\omega_\mu^{ab}$）的曲率，作用在 **切空间指标** ，给 Einstein 方程 $G_{\mu\nu} = 0$。

**核心结论** ：$F^2$ 给 **YM** ，不给 **EH** 。桥 B 要的 EH 来自 $a_2$（标量曲率）， **不是** $F^2$ 的变分。

这是 Chamseddine–Connes 1997 的标准结构。

### 三、为什么这是“精确化”而不是“否定”

**1. 桥 B 从“猜”变“清楚”**

之前把“曲率项 $F^2$”和“整体变分 → EH”写在一起，暗示“$F^2$ 变分 → EH”。现在发现这条链 **是断的** ——$F^2$ 变分给 YM，不是 EH。正确桥 B = 谱作用量展开取 $a_2$ 项 = EH。

**2. 和付费桥 2 的“分离墙”是同一条线**

要让 $F_{\mu\nu} = [T_\mu, T_\nu]$ 长出“时空曲率”，需 $\omega_\mu$ 从“内部 SU(2) 自旋”（规范联络）变成“自旋联络”（Levi-Civita）。这正是付费桥 2 撞的“分离”。

**3. 三个缺口是同一个缺口的三个投影**

动力学缺失（缺 EH）→ 桥 B（取 $a_2$）→ 需时空曲率 → 需 $\omega_\mu$ = 自旋联络 → 付费桥 2 分离 → 卡“离散 → 连续”。$F^2$ 是 sector 常数（变分 = 0）正是“离散”这一端卡住“连续”的精确表现。

**4. “q 变形桥 vs 离散 → 连续”是待判开放问题**

付费桥 2 的“q 变形极限”（$q \to 1$）和桥 B 的“离散 → 连续”（$N \to \infty$ / 观察者内化）很可能同一，但文档没证，不该硬说“是”。

### 四、结论

**1.** $F^2$ 给 Yang-Mills，不给 Einstein-Hilbert——这是谱作用量热核展开里 $a_4$（规范曲率）与 $a_2$（标量曲率）两个不同阶的区分。之前“加曲率项 $F^2$ → EH”是 **断链** 。

**2.** 纯 π 磁通里 $F^2$ 是 sector 常数（$F_{\mu\nu}^2 = -4s_\mu s_\nu I$，变分恒 0），这是“离散”这一端卡住“连续”的精确表现。

**3.** 桥 B 的正确结构 $\equiv$ 谱作用量取 $a_2$ 项（标量曲率）→ EH；前置 = 代数 A + 离散 → 连续（观察者内化）。本文只做“定位”，不做“推导”。

**后注（2026-09-15 自旋校准）** ：结论 1（$F^2 = \text{YM}$ 不是 EH）仍对；但结论 3 的“取 $a_2$ 项”后来证明是 **红鲱鱼** ——真曲率是 Q1 角亏 $\delta$（离散，不需连续谱），不是连续流形上的 Seeley–DeWitt $a_2$。

### 五、诚实边界

**1.** 这是“定位”不是“推导”：谱作用量 → EH 是 Chamseddine–Connes 已知结果（“形式化”档，非新硬货）。本文价值 = 拆清“$F^2$”和“EH”两个概念，避免“$F^2$ 变分 → EH”断链。

**2.** “$F^2$ 是 sector 常数”是已证事实，但只说明“纯 π 磁通离散模型里 $F^2$ 退化”，不是“$F^2$ 给不出任何动力学”——偏离 π 磁通后 $F^2$ 变场泛函，只是它给 YM 不是 EH。

**3.** 桥 B 真正坎仍是“离散 → 连续”：$a_2$ 系数是连续流形上的 Seeley–DeWitt 系数，离散有限维 $D$ 上取不出干净的 $a_2$。
