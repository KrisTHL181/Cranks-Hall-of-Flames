### 一、先摆出问题：自旋联络

要理解空间维度，关键对象是 **自旋联络** $\omega_\mu$。

它的作用是： **把”内部自旋”和”空间方向”绑定起来。**

打个比方：你手里有一个自旋箭头（内部 SU(2)），现在你要带着它在空间里走一圈。这个箭头会不会转、怎么转，就是自旋联络在描述的事情。

数学上它写为：

$$
D = i\gamma^\mu(\partial_\mu + \omega_\mu), \qquad \omega_\mu = \tfrac{1}{4}\omega_\mu^{ab}\gamma_{ab}, \qquad \gamma_{ab} = [\gamma_a, \gamma_b]/2.
$$

要构造它，需要两件东西：

1. **洛伦兹生成元** $\gamma_{ab}$（之前预印本 #5 已有：从 π 磁通自发涌现的 4×4 Dirac 结构）；
2. **联络系数** $\omega_\mu^{ab}$——这是本文要回答的：从哪来、卡在哪。

### 二、四条独立的路，撞同一堵墙

我试了四条独立路线，它们全部撞到同一堵墙。

### 路线 1：代数 A（Connes 谱三元组的路线）

Connes 的非交换几何提供了一套成熟机器：给定一个”代数 A”，就可以构造内禀涨落 $D \to D + \sum_j a_j[D, b_j]$，从而生成规范场和自旋联络。

但有一个要求： **一阶条件** $[[D, a], b] = 0$。

**定理 A1** ：如果 A 是对角交换代数（点函数代数），连通图上的一阶条件会强迫 A 平凡（变成复数 $\mathbb{C}$）。

> **证明概要** ：对每条边 $(i,j)$，一阶条件逐元素给出 $(a_j-a_i)(b_j-b_i)=0$。对任意 $a,b \in A$：若存在某个 $b$ 使 $b_j \neq b_i$，则对 **所有** $a$ 必有 $a_j = a_i$；否则 $A$ 在 $\{i,j\}$ 上取常值。无论哪种情况，$A$ 在每条边的两端都取常值。图连通，所以 $A$ 在全图取常值，即 $A = \mathbb{C}$。∎

**定理 A2** ：如果 A 是全矩阵代数 $M_N$，一阶条件会强迫 $D = 0$（杀死整个理论）。

> **证明概要** ：$[[D,a],b]=0$ 对所有 $b \in M_N$ 推出 $[D,a]$ 与所有矩阵对易，即 $[D,a] \in Z(M_N) = \mathbb{C}I$，写成 $c_a I$。又 $\text{Tr}[D,a] = 0$（迹的循环性），所以 $c_a N = 0$，即 $c_a = 0$。于是 $[D,a]=0$ 对所有 $a$，即 $D$ 与所有矩阵对易，$D \in Z(M_N)$，即 $D = \lambda I$。零对角条件推出 $\lambda = 0$，即 $D = 0$。∎

**数值全谱** （4×4 torus）：五种候选代数 A，全部失败。

- A = 16 维对角代数：违例量 34.1 ✗
- A = 16 阶全矩阵代数：违例量 322（D 逼 0）✗
- A = span{I, D}：违例量 0，但 [D, a] = 0 平凡 ✓（退化）
- A = M_8 ⊕ M_8（chiral 全块）：违例量 190 ✗
- A = C^8 ⊕ C^8（chiral 对角）：违例量 34.4 ✗

**结论** ： **标准一阶条件对离散关系无解。** 唯一出路是标准模型有限部分（$A = \mathbb{C} \oplus \mathbb{H} \oplus M_3$ + 电荷共轭 J），但那是”完整机器、不是快修”。

### 路线 2：方向 1（绕开代数 A，直接定义）

绕开代数 A，直接定义 $\omega_\mu$ = 框架沿边的转动 $U_{ij} = g_i g_j^{-1}$。

**结果** ：

- 格点规范律：误差 $6.7 \times 10^{-16}$ ✓
- 连续极限：误差 $4 \times 10^{-10}$ ✓
- **但** ：D 的边相位是 $s_{ij} = \pm 1 \in \{\pm I\}$（SU(2) 的 **中心** ）。

这是 U(1)/Z₂ 磁通， **不是** SU(2) 自旋联络。因为中心元素在 SU(2) 规范下会变，它不是真正的非阿贝尔自旋联络。

### 路线 3：框架来源

框架 $g_i$ 来自 Kramers J（$T^2 = -1$）。四个结果：

1. 最小 Kramers 对象是 **面** （plaquette），不是 **点** ；
2. Z₂ 到 S² 方向场：16 plaquette 全 −1，Chern = 8（abelian 影子）；
3. **全局 J 不局域化** ：16/16 plaquette 的局部限制全失败；
4. 局部 J_p 存在，但是 **gauge** （依赖 π 磁通规范选择）。

**结论** ：底空间 toroidal ✓、纤维 S³ ✓，但 **转移函数的非平凡内容必须是”非交换 SU(2)“，而 π 磁通只给 Z₂（SU(2) 中心，交换）。**

### 路线 4：S² 序参量

Hopf map 的关键事实： **SU(2) 中心 $Z_2 = \{\pm I\}$ 在 Hopf map $S^3 \to S^2$ 下都映射到同一点（北极）** 。

所以 π 磁通（16 个 plaquette 全 −1 = Z₂ 中心）给出的 S² 序参量是 **常数，winding = 0** 。

**非平凡 S² 序参量（winding ≠ 0）需要非中心 SU(2) 元素 = 完整 S³ = 第三层。**

### 四条线收敛

**代数 A（无解）/ 方向 1（U(1) 非 SU(2)）/ 框架（J 不局域化）/ S²（winding = 0）——四条线撞同一堵墙 = 全局 SU(2) 的局部化 = 第三层（2D 到 3D，Hopf）。**

这是拓扑硬事实（$\pi_3(S^2) = \mathbb{Z}$ 只在 3D 非零），不是方法问题。

### 三、换到 3D：结构更丰富，但墙还在

既然 2D 撞墙，换到 3D π 磁通（4×4×4，64 格点）会怎样？

3D 有三对反对易磁平移 $T_x, T_y, T_z$（比 2D 的一对更丰富）。我在 3D π 磁通上做了 **不可约分解** 。

### 定理 1（不可约分解）

3D π 磁通的磁平移 $T_x, T_y, T_z$ 生成 Cl(3) 代数，其不可约分解 = **32 个 2 维泡利块** ，全由动量标签组织、 **位置完全弥散** （$\text{var}(x) = (L^2 - 1)/12$ = 均匀分布）。

**所以 SU(2) 活在动量空间，不存在实空间局域自旋密度。**

> **证明概要** ： **第一步** ：$T_i^2$ 是对易的纯平移（本征值 $\pm 1$），所以 $(T_x^2, T_y^2, T_z^2) \in \{\pm 1\}^3$ 给出 $2^3 = 8$ 个 sector，每个 $64/8 = 8$ 维。 **第二步** ：每个 sector 内 $\chi = T_x T_y T_z$ 满足 $\chi^2 = -s_x s_y s_z I$（标量），所以 $\chi$ 有 2 个本征值，各 4 维。 **第三步** ：复 Cl(3) 代数 $\cong M_2(\mathbb{C}) \oplus M_2(\mathbb{C})$，不可约表示是 2 维（泡利矩阵）。所以每个 4 维 $\chi$ 子空间分解为 2 个 2 维泡利块。 **总计** ：$8 \times 2 \times 2 = 32$ 个泡利块。∎

### 位置判据：决定性

每个块取基矢 $v$，算实空间分布 $|v_i|^2$：

- 参与率 PR：32（均匀 = N/2）
- x 位置方差 var(x)：1.25 = $(L^2 - 1)/12$（完全均匀）

> **证明概要** ：均匀分布（平面波）在 $L$ 个格点上的位置方差为 $(L^2-1)/12$（均匀分布的标准结果）。局域态（单点）方差为 0。数值结果：32/32 块的 var(x) = 1.25 = 均匀值，所以 **所有块都是平面波，没有一个是局域态** 。∎

### 四、核心结果：ω_μ 已内建

但 3D 分析给出了一个漂亮的统一： **磁平移 $T_\mu$ 本身就是”统一对象”。**

### 定理 3（ω_μ 已内建）

$T_\mu$ 同时是三样东西：

| 角色 | 内容 | 来源 |
| --- | --- | --- |
| 轨道平移 ∂_μ | x → x + e_μ（link） | T_μ 的 link 结构 |
| U(1) 磁通 A_μ | 相位 = ±1 | T_μ 的相位值 |
| SU(2) 自旋 ω_μ | 反对易 T_μT_ν = −T_νT_μ | T_μ 的反对易 |

所以 $T_\mu = \partial_\mu + A_\mu + \omega_\mu$ 是 **三者统一** ——轨道、电荷、自旋在磁平移里不可分。

**$\omega_\mu$ 不是”待构造”，它已内建在 $T_\mu$ 里。**

> **证明概要** ：$T_\mu$ 在位置基下是一个”带相位的平移算符”：$T_\mu |x\rangle = s_\mu(x) |x + e_\mu\rangle$，其中 $s_\mu(x) = \pm 1$ 是 π 磁通的 U(1) 相位。所以 $T_\mu$ 本身既包含平移（∂_μ），又包含相位（A_μ）。而三个 $T_\mu$ 之间的反对易关系（$T_x T_y = -T_y T_x$ 等）给出 Cl(3) 代数，Cl(3) 的生成元就是 SU(2) 自旋——所以 $\omega_\mu$ 就是 $T_\mu$ 的反对易部分。∎

### 曲率

$$
F_{\mu\nu} = [T_\mu, T_\nu] = 2T_\mu T_\nu \quad (\text{反对易})
$$

- 非平凡：$\|F\| = 16$
- **无迹** （trace = 0，SU(2)-like）
- $F_{\mu\nu}^2 = -4s_\mu s_\nu I$

**这个曲率是”U(1) 磁通 × SU(2) 自旋”的统一曲率。**

> **证明概要** ：$T_\mu T_\nu = -T_\nu T_\mu$ 推出 $[T_\mu, T_\nu] = T_\mu T_\nu - T_\nu T_\mu = T_\mu T_\nu - (-T_\mu T_\nu) = 2T_\mu T_\nu$。$\|F\| = 2\|T_\mu T_\nu\| = 2 \times 8 = 16$（$T_\mu$ 是酉，$\|T_\mu\| = \sqrt{64} = 8$）。迹为零因为 SU(2) 生成元无迹。$F_{\mu\nu}^2 = 4T_\mu T_\nu T_\mu T_\nu = -4T_\mu^2 T_\nu^2 = -4s_\mu s_\nu I$（用了反对易和 $T_i^2 = s_i I$）。∎

### 五、分离不可分：真正的墙

### 定理 4（SU(2) 是 U(1) 的涌现）

把 $T_\mu$ 的 U(1) 相位剥掉（$T_\mu \to |T_\mu|$ 纯平移），反对易消失：

|  | {T_x, T_y} | [T_x, T_y] | SU(2)/Cl(3) |
| --- | --- | --- | --- |
| 带磁通（±1） | 0 | 16 | ✓ 有（反对易） |
| 无磁通（纯平移） | 16 | 0 | ✗ 无（对易） |

**SU(2)（反对易）是 U(1) 相位（π 磁通）的涌现——去相位就无 SU(2）。**

所以 SU(2) 与 U(1) 在 $T_\mu$ 里 **不可分** ， **纯 SU(2) 的 $\omega_\mu$ 在 π 磁通里不存在。**

> **证明概要** ：带磁通时 $T_\mu |x\rangle = s_\mu(x)|x+e_\mu\rangle$，其中 $s_\mu(x) = \pm 1$ 依赖位置。计算 $\{T_x, T_y\} = T_x T_y + T_y T_x$：两个算符都作用在同一格点上，但路径不同（先 x 后 y vs 先 y 后 x），相位差恰好给出 $-1$（π 磁通），所以 $T_x T_y = -T_y T_x$。去掉相位后 $s_\mu(x) = 1$，两个路径等价，$T_x T_y = T_y T_x$，反对易消失。∎

### 为什么分离难

分离需要”独立的 site SU(2)“（作用在自旋指标、不涉及平移）。但 $P_x T_\mu P_x = 0$（$T_\mu$ 是 link 不是 site）——SU(2) 和轨道平移在 $T_\mu$ 里不可分，所以没有独立 site SU(2)。

> **证明概要** ：$P_x$ 是投影到单点 $x$ 的投影算子。$T_\mu |x\rangle = s_\mu(x)|x+e_\mu\rangle$，所以 $P_x T_\mu P_x = 0$（$T_\mu$ 把 $x$ 送到相邻点，不再落回 $x$）。这意味着 $T_\mu$ 不”停留”在单点上，它是 link（连接相邻点），不是 site（单点算符）。所以 SU(2) 不能从 $T_\mu$ 里”提取”出来变成只作用在单点自旋指标上的算符。∎

### 六、卡在哪：两层 + 定位

非平凡 $\omega_\mu$ 卡两层：

1. **分离（根本层）** ：π 磁通里 SU(2) 是 U(1) 的涌现，没有独立的 SU(2) 自旋 → 必须换体系；
2. **拓扑障碍（Hopf 荷，未证）** ：要”独立自旋”需非平凡拓扑；”自旋局域化的障碍 = Hopf 荷”未证。

**定位：不是重推，是新增。**

之前的东西（量子腿 + 纯迹选 π 磁通）不用重推——它们对、闭环。墙的本质是： **之前选出的 π 磁通（拓扑平凡，Chern = 0）给不了”独立自旋”。**

越墙 = **补上缺的一块：非平凡 Hopf 荷的”自发来源”** 。

这块硬，因为经典作用量（曲率惩罚）已证不生成拓扑（负结果），来源只能从”量子化 / 拓扑荷守恒”侧找。

### 七、一个值得注意的数字巧合（诚实标注）

付费桥 2（分离）与付费桥 1（量子化）可能在”2”上有张力，但 **来源不同、疑似数字巧合** ：

- 结构选择门给 **经典** 本征值尺度 $\pm\sqrt{d} = \pm 2$（$D^2 = 4I$）；
- 付费桥 1（量子化）给 **量子** 尺度 $\delta = 2\cos(\pi/(k+2)) < 2$（经典极限趋向 2）。

**决定性检验** （代数事实）：$\delta = 2\cos(\pi/(k+2))$ 值域 $[1, 2)$，上确界 2；而 $d = 6$（真正的 3D）时 $\sqrt{d} = \sqrt{6} \approx 2.449 > 2$。若两者是同一函数则 $\sqrt{d}$ 必落在 $[1, 2)$，矛盾。

**所以本征值尺度 ≠ 量子维度（作为函数）——大概率巧合。** 不作为独立结论。

### 八、诚实边界

1. **付费桥 2 = 分离是墙** ，不是”最后一公里”——非平凡 $\omega_\mu$ 需要换非平凡拓扑体系（honeycomb Haldane / Kane–Mele / 3D 拓扑绝缘体），且”自旋障碍 = Hopf 荷”对应未证。
2. **不可约分解严格依赖 $L = 4$** （$T_i^2$ 对合），一般 $L$ 推广开放。
3. **代数 A 的出路（标准模型有限部分）是”完整机器、不是快修”** 。
4. **“2 的巧合”疑似数字巧合** ，不当结构结论。

### 九、一句话总结

**物理空间三维的墙被精确到”分离”——$\omega_\mu$ 已内建在磁平移（平移 + U(1) + SU(2) 统一），但 SU(2) 与 U(1) 不可分（SU(2) 是 U(1) 相位的涌现），所以没有独立的实空间自旋联络。**

$$
T_\mu = \partial_\mu + A_\mu + \omega_\mu \ (\text{统一}) \xrightarrow{\text{去相位}} \text{无 SU(2)} \xrightarrow{\text{SU(2) 是 U(1) 涌现}} \text{分离不可分}
$$

越墙 = 补”非平凡 Hopf 荷的自发来源”（新增机制，非重推），障碍 = 拓扑（Hopf 荷），当前正方格点拓扑平凡（Chern = 0）只能给平凡 $\omega_\mu$。

**这是几何腿最后一个、也是最精确的卡点。它把”2D 到 3D 局部化”这个模糊的墙，精确成了”分离 U(1) × SU(2)“这个可判定的算子问题。**
