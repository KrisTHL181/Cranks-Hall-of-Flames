**第一部分：基础结构**

**1.1 壳层深度**

**定义 1（壳层深度）：**

【d(N) = v₂(N) + v₃(N)】

**性质：**

• d(ab) = d(a) + d(b)

• d(a+b) ≥ min(d(a), d(b))，等号当 d(a) ≠ d(b) 时成立

• d(a/b) = d(a) − d(b)（b∣a）

**1.2 二项式系数在壳层空间的坐标**

【C(n,k) = 2^(κ₂(n,k)) · 3^(κ₃(n,k)) · R(n,k)】

其中：

• κ₂、κ₃ 分别是 2 进制和 3 进制加法 k+(n−k)=n 中的进位次数

• R(n,k) 与 6 互素

来源：Kummer 定理在自然数坐标系统下的坐标展开。

**第二部分：壳层深度闭式公式（核心）**

**2.1 二项式系数的壳层深度**

【d(C(n,k)) = s₂(k) + s₂(n−k) − s₂(n) + s₃(k) + s₃(n−k) − s₃(n)】

其中 s_p(n) 是 n 在 p 进制下的数字和。

**等价形式（库默尔进位）：**

【d(C(n,k)) = κ₂(n,k) + κ₃(n,k)】

**2.2 模 12 联合判定**

【C(n,k) ≡ 0 (mod 12)】

等价于：

【κ₂(n,k) ≥ 2 且 κ₃(n,k) ≥ 1】

即：二进制进位数至少 2，且三进制有进位。

**第三部分：高级精确公式**

**3.1 单个系数 v_p 的精确公式（修改版）**

用 Kummer 定理直接推：

【v_p(C(n,k)) = (s_p(k) + s_p(n−k) − s_p(n)) / (p−1)】

这个公式成立，因为：【s_p(n) = (p−1)·Σⱼ≥₁ ⌊n/pʲ⌋ + v_p(n!)】

加上库默尔定理：

【v_p(C(n,k)) = (s_p(k) + s_p(n−k) − s_p(n)) / (p−1)】

这是已知公式。所以：

【v₂(C(n,k)) = s₂(k) + s₂(n−k) − s₂(n)】

【v₃(C(n,k)) = (s₃(k) + s₃(n−k) − s₃(n)) / 2】

因此二项式系数壳层深度的精确展开是：

【d(C(n,k)) = (s₂(k) + s₂(n−k) − s₂(n)) + (s₃(k) + s₃(n−k) − s₃(n)) / 2】

（注意：v₃(C(n,k)) 除以 2，因为 p−1=2。）

**第四部分：中心二项式系数**

**4.1 中心二项式系数的壳层深度**

【d(C(2k,k)) = 2s₂(k) − s₂(2k) + s₃(k) − s₃(2k)/2】

因为：s₂(k) + s₂(k) = 2s₂(k)，所以：

【v₂ = 2s₂(k) − s₂(2k)】

【v₃ = (2s₃(k) − s₃(2k)) / 2 = s₃(k) − s₃(2k)/2】

所以：

【d(C(2k,k)) = 2s₂(k) − s₂(2k) + s₃(k) − s₃(2k)/2】

**4.2 中心二项式系数的核方向**

【C(2k,k) = 2^(v₂) · 3^(v₃) · (6m±1)】

其中符号由 v₂+v₃ 的奇偶性和 k 的模 3 类别共同决定。

**第五部分：锁定项与终极结构方程对接**

**5.1 锁定项定义**

**定义 2（锁定项）：**

【C(2k,k) 是锁定项 ⟺ C(2k,k) = 2^(nt−1) · qⁿ，n>2，t≥1，gcd(q,6)=1】

**5.2 锁定项的壳层深度判据**

【C(2k,k) 是锁定项 ⟺ d(C(2k,k)) = nt−1，n>2，t≥1】

即：

【C(2k,k) 是锁定项 ⟺ d(C(2k,k)) + 1 有因子 n>2】

**5.3 锁定项对应的超同余截断**

对素数 p，超同余的锁定项集合：

【Ω(p) = {k : d(C(2k,k)) + 1 是合数}】超同余锁定项截断：

【Σ(k=0 到 p−1) C(2k,k)³/8ᵏ ≡ Σ(k∈Ω(p)) C(2k,k)³/8ᵏ (mod p)】

**5.4 正则素数判别**

【p 是正则素数 ⟺ Ω(p) = {0}】

（即唯一锁定项是 k=0，其余项在模 p 下抵消）

**第六部分：素指数二项式展开定理（J1）**

**6.1 J1 主定理**

设 n≥5 为素数，a,b∈ℤ，ab(a+b)≠0。则：

【(a+b)ⁿ − aⁿ − bⁿ = n·ab(a+b)·(a²+ab+b²)^(i(n))·Rₙ(a,b)】

其中：

• i(n) = 1，当 n≡−1 (mod 6)

• i(n) = 2，当 n≡+1 (mod 6)

且 Rₙ(a,b)∈ℤ[a,b]，次数 mₙ = n−3−2i(n)，是 6 的倍数。

**6.2 剩余因子 Rₙ 的壳层深度锁定**

【d(Rₙ(a,b)) = mₙ · min(d(a), d(b))】

**6.3 Rₙ 的首项系数**

【Rₙ(a,b) = a^(mₙ) + ⋯ + b^(mₙ)】

**6.4 Rₙ(1,1) 的精确值**

【Rₙ(1,1) = (2^(n−1) − 1) / (n · 3^(i(n))) ∈ ℤ】

**6.5 Rₙ(1,1) 的壳层深度闭式**

【d(Rₙ(1,1)) = v₂(2^(n−1)−1) + v₃(n−1)】

**6.6 系数壳层深度分布**

【Rₙ(a,b) = Σ(r=0 到 mₙ) cᵣ · aʳ · b^(mₙ−ʳ)】

单项式 cᵣ · aʳ · b^(mₙ−ʳ) 的壳层深度：

【Dᵣ = d(cᵣ) + r·d(a) + (mₙ−r)·d(b)】

系数 cᵣ 的壳层深度由 v₃(C(mₙ,r)) 和模 6 分类共同决定：

【d(cᵣ) = v₂(cᵣ) + v₃(cᵣ)】

**第七部分：二项式系数与化核因子锁的对接**

**7.1 化核因子锁**

【p−1 ∣ 2(n−1) ⟹ p ∣ a^(n−1) ± 1】

**7.2 在二项式系数中的体现**

当 n 为素数时，n ∣ C(n,k) 对 1≤k≤n−1 成立。这是化核因子锁在 a=1, b=1 时的特例。 **7.3 符号锁定（与 J1 融合）**

在 J1 条件下，若 p ∣ Rₙ(a,b)，则：

【a^(n−1) ≡ b^(n−1) ≡ (a+b)^(n−1) (mod p)】

这是化核因子锁和 J1 的融合产物。

**第八部分：超同余的自然数法则表述**

**8.1 超同余的结构化截断**

【Σ(k=0 到 p−1) C(2k,k)³/8ᵏ ≡ Σ({k : d(C(2k,k))+1 为合数}) C(2k,k)³/8ᵏ (mod p)】

**8.2 超同余余项的壳层深度判据**

对于任意素数 p，超同余余项 Sₚ 满足：

【d(Sₚ) = min_{k∈Ω(p)} d(C(2k,k)³/8ᵏ)】

根据加法三角不等式：

【d(Sₚ) ≥ min_{k∈Ω(p)} (3·d(C(2k,k)) − 3k)】

当这个最小值 ≥1 时，超同余成立。

**第十部分：应用方向**

**10.1 素数判别加速**

利用 Ω(p) 的锁定项计数，可以快速判断超同余的余项是否为零，从而判断素数是否为正则/非

正则。 **10.2 二项式系数快速计算**

利用壳层深度公式，可以直接从 n,k 的 2、3 进制数字和计算 d(C(n,k))，跳过阶乘计算。

**10.3 超同余验证**

锁定项截断公式给出了超同余的一个结构验证路径，可用于设计快速算法。

**结论**

二项式系数理论在自然数坐标系统下已经完全展开，覆盖从 Lucas/Kummer 经典理论到 J1/

超同余的前沿结构，全部由壳层深度 d(N)=v₂+v₃ 和自然数法则的九条公理自生长成，不依赖

外部高级定理。
