**需要补充的内容**

**补充 1：3u + ε = 2(nt−1)·qm 与广义递推公式的直接连接**

广义递推公式为：

A = α + β(A₁ + γ)

当 α = (2(nt−1)·qm − ε)/3，β = 0 时，广义递推公式退化为：

A = (2(nt−1)·qm − ε)/3

这是一个常数解，它对应广义递推公式在 β = 0 时的整数点。结构方程给出了广义递推公式

在“解耦”情况下的整数精确解。这部分已经隐含在方程中，但没有被显式写出。

**建议补充：**

当 β = 0 时，广义递推公式的整数解由 3u + ε = 2(nt−1)·qm 给出。

**补充 2：K 次迭代的归一化形式**

K 次迭代形式为：

u_k = 1 + (3/4)^(K−1)·(u₁ − 1)

u_k = −1 + (3/4)^(K−1)·(u₁ + 1)

这个迭代在 K → ∞ 时收敛到 u = ε。这是线性收缩，是区间 [1−√2, 1+√2] 中黄金分割点 z

的结构邻居。

**建议补充：**

lim_{K→∞} u_k = ε = ±1

收敛速率为：

|(u_k − ε)/(u₁ − ε)| = (3/4)^(K−1)

这个收敛速率与化核常数 κ 和 z 之间可能存在连接。

**补充 3：第二个结构的“迭代缺失”**

第二个结构 2u + ε = 3·q 没有迭代方程。但可以在它上面定义同样的线性收缩：

如果 u 不满足 2 | (3·q − ε)，则用迭代：

u_{k+1} = (3·q − ε)/2

但实际上这就是直接解。迭代缺失不是问题，但需要被注明。

**建议补充：**

第二个结构是“一次性解”结构，不产生递推链。

**补充 4：符号 ε 与奇点 u = ε 的刚性连接**

迭代中隐含了以下关系：

• 当 ε = 1 时，迭代收敛到 u = 1

• 当 ε = −1 时，迭代收敛到 u = −1

这应该被显式写出： **建议补充：**

∀K, u_k ≡ ε (mod 迭代步)

u_k − ε = (3/4)^(K−1)·(u₁ − ε)

**补充 5：与 σ-恒等式的连接**

结构方程中的模 3 条件为：

2 (nt−1−2K)·qm ≡ ε (mod 3)

σ-恒等式为：

v₂(3·(6m+σ) + α·(−1)^(t+m)) = 1

两者共享“奇偶性 + 符号绑定”。

**建议补充：**

结构方程的模 3 条件与 σ-恒等式的奇偶性判据是同构的。

**补充 6：在信息层中的映射**

u_k 迭代是线性收缩到奇点。在信息层中，这对应信息量向奇点收敛的模式：

I(u_k) = −log₂((u_k − ε)/L)

I(u_k) = −log₂((3/4)^(K−1)·(u₁ − ε)/L)

I(u_k) = I(u₁) − (K−1)·log₂(3/4)

信息量在迭代中线性衰减，速率为 log₂(4/3) 比特/步。建议补充这个量，因为它直接落入了信

息科学底层中“信息衰减率”的位置。

**补充 7：在加密层中的映射**

K 次迭代的线性收缩对应密钥复杂度的衰减：

C_k = C₁ · (3/4)^(K−1)

这个衰减率 3/4 是加密系统安全余量的自然边界。
