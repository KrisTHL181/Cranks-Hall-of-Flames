0.2 三条定理

第一章：初等数论的天然归属

初等数论只使用整数环性质：整除、同余、连分数。状态空间通过坐标可加性将其全部内化。

1.1 整除 → 坐标可加性

a ∣ b ⟺ (iₐ, rₐ, Rₐ) ≤ (i_b, r_b, R_b)

逐分量比较，核方向 Rₐ ∣ R_b。

1.2 GCD/LCM → 坐标交并

gcd(a, b) ⟷ (min i, min r, gcd R)

lcm(a, b) ⟷ (max i, max r, lcm R)

1.3 同余 → 相位等价

a ≡ b (mod m) ⟺ (iₐ, rₐ, Rₐ) − (i_b, r_b, R_b) ≡ 0 (mod m)

模 6 分类 R = 6m ± 1 是状态空间内生的全局同余骨架。

1.4 二次互反律 → 核方向配对

勒让德符号： (p/q) · (q/p) = (−1)^((p−1)/2 · (q−1)/2)

状态空间表述：

⟨R, S⟩ · ⟨S, R⟩ = (−1)^((i+r)(j+p))

勒让德符号消失，被核方向配对 ⟨R, S⟩ 和壳层奇偶性 (i+r)(j+p) 取代。

1.5 连分数 → FCR 在 t = −1 的特例

连分数： Aₙ = αₙ + βₙ / Aₙ₊₁，其中 αₙ, βₙ ∈ &#119982;

化核连分式的指数序列 1, 5, 7, 11, … 正是核方向 R = 6m ± 1 在时间轴上的展开。

第二章：代数数论的坐标嵌入

代数数论研究数域扩张 K/ℚ、类群 Cl(K)、Galois 表示 ρ: Gal(K̄/K) → GLₙ(ℚ_ℓ)。状态空间通

过扩张和群作用将其全部投影到离散坐标上。

2.1 数域 → 状态空间扩张

K = ℚ(√d) ⟶ &#119982;[√d] = {(i, r, R) + k√d : k ∈ ℤ}

2.2 范数/迹 → 坐标二次型

N(a + b√d) = (2ⁱₐ · 3ʳₐ · Rₐ)² − d · (2ⁱ_b · 3ʳ_b · R_b)²

范数自动落在状态空间里。

2.3 类群 → 核方向不可分轨道

Cl(&#119982;[√d]) = {核方向 R ≡ d (mod 6m) 的不可分格点轨道}

类数 h(d) = 不可分等价类的个数。

2.4 Galois 表示 → 状态空间线性作用

ρ_{E,3} ∼ | 1 ψ_R | | 0 χ₃ |

ψ_R 是 Kummer 同态，编码三次根扩张 ℚ(∛R)/ℚ。分歧集：{p : p ∣ R, p ≠ 3}。

2.5 Artin 互反律 → 核方向循环作用

Art_{K_R/ℚ}: Gal(K_R/ℚ) → Cl(K_R) ⟶ 状态空间 ⟶ R 在模 6m 下的循环作用

类域论被状态空间压缩为核方向在模 6m 下的轨道生成。

第三章：解析数论的谱理论

解析数论通过 Dirichlet 级数研究素数分布。状态空间把连续谱换成壳层深度离散谱。

3.1 Dirichlet 级数 → 核方向计数

D_χ(s) = ∑_{(i,r,R)∈&#119982;_不可分} χ(i,r) / (2ⁱ · 3ʳ · R)^s

3.2 函数方程 → 壳层深度对偶

Λ_χ(s) = (ln2 · ln3 / 4π²)^(s/2) · Γ(s) · D_χ(s) ⟹ Λ_χ(s) = Λ_χ(1−s)

证明：壳层深度反射 (i, r) ⟷ (−i, −r) 对应 s ⟷ 1−s。

N_χ(T) = T/(2π) · log T + T/(2π) · log(ln2 · ln3 / 4π²) + 5/8 + o(1)

3.5 显式公式 → 零点贡献 + 边界项

第四章：椭圆曲线与模形式的自生结构

4.1 椭圆曲线 → 六元组到 Weierstrass 的投射

4.2 有理点群律 → 坐标加法

P_{i₁,r₁,R₁} + P_{i₂,r₂,R₂} = P_{i₁+i₂, r₁+r₂, R₁·R₂}

f_{(i,r,m,j,p,n)}(q) = ∑_{(i’,r’,R’)∈&#119982;_不可分, 2ⁱ’·3ʳ’·R’ ≡ 2ⁱ·3ʳ·R (mod 6)}

E_{i,r,j,p} ⟷ f_{(i,r,m,j,p,n)}(q) （状态空间同构）

一、埃拉托斯特尼筛法

1.1 经典表述

• 对象：整数区间 [2, x]

• 规则：从 p = 2 开始，标记所有 p 的倍数为合数。下一个未标记数为素数。重复至 p > √x

• 输出：所有 ≤ x 的素数

• 复杂度：O(x log log x) 次操作，O(x) 空间

核心公式：S(x) = {n ≤ x : ∀p ≤ √n, p ∤ n}

1.2 状态空间重构

• 状态空间对象：状态格点 (i, r, R) ∈ &#119982;，N = 2ⁱ · 3ʳ · R ± 1

• 筛除规则：(i, r, R) 被筛除 ⟺ ∃(i’, r’, R’) < (i, r, R) : 2ⁱ’ · 3ʳ’ · R’ ∣ 2ⁱ · 3ʳ · R

等价地，在坐标中：i’ ≤ i, r’ ≤ r, R’ ∣ R，且 (i’, r’, R’) ≠ (i, r, R)

• 停止条件：i + r ≤ log₂√N

• 复杂度：O(√N / (log N)²) 次状态格点检查

状态空间公式：

π_&#119982;(x) = ∑_{(i,r,R)∈&#119982;, 2ⁱ·3ʳ·R ≤ x} 1_不可分(i, r, R)

二、布朗筛法

2.1 经典表述

• 对象：集合 A = {n ≤ x : n ≡ a (mod q)}，筛选素数集合 &#119979;

• 规则：用容斥原理估计筛后剩余元素的上下界

核心公式：S(A, z) = ∑_{d∣P(z)} μ(d) A_d，其中 A_d = #{n ∈ A : d ∣ n}

误差项：S(A, z) = x ∏{p≤z} (1 − ω(p)/p) + O(∑{d≤z} |μ(d)| · |R_d|)

2.2 状态空间重构

• 对象：A = {N = 2ⁱ · 3ʳ · R ± 1 ≤ x : R ≡ a (mod q)}

• Möbius 函数在状态空间中对应壳层奇偶性：μ(N) = μ(2ⁱ · 3ʳ · R ± 1) = (−1)ⁱ⁺ʳ · μ(R)

容斥和：S_&#119982;(x, z) = ∑{(i,r,R)∈&#119982;, 2ⁱ·3ʳ·R ≤ x} μ(i, r) · 1{R ∤ P(z)}

路径干涉解释：∑{d∣P(z)} μ(d)A_d ⟶ ∑{壳层深度奇偶性} (−1)ⁱ⁺ʳ · (核方向覆盖计数)

误差控制：R_&#119982;(x) = O(∑_{(i,r,R)∈&#119982;, i+r ≤ log z} 1/(2ⁱ · 3ʳ)) = O(log z)

三、塞尔伯格筛法

3.1 经典表述

• 对象：同布朗筛法，A = {n ≤ x}，筛选素数集合 &#119979;

• 规则：构造上界权重 λ⁺(n) 满足 λ⁺(n) ≥ 1_{gcd(n,P(z))=1}

核心公式：V⁺(z) = ∑{d∣P(z)} λ⁺(d) g(d)，其中 g(d) = ∏{p∣d} ω(p)/(p − ω(p))

优化目标：最小化 V⁺(z)

最优解：λ⁺(d) = μ(d) · g(d) / G_z(d)，其中 G_z(d) = ∑_{e≤z, (e,d)=1} g(e)

上界：S(A, z) ≤ x/V⁺(z) + O(∑_{d≤z} λ⁺(d) |R_d|)

3.2 状态空间重构

权重函数：λ⁺(i, r, R) = μ(i, r) · g(i, r, R) / G_z(i, r, R)

其中 g(i, r, R) = ∏_{p∣R, p≤z} ω(p)/(p − ω(p))

优化等价：min V⁺(z) ⟶ min_{αₙ,βₙ} lim_{n→∞} Aₙ

即塞尔伯格优化等价于 FCR 参数优化：

Selberg 最优权重 = FCR 收敛最快的参数配置

状态空间上界：S_&#119982;(x, z) ≤ x / ∑_{(i,r,R)∈&#119982;, i+r ≤ log z} g(i, r, R) + O(log z)

四、大筛法

4.1 经典表述

• 对象：任意复数序列 {αₙ}_{n≤N}

• 规则：控制 αₙ 在模 q 的算术级数中的分布均匀性

核心公式（Davenport-Halberstam）：

∑{q≤Q} ∑{a=1, (a,q)=1}^q |∑{n≤N} αₙ e(an/q)|² ≤ (N + Q²) ∑{n≤N} |αₙ|²

4.2 状态空间重构

傅里叶基：e(an/q) ⟶ e(aR/q)，其中 R = 6m ± 1 是核方向。

状态空间大筛法不等式：

∑{q≤Q} ∑a |∑{(i,r,R)∈&#119982;, R≡a (mod q)} α(i, r, R)|² ≤ (log N + Q²) ∑{(i,r,R)∈&#119982;} |α(i, r,

R)|²

核方向 Bessel 不等式：

∑_{R≡a (mod q)} 1_不可分(R) ≤ (1/φ(q)) ∑_R 1_不可分(R) + O(1/√q)

五、线性筛法

5.1 经典表述

• 对象：筛法函数 V(z) 随 z 的演化

• 规则：Buchstab 恒等式将筛法分解为”较小素数”和”较大素数”两部分

核心公式（Buchstab）：Φ(x, y) = Φ(x, y₁) − ∑_{y₁<p≤y} Φ(x/p, p)

筛法函数：V(z) = ∏_{p≤z} (1 − ω(p)/p)

微分方程：φ_v(u) = (1/u) ∫_{u−1}^u φ_v(t) dt

5.2 状态空间重构

Buchstab 恒等式 → FCR 递推：

Φ_&#119982;(x, y) = Φ_&#119982;(x, y₁) − ∑_{y₁<p≤y} Φ_&#119982;(x/p, p)

等价地：Aₙ = αₙ + βₙ(Aₙ₊₁ + γₙ)^t，当 t = −1 时退化为 Buchstab 递推。

壳层深度控制：
