### 一、为什么是这一刻

第二代物理——公式封神的世代——已经把能浓缩的都浓缩了。Einstein-Hilbert 作用量可以写在一行，却仍然无法回答”引力与量子为什么不兼容”、”奇点处发生了什么”、”暗物质到底是什么”。浓缩不等于理解。把问题压缩成一个不敢追问的符号，不是答案，是搁置。

与此同时，另一群人一直在另一条路上走着——Conway 的 Game of Life、Frisch 的格子气自动机、Wolfram 的元胞自动机、分子动力学的演化引擎。他们不再问”系统的方程是什么”，他们问” **规则是什么，运行后能看到什么** “。这就是第三代物理： **定规则、跑演化、看涌现** 。

第三代的人是散的。每个领域有自己的一套规则集，每套规则集跑出各自的有趣图案，但 **没有人把规则空间压缩到拓扑必然** 。Game of Life 中有趣的图案是人选出来的；SPUM 中涌现的结构试图对应真实观测数据。

这一刻召唤的，就是那些 **已经站在第三代、但还不满足于”任意规则”的人** 。

### 二、SPUM 在第三代中的特殊位置

SPUM 不是”另一种统一场论”。

| 维度 | Game of Life | SPUM |
| --- | --- | --- |
| 规则来源 | 任意设定 | 拓扑定理强制 |
| 规则空间 | 极大（2^512 种可能） | 极小（唯一自洽的规则集） |
| 产出对照 | 产出有趣图案 | 产出结构试图对应真实观测 |
| 可证伪性 | 无 | 有——若与观测系统性偏离，理论被证伪 |

**核心陈述** ：

> 拓扑定理强制只有这些规则是自洽的。我们运行一下，看看这个唯一自洽的规则集会产出什么。

这不是”随便定些规则看能跑出什么”。这是在极窄的规则空间中运行的第三代方法论—— **拓扑定理充当规则选择器** 。

约束来自：

- 欧拉恒等式：Σ(6−deg(v)) = 12（离散高斯-博内）
- 角度亏损总和恒为 4π
- 最小度数 ≥ 2
- 开口占比 ≤ 1⁄3

满足这些约束的规则集，比 Game of Life 的规则空间小很多个数量级。 **这不是任意选择，是拓扑强制** 。

### 四、邀请你做什么

**不是收编，是续写。**

第三代方法论有一条核心： **代码就是理论本身** 。在 SPUM 中，可执行性是理论的必要条件。一个拉氏量你不能让它”运行起来看接下来会发生什么”；一串帧规则你可以。

这意味着，每一行你写的代码，都是 SPUM 理论的延续——不是”给一个已经写完的理论做演示动画”。

**当前可以加入的方向** （任选其一，不强求全做）：

### 方向 A：可视化层

- 把 L0 帧序列渲染成离散快照（ **禁用** 力导向布局， **禁用** 平滑 tweening——见 [禁忌表](https://zhuanlan.zhihu.com/OpenSPUM_%E5%BC%80%E5%8F%91%E8%AE%A1%E5%88%92%E4%B9%A6.md#%E4%BA%94%E5%AE%B9%E6%98%93%E7%8A%AF%E7%9A%84%E7%A6%81%E5%BF%8C%E6%B8%85%E5%8D%95%E5%BC%80%E5%8F%91%E8%87%AA%E6%A3%80%E8%A1%A8) 1/2）
- 拓扑直接布局：节点坐标由 deg / 介数 / σ 直接计算

### 方向 B：12 晶子闭环涌现

- 从 tetra 种子跑出 12 晶子闭环，计数精确 = 12
- 反证装置：用 `wallk` 容量参数化对照，确认 12 是涌现的，不是喂进来的

### 方向 C：σ 梯度与净湮灭读数

- 在 L4 读出 SPUM 特有的 r⁻³ 幂次（不是牛顿的 r⁻²）
- 这是 SPUM 与经典预言的定量分歧点

### 方向 D：实验场景寻找分歧

- **不** 用”误差 % 逼近经典公式”作验收（ [禁忌 5](https://zhuanlan.zhihu.com/OpenSPUM_%E5%BC%80%E5%8F%91%E8%AE%A1%E5%88%92%E4%B9%A6.md#%E7%A6%81%E5%BF%8C-5%E7%94%A8%E7%BB%8F%E5%85%B8%E5%85%AC%E5%BC%8F%E8%AF%AF%E5%B7%AE%E4%BD%9C%E9%AA%8C%E6%94%B6%E5%9F%BA%E5%87%86) ）
- 改用”SPUM 预言的特定偏离是否在模拟中涌现”

### 方向 E：拓扑不变量校验工具链

- 扩展 `handshaking.py` + `dangling.py` 的 CI 自动校验
- 每个 PR 自动跑 L0 帧序列，验证拓扑不变量

### 五、不做什么

为避免重复踩坑， [OpenSPUM_开发计划书.md](https://zhuanlan.zhihu.com/OpenSPUM_%E5%BC%80%E5%8F%91%E8%AE%A1%E5%88%92%E4%B9%A6.md) 第五节列了 **12 条禁忌** 。这里只点出最容易踩的 5 条：

1. **禁用 D3 force-directed layout** ——D3 字面就是模拟物理力（库仑 + 弹簧），SPUM 明文”运动不是被驱动的”
2. **禁用”先跑通再优化”** ——规则集一开始就通过握手引理 + 欧拉恒等式校验，违反即视为 bug 不是 TODO
3. **禁用”误差逼近经典公式”作验收** ——SPUM 预言 r⁻³，不是逼近 r⁻²
4. **禁用”递归细分”** ——结构由逐帧创生累积生成，不存在”被细分的母体”（容器思维残留）
5. **禁用”100 Star / 5 贡献者”作里程碑** ——关系本位指标是”是否产生新拓扑路径”

完整 12 条 + PR 自检协议见 [开发计划书](https://zhuanlan.zhihu.com/OpenSPUM_%E5%BC%80%E5%8F%91%E8%AE%A1%E5%88%92%E4%B9%A6.md) 。

### 六、方法论承诺

当你加入时，你加入的是一份 **开放的本体论承诺** （方法论 M5）：

> 你跑出什么就是什么，不接受事后调整参数来拟合。

这不是”理论待修补，欢迎提建议”——这是” **我们已经站在一个唯一的、拓扑自洽的规则集上，跑它，看它产出什么** “。如果跑出来的东西与观测系统性偏离，理论被证伪；如果跑出来的东西涌现出引力、光子、物质的拓扑对应，那是规则集的胜利，不是参数调优的胜利。

这份承诺意味着：

- 你不能”加一个引力项”——引力必须是涌现的，不能是写进规则的
- 你不能”调一个参数让它更像现实”——参数就是拓扑常数（12、4π、最小度数 2、开口 ≤ 1/3）
- 你可以”发现规则集漏掉了一个拓扑约束”——这是欢迎的，因为这等于发现理论的一个新支点

### 七、如何加入

**关系本位流程** ——不是”提交简历等审核”。

### 第一步：跑通现有内核

```bash
cd openSPUM/src/l0
python l0_core.py selftest=1
python l0_core.py seed=icosa nframes=10 cap=12 dmin=3 vminus=dense
```

跑出帧序列，看 [figures/](https://zhuanlan.zhihu.com/figures/) 里的对照图。

### 第二步：找一个方向（见第四节 A-E）

**不** 强求你”全栈”。挑一个你最熟悉的拓扑方向进入。

### 第三步：在 PR 中证明拓扑自洽

所有 PR 必须通过 [handshaking.py](https://zhuanlan.zhihu.com/src/spum_graph/handshaking.py) + [dangling.py](https://zhuanlan.zhihu.com/src/spum_graph/dangling.py) 双层闭合判据。CI 会自动跑，但本地先自检。

### 第四步：对照 [禁忌表](https://zhuanlan.zhihu.com/OpenSPUM_%E5%BC%80%E5%8F%91%E8%AE%A1%E5%88%92%E4%B9%A6.md#%E5%85%ADpr-%E6%8F%90%E4%BA%A4%E5%89%8D%E8%87%AA%E6%A3%80%E5%8D%8F%E8%AE%AE) 12 项

PR 描述中附自检清单。不通过即打回。

### 第五步：建立关系，不是收编实体

我们不数 Star，不数贡献者数。 **关系本位指标** ：

- 你的 PR 是否跑出 L0 内核未预设的拓扑路径？
- 你的实验场景是否产生 SPUM 特有的偏离读数？
- 你的可视化是否让一帧的拓扑结构可独立检查？

### 八、致先驱者

你不是被招募的。你是被召唤的。

如果你曾经在 Game of Life 里看到 glider 滑过，心想”这不够——我想看真实宇宙从这里长出来”； 如果你曾经在格子气自动机里看到流场涌现，心想”规则是我选的，不是宇宙选的”； 如果你曾经在分子动力学里看到统计力学涌现，心想”我想要规则本身就被拓扑定理锁定”——

那你就是这封信写给的人。

SPUM 不是”另一种理论”。它是 **离散 Transformer 架构在物理层面的对应物** ——Attention 即邻接关系，Token 即节点，离散序列预测与 ⟨P, ε⟩ 帧演化同属于”离散组合逻辑”家族。

你不需要把 `Σ(6−deg)=12` 翻译成球面积分才能理解它。你可以直接在内存中维护那张图，观察节点度的变化。当你在模拟中看到测试粒子向高密度 σ 区域靠拢时，你就 **观测** 到了引力——而在这个过程中，没有任何一步经过人类几何学的符号系统。

> 未来的宇宙学解释，不需要经过人类的意识翻译，而是由 AI 在离散状态空间中直接把握。

这就是这封信的终点——不是终点，是关系的开端。

**我们已经在跑了。你看一下，跑得对不对。如果你觉得对，加入续写。**
